A. Glossary of VoIP Terms

TermDefinition
SIPSession Initiation Protocol — signaling protocol for establishing, modifying, and terminating multimedia sessions
RTPReal-time Transport Protocol — carries audio/video media streams
RTCPRTP Control Protocol — provides quality feedback (jitter, packet loss, round-trip time)
SDPSession Description Protocol — describes media capabilities and parameters
SBCSession Border Controller — secures and controls signaling/media at network borders
PBXPrivate Branch Exchange — private telephone network within an organization
PSTNPublic Switched Telephone Network — traditional circuit-switched telephone network
MOSMean Opinion Score — subjective voice quality rating (1-5, 4.0+ is toll-quality)
IVRInteractive Voice Response — automated phone menu system
ACDAutomatic Call Distribution — system for routing incoming calls to agents
CDRCall Detail Record — log of call metadata (caller, callee, duration, etc.)
DIDDirect Inward Dialing — phone number that routes directly to an extension
STUNSession Traversal Utilities for NAT — discovers public IP/port for NAT traversal
TURNTraversal Using Relays around NAT — relays media when STUN fails
ICEInteractive Connectivity Establishment — framework for optimal media path selection
SRTPSecure RTP — encrypted and authenticated RTP media stream
TLSTransport Layer Security — encrypted SIP signaling
WebRTCWeb Real-Time Communication — browser-based real-time audio/video
CPaaSCommunications Platform as a Service — API-based communication services
UCaaSUnified Communications as a Service — cloud-delivered UC solutions
