Appendix A — Glossary of AI Engineering Terms

This glossary collects the terms used throughout the book in one place. Definitions are written for engineers: practical, concise, and focused on how the concept appears in a real system. Where a term has a precise technical meaning and a looser industry usage, both are noted.

Models and prompting

Attention
The mechanism that lets a model weigh other tokens in the context when predicting the next token. Because attention is finite, irrelevant context competes with relevant context and can degrade output.

Batching
Processing several inference requests together to improve throughput. Continuous batching adds new requests to a running batch; static batching waits for a group.

Context window
The maximum number of tokens a model can consider in one call, including instructions, history, retrieved evidence, and the output being generated.

Context engineering
The discipline of putting the right information, in the right shape, into the context window at the right time. Distinct from prompt engineering, which focuses on instruction wording.

Few-shot prompting
Including a small number of input–output examples in a prompt to demonstrate a format or judgement rule.

Foundation model
A large pre-trained model that can be adapted to many downstream tasks through prompting, retrieval, or fine-tuning.

Instruction tuning
Additional training that makes a model follow directives and adopt an assistant style, as opposed to a base model that simply continues text.

Quantisation
Storing model weights at lower numeric precision to reduce memory and improve speed, sometimes at a cost to quality.

Reasoning model
A model that spends extra tokens on internal steps before answering. Useful for hard problems, slower and costlier for simple ones.

Structured output
Constraining a model's response to a schema so it can be consumed as typed data by application code.

Temperature
A sampling parameter that flattens or sharpens the token distribution. Low values suit extraction; higher values suit creative work.

Token
The unit a model reads and generates. Tokens drive context limits, cost, and latency. English averages roughly four characters per token.

Retrieval and data

Chunking
Splitting documents into passages small enough to retrieve precisely and large enough to be meaningful. Structure-aware chunking follows headings and paragraphs.

Embedding
A vector representation of text in which semantically similar content lies nearby. Used for vector search and retrieval.

Hybrid retrieval
Combining vector search with keyword search to cover both conceptual similarity and exact terms such as identifiers.

Reranking
Scoring and reordering a shortlist of retrieved candidates with a stronger, slower model to improve precision.

RAG
Retrieval-Augmented Generation: looking up relevant material at request time and placing it in context so answers are grounded in fresh, private data.

Vector store
A database optimised for storing embeddings and finding nearest neighbours to a query vector.

Agents and orchestration

Agent
A loop that observes, decides, acts, and observes again. In practice, a model plus instructions, tools, state, and a stopping condition.

Agentic system
The larger application around an agent: tools, memory, policies, evaluation, runtime, and user interfaces.

Checkpointer
A component that persists state after each step, enabling conversational memory, replay, and resume after a restart.

Handoff
A transfer of control from one agent to another, usually with a payload carrying context about why the transfer happened.

Node
In a graph-based orchestrator, a function that reads state and returns an update. Nodes do the work; edges decide what runs next.

ReAct
A pattern that interleaves short reasoning with tool calls, so the next action depends on the last observation.

Reflection
A pattern where a generator produces output and a critic evaluates it against a rubric, optionally requesting revision.

Tool calling
A structured request from a model to the harness asking it to run a named function with specific arguments. The model proposes; the harness executes.

Workflow
A prescribed path where the developer controls transitions. Contrasts with an agent, which has more say over the next step.

Protocols and integration

MCP
Model Context Protocol: a standard contract by which AI applications discover and use tools, resources, and prompts exposed by servers.

Resource
In MCP, a data capability identified by a URI. Distinguished from a tool (an action) and a prompt (reusable context).

Idempotency key
An identifier that ensures a repeated mutating request produces the same effect rather than a duplicate side effect.

Durable state
State stored outside a process so a long-running task can survive restarts and resume from its last checkpoint.

Evaluation and operations

Canary
A small, stable set of cases run continuously against production to track quality as a time series and detect drift.

Drift
A gradual change in behaviour or output distribution that passes hard assertions but degrades quality.

Eval harness
A program that runs cases against a system, applies scorers, and produces a report. Comprises cases, runner, scorers, and reporter.

LLM judge
A model used to score outputs against a rubric. Requires calibration against human judgement and should be decomposed into atomic questions.

Groundedness
The degree to which claims in an answer are supported by the evidence supplied in context.

Mutation testing
Deliberately breaking code or context to check whether tests or evals detect the change. Exposes tests that check nothing.

Silent failure
Degradation that produces plausible output and no error signal, so it is noticed by users before dashboards.

Span
A timed unit of work inside a trace: a model call, tool execution, retrieval step, or guardrail check.

Trace
A tree of spans representing one complete run, used to reconstruct behaviour and attribute cost and latency.

Safety and infrastructure

Guardrail
A check on input or output that can allow, block, or transform. A useful control layer, but not a substitute for tool-level authorisation.

Least privilege
Giving a component only the permissions it needs to do its job, minimising blast radius if it is manipulated.

Prompt injection
Untrusted text that attempts to change an agent's instructions or goals. Mitigated by isolation and tool policy, not by delimiters alone.

Model router
A component that selects a model or specialist per request, balancing cost, latency, and quality.

Cascade
A cheap-first routing strategy that escalates to a stronger model only when a verifier rejects the first answer.

Prefix caching
Reusing computed attention state for a stable prompt prefix to reduce cost and latency.

Serverless
An execution model where the platform manages scaling and you pay for execution time. Fits short, bursty tool calls.
