19. References

References

iOS API Reference

  • UIKit — UI components and event handling
  • SwiftUI — Declarative UI framework (iOS 13+)
  • Foundation — Core data types, collections, networking
  • Core Data — Object graph and persistence
  • CloudKit — iCloud data storage and sync
  • MapKit — Maps, annotations, routing
  • AVFoundation — Audio and video playback/recording
  • Core Motion — Accelerometer, gyroscope, pedometer
  • Core Location — GPS and location services
  • StoreKit — In-app purchases and subscriptions
  • GameKit — Leaderboards, achievements, multiplayer
  • SpriteKit — 2D game engine
  • SceneKit — 3D graphics engine
  • HealthKit — Health and fitness data
  • LocalAuthentication — Face ID and Touch ID
  • Speech — Speech recognition
  • AuthenticationServices — Sign in with Apple

Glossary

ARCAutomatic Reference Counting — memory management
IBActionInterface Builder action method connected from UI

MVCModel-View-Controller architecture pattern
MVVMModel-View-ViewModel pattern (common with SwiftUI)

SDKSoftware Development Kit
StoryboardVisual representation of app screens and segues
SwiftUIDeclarative UI framework introduced in iOS 13

  • Fastlane — Build automation and deployment
