Build the CashTrack Web App

Time to build something real with Copilot as your pair programmer. CashTrack is a small single-page app (HTML + CSS + JavaScript) that lets a user record income and expenses, see the totals split by category in an interactive bar chart, and download the entries as a file. By the end of this chapter you will have used nearly every Copilot surface: chat, quick chat, inline chat, completions, and editing. It is intentionally simple — the point is the way we build it.

Reference result: a page with a navbar, a transaction form, a list of transactions, a Chart.js bar chart ("spending by category"), and a Download button that saves a CSV. All plain files — no build tooling, just open index.html in a browser.

1. Create the project using Copilot Chat

Make a folder cashtrack/ and open it in VS Code. Rather than creating three files by hand, ask the chat panel to scaffold the skeleton:

@workspace /generate \
Create a single-page income & expense tracker called "CashTrack". Three files:
- index.html  : includes Bootstrap 5 (CDN) and Chart.js (CDN), a navbar, a form to add a
                transaction (description, amount, type: income|expense, category), a
                transactions table, a canvas for a Chart.js bar chart, and a Download button.
- style.css   : minimal custom overrides on top of Bootstrap.
- app.js      : add/edit/delete logic in a transaction array, render the table, store to localStorage,
                render the chart (spending by category for expenses), and export a CSV when Download is clicked.
Use only the standard library, no frameworks beyond these CDNs.

Copilot creates all three files with reasonable structure. Do not accept blindly — open each file and confirm it matches the description. This "describe → generate → verify" loop is the core Copilot rhythm.

First review: Copilot will guess your taste. If it omitted the navbar or the download isn't wired, do not start over — press Enter in a new chat message and say precisely what is missing. Rephrase, don't restart.

2. Integrate Bootstrap and add a navbar

If the scaffold did not include Bootstrap, or you want a bigger navbar, use inline chat on the <head> and <nav> targets:

# Select the <head> region and press Ctrl+I (inline chat):
> Add Bootstrap 5.3 CSS from jsdelivr in the head, and give the page a light background.
> Also add the Bootstrap JS bundle before .

# Select a placeholder <nav> (or ask where one is missing):
> Replace with a Bootstrap navbar: brand "CashTrack", links Home / Transactions / Report,
> a dark bg-light shadow, and a Wallet emoji in the brand.

Inline chat inserts the change right where your cursor is. This is the fastest way to make localized UI changes — no need to context-switch to the chat panel.

3. Quick chat vs. inline chat

Two surfaces do similar work; knowing when to use each keeps you fast:

SurfaceShortcutBest forWhat you get
Chat panelCtrl+Alt+IOpen-ended questions, multi-file plans, explanationsA whole conversation you can iterate on
Quick chat (floating input)Ctrl+Shift+IOne-off questions without opening the panelA small input popup that closes after your answer
Inline chatCtrl+ITargeted edits to the code under the cursorInsert/Apply actions directly in the file

Rule of thumb: editor changes → inline chat, single question → quick chat, everything else → panel.

5. Add a Chart.js bar chart using Copilot

Chart.js is loaded via CDN (it comes with the scaffold). To draw "spending by category", instruct in chat:

Panel / inline (select app.js):
> Add a function renderChart(transactions) that:
>   - filters to expenses only,
>   - groups by category summing amounts,
>   - draws a bar chart on the #spendingChart canvas with label 'Spending by category',
>     sky-blue bars and a grid,
>   - destroys any previous chart instance before redrawing so edits don't accumulate.
> Call it after every add/delete and after load from localStorage.
// A version Chat might produce (always redraw, never leak old charts)
let chart; // hold the instance
function renderChart(txns) {
  const byCat = {};
  txns.filter(t => t.type === 'expense').forEach(t => {
    byCat[t.category] = (byCat[t.category] || 0) + +t.amount;
  });
  const labels = Object.keys(byCat), values = Object.values(byCat);
  if (chart) chart.destroy();
  chart = new Chart(document.getElementById('spendingChart'), {
    type: 'bar',
    data: { labels, datasets: [{
      label: 'Spending by category', data: values,
      backgroundColor: '#7eb8ff', borderRadius: 4
    }] },
    options: { scales: { y: { beginAtZero: true } } }
  });
}

Two details are worth checking every time Chat emits a chart: the destroy-the-old-chart pattern (avoids duplicate bars after re-render) and the + +t.amount string-to-number coercion (JSON values from inputs are strings until parsed).

6. Implement the download functionality

CSV download is a classic "boring, fiddly, perfect for AI" task. Describe the shape you want, then adjust:

Inline (select the Download button handler):
> On click, export all transactions as a CSV with columns
> date, description, category, type, amount. Escape commas in fields,
> use LF line endings, and trigger the download as cashtrack.csv
> via a temporary anchor with data:text/csv;charset=utf-8.

Then refine:  "Prefix the amount with minus when type is expense."
             "Add a BOM (\uFEFF) so Excel opens the CSV with correct encoding."
function downloadCsv(txns) {
  const head = 'date,description,category,type,amount';
  const rows = txns.map(t => [
    t.date, `"${(t.description||'').replace(/"/g,'""')}"`,
    t.category, t.type,
    t.type === 'expense' ? `-${t.amount}` : t.amount
  ].join(','));
  const csv = '\uFEFF' + [head, ...rows].join('\n');
  const a = document.createElement('a');
  a.href = 'data:text/csv;charset=utf-8,' + encodeURIComponent(csv);
  a.download = 'cashtrack.csv';
  a.click();
}

Notice the prompt chain: first get the happy path, then add escaping, then add the Excel BOM. Each is a small, reviewable delta — never one giant request.

7. Persistence and finishing touches

Have Chat wire the checklist, one sentence per item, so you stay in control:

  • Store the array in localStorage under cashtrack.txns on every mutation (Chat also adds a load-on-start and a defensive JSON parse).
  • Add a totals strip (Income / Expense / Net) computed from the array.
  • Delete row button per transaction, with confirm() before removal.
  • Validation: empty description or amount ≤ 0 shows a friendly alert instead of pushing.
What you practiced: building a whole page from a single chat description, editing HTML/CSS/JS in place with inline chat, choosing the right chat surface, iterating on charts and CSV export via targeted prompts, and — the real skill — mentally mapping every AI output back onto the code before and after it merges.
