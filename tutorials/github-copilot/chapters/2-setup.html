Setup & Installation

Getting Copilot running takes about five minutes: install the official extension for your editor, sign in with your GitHub account, choose (or confirm) a plan, and type your first suggestion.

1. Install the extension

EditorExtension / pluginWhere to get it
Visual Studio CodeGitHub CopilotMarketplace — search "GitHub Copilot" or use the link in the docs
Visual StudioGitHub.Copilot.vsExtensions → Manage Extensions → search "GitHub Copilot"
JetBrains (IntelliJ, PyCharm, WebStorm, GoLand)GitHub Copilot pluginMarketplace / Settings → Plugins → search "GitHub Copilot"
Neovimgithub/copilot.vim:Copilot setup after adding the plugin
Two extensions in VS Code: install both GitHub Copilot (code completions) and, optionally, GitHub Copilot Chat (chat panel — it is bundled in newer versions, but if you do not see the chat icon, add it explicitly).

2. Sign in with your GitHub account

  1. Press Ctrl+Shift+P (or Cmd+Shift+P on macOS) and run GitHub Copilot: Sign In to GitHub.
  2. Your browser opens. Confirm the device code shown in the editor.
  3. If you have not chosen a plan yet, GitHub walks you through Copilot Free (or upgrading to Pro/Business). The free plan is enough for this course.
  4. Back in the editor you should see the Copilot status icon in the bottom-right corner showing an active state (usually a small dot or a checkmark).
Auth is per-machine identity + GitHub seat. You authenticate once per editor. Seats are managed under github.com/settings/copilot for individuals or in your organization for Business/Enterprise. If the status icon shows an error, first check that you are signed into the right GitHub account.

3. Pick a model (optional)

Newer versions of the extension let you choose the model that powers completions and chat:

  • Completions model — selectable in VS Code via the top "model" picker when a suggestion appears, or in settings.
  • Chat model — a dropdown at the top of the chat panel (e.g., Codex or other available models). Different tiers unlock more models.

You generally do not need to touch this; the default is a good, fast choice.

4. Key settings you should know

// VS Code settings.json (Ctrl+, → search "copilot", or edit directly)
{
  "github.copilot.enable": {
    "*": true,            // turn on for all languages
    "markdown": false     // ...but maybe leave docs files "manual"
  },
  "editor.inlineSuggest.enabled": true, // show ghost-text suggestions
  "github.copilot.editor.enableAutoCompletions": true,
  "github.copilot.chat.codeGeneration.instructions": [
    { "file": ".github/copilot-instructions.md" } // see Chapter 4
  ],
  "github.copilot.suggestions.enableCodeReferencing": true,
  "github.copilot.advanced.debug.useNodeForFetches": true
}

Use the command palette command GitHub Copilot: Enable/Disable Completions to toggle without touching settings, and the status icon to report issues.

5. Your first suggestion

Create a new file demo.py and type this, then hit Enter after the colon:

def is_palindrome(s: str) -> bool:
    # normalize to lowercase and remove non-alphanumeric characters, then compare

After a beat, grey ghost text should appear with the body of the function. Press Tab to accept it. If instead Copilot suggests the whole function without the comment, type a comment first — comments are one of the most reliable ways to steer completions.

Sanity check before you continue: open the Copilot status icon and run Report problem if something fails. Most setup issues are either (a) not signed in, (b) no plan/seat assigned, or (c) an outdated editor version.

6. What is new in Copilot Chat?

Copilot Chat ships continuously, so this section is a snapshot of what you will actually see in a modern editor. Expect the feature set to keep growing — the patterns here stay useful regardless:

  • Always-on chat panel with conversation history, copy/insert buttons, and slash-command autocomplete.
  • Model picker — choose which model powers your chat (some plans expose several; see Chapter 4).
  • Built-in agents like @workspace and @terminal, plus user-defined agents (Chapter 4).
  • Copilot Edits — multi-file, plan-then-apply edits that track a working set of files (Chapter 4).
  • Context chips and attachments — pin files, selections, or search results to a chat message explicitly.
  • Custom instructions support — repository-level guidelines loaded automatically (Chapter 4).
  • Inline chat improvements — apply/inline buttons that insert the result directly at the cursor.
