What is GitHub Copilot?

GitHub Copilot is an AI pair programmer: a service, plugged into your code editor, that suggests whole lines, functions, tests, and plain-text answers as you type. It was announced in June 2021 and shipped to general availability in 2022, and it runs on a family of large language models (originally OpenAI Codex, later GPT-4/4.1 and Codex variants, with model selection growing over time). Today it is one of the most widely used AI developer tools in the world.

Think of it as a teammate who is extremely fast, never sleeps, and always has an opinion about the next line of code — but who has never seen your project before 30 seconds ago. Your job as the developer is to review everything it suggests, just as you would review any pull request.

How does it actually work?

When you pause typing, the editor extension collects a prompt from your current context:

  • The current file around your cursor (before and after it).
  • The language and file path (so it knows it is a Python test, a React component, etc.).
  • Other open tabs and the selection, used as extra context when relevant.
  • Anything you type in Copilot Chat (prompts, selections, chat history).

That context is sent to GitHub's servers, a code model generates candidate completions, and the extension renders the top result as ghost text. Press Tab to accept. The loop is fast (typically well under a second for a line) and stateless on your machine — GitHub Copilot itself is a cloud service, not a local model.

The 80/20 rule: Copilot is at its best for boilerplate, repetitions, tests, regex, small pure functions, glue code, and translating an idea into a first draft. It is weakest at deep architectural decisions, novel algorithms nobody has written before, and anything that depends on invisible business rules.

What plans exist?

Pricing and limits change frequently, so always verify against github.com/settings/billing/summary and GitHub's docs. As a rule of thumb, Copilot ships in these tiers:

TierWho it is forTypical limits
Copilot FreeAnyone with a GitHub account, incl. studentsA monthly budget of code completions + chat messages (e.g. ~2,000 completions and 50 chat requests/month) and access to a limited model selection
ProIndividuals / freelancersUnlimited completions and chat in your editor, more (or premium) model choices, and extended limits
BusinessSmall teams under one GitHub organizationAll Pro features plus organization-wide policy, audit logs, and code-suggestion filtering
EnterpriseLarge companiesEverything in Business plus centralized policy, data controls, and premium support

There is also Copilot in the CLI (gh copilot) for terminal help, and the Copilot experience in the browser/mobile GitHub app.

Recommendation: since Copilot plugs into VS Code, JetBrains, Visual Studio, and Neovim and reuses your GitHub account, it is the lowest-friction default — but the principles in this course (context, reviewing, prompting) apply to any AI coding tool.

Why do developers recommend it?

Copilot is worth your time for a few well-documented reasons (evidence comes from marketplaces, surveys, and engineering blogs — always worth re-checking for yourself):

  • It ranks among the top extensions in its storefronts. In the VS Code Marketplace and the JetBrains Plugin Marketplace it consistently sits among the highest-rated and most-downloaded developer tools, which is a rare consensus signal for a paid product.
  • It takes the friction out of routine coding. Boilerplate, glue code, tests, and repetitive data-shaping are exactly where people report the biggest time savings.
  • It is a constant (free) reviewer. Used well, it imitates senior review: "have you handled the empty case?" — before your human reviewer even opens the PR.
  • Surveys report solid-but-honest gains. Team and academic studies (e.g., the GitHub–MIT productivity study) found meaningful speedups on common tasks, with the caveat that speed gains are smaller on complex, unfamiliar work and depend heavily on how you review output.
Balanced view: experienced pairs report the biggest wins come not from "more AI" but from better prompts and better review habits. That is exactly what the rest of this course trains you to do.

What Copilot is NOT

  • Not a replacement for understanding your code. It can write a bubble sort; it cannot know whether sorting is what your business logic requires.
  • Not authoritative on your private codebase unless you give it the context (open files, chat selection, or a query about your repo). It does not read your whole repository by default.
  • Not deterministic. Re-run the same prompt and you may get a different suggestion.
  • Not free of risk. Suggestions can be wrong, insecure, or — rarely — reminiscent of public code with restrictive licenses (more on this in Chapter 4).
✏️ Exercise: Open a small file you wrote recently and, from memory, write down: (a) which 20% of it was boring boilerplate, and (b) which 20% required real reasoning. That ratio tells you how much you could delegate to Copilot and how much you must keep for yourself.
