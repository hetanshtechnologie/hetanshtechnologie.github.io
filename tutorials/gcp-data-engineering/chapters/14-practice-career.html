14. Practice, Labs & Career Path

Chapter 14

Learning by Doing

Data engineering is an applied craft. This chapter gives you a realistic hands-on path using GCP's free tier and local tools, plus the certifications and career roadmap that turn skill into a job.

Cost safety: Set a monthly budget + alert on your project before you start. Prefer ephemeral Dataproc and Composer environments that you delete after lab sessions. Most labs in this book run on the free tier.

A 30-Day Practice Plan

  1. Days 1-5: GCP basics — project, IAM, gcloud; load a public dataset into BigQuery and run 10 queries with partitioning/clustering.
  2. Days 6-10: BigQuery optimization — dry runs, partitioning, clustering, INFORMATION_SCHEMA cost queries, time travel, a simple BQML model.
  3. Days 11-15: Python + GCS — write a loader script, upload data, load into BigQuery idempotently, add pytest tests.
  4. Days 16-20: PySpark on Dataproc — run a real job (read GCS → transform → BigQuery), tune partitions, test locally.
  5. Days 21-25: Airflow + Composer — build the wait/load/transform/quality/notify DAG and backfill two days.
  6. Days 26-28: dbt — staging + incremental fact + tests + snapshots; run dbt build from Composer.
  7. Days 29-30: Migration exercise — write the AWS-to-GCP mapping and a fake migration plan; document everything in a portfolio repo.

Portfolio Project Ideas

  • eCommerce analytics pipeline: synthetic orders → GCS → BigQuery → dbt models → dashboard. Measure your cost per query and document optimizations.
  • COVID / weather / public-data project: load a public dataset, model it with dbt, schedule with Composer, serve with a Looker Studio dashboard.
  • Log analytics pipeline: streaming events via Pub/Sub → Dataflow/BigQuery → real-time dashboard.
  • Migration playbook repo: documented service mappings, SQL translation cheat-sheets, and a sample Redshift→BigQuery migration.

Career Roadmap

  • Phase 0 - Foundations (0-1 yr): SQL, Python, Linux, basic cloud; build the lab.
  • Phase 1 - Junior Data Engineer (1-3 yr): maintain pipelines, write SQL/Python, learn BigQuery + Airflow, fix incidents, learn dbt.
  • Phase 2 - Data Engineer (3-5 yr): design pipelines and schemas, own orchestration, lead dbt projects, handle Spark workloads, cost optimization.
  • Phase 3 - Senior / Staff Data Engineer: architect platforms, data governance, migrations, mentor juniors, own reliability and SLAs.
  • Phase 4 - Principal / Architect: org-wide data strategy, platform vision, budget, standards.

Interview Preparation

  • Be ready to write SQL with window functions and aggregations on a whiteboard.
  • Know BigQuery specifics: partitioning vs clustering, cost model, time travel, INFORMATION_SCHEMA.
  • Be able to design a pipeline on a whiteboard: sources → storage → transform → serving, with idempotency and quality gates.
  • Explain orchestration: DAG, catchup, data interval, retries, sensors.
  • Explain when you'd use BigQuery vs Dataproc vs Dataflow.
  • Describe a migration (or the mapping) at an abstract level: phases, risks, reconciliation.
  • Quantify achievements: "reduced pipeline cost 40% by partitioning and incremental models", "cut MTTR for pipeline failures from 2h to 20min".

Ethics and Responsibility

  • Respect data privacy and residency; never move regulated data without approval.
  • Keep credentials secure; never commit secrets.
  • Design for correctness: idempotent pipelines, tested transformations, honest metrics.
  • Document decisions and be transparent about data lineage.

Keeping Current

  • Follow Google Cloud blog (BigQuery, Dataproc, Composer release notes).
  • Join the dbt community and Analytics Engineering meetups.
  • Track open-source: Iceberg/Delta/Hudi, Airflow, dbt-utils releases.
  • Practice on public datasets regularly — skill decays without use.
Final Practice Task: Write a one-page "Data Engineer Portfolio Plan": the lab you will build this quarter, the two pipelines you will complete, the certifications you will target (with dates), and one measurable goal per month. Then start Day 1 of the 30-day plan. Revisit the plan monthly and update it as you grow.
