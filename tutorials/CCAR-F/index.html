Claude Certified Architect (CCAR-F)

A practical study guide for agentic system design, tool design, Claude Code, prompting, and context management

This book is an independent study companion built from a published certification syllabus. It reorganises the syllabus into a learning path, explains every topic in original language, and adds worked examples, design trade-offs, exercises, and review questions. It is not an official certification guide and is not affiliated with or endorsed by any certification provider or vendor.

Copyright and originality. Every sentence in this book is original. Chapter titles are paraphrased; no lecture title, course description, or syllabus text is reproduced verbatim. No lecture durations, instructor names, or course materials are included. Product names, framework names, and certification codes are used only as descriptive factual identifiers. Trademarks belong to their respective owners. If you adapt this book for publication, keep this notice and add your own source attributions.

How to read this book

  • Parts I–II build the architectural core: what agents are, how they loop, how work is decomposed, and how failures are contained.
  • Part III covers tool contracts and the Model Context Protocol, from schema design to production deployment.
  • Part IV turns to Claude Code as a working environment: configuration, commands, skills, hooks, and automation.
  • Part V develops prompt design and structured-output discipline.
  • Part VI addresses context as an engineering resource: memory, compaction, confidence, and provenance.
  • Part VII prepares you for the exam with a study plan and two original practice papers.

The original syllabus is arranged by exam domain. This book intentionally rearranges the sequence so that ideas are introduced before they are needed. A concept that appears early in a chapter may be revisited later in a different context — that repetition is deliberate.
