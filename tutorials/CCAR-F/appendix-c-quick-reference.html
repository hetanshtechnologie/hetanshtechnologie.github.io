Appendix C — Exam-Day Quick Reference

This appendix compresses the book into decision tables and distinctions. Skim it the night before and again on the morning of the exam. It is a reminder of principles, not a substitute for understanding them.

High-value distinctions

QuestionOne sideOther sideKey discriminator
Agent or workflow?Agent: model chooses next stepWorkflow: code chooses next stepDoes the path genuinely vary per request?
Stop or budget?Stop: goal achievedBudget: resources exhaustedOne is success; the other is a bound.
Tool or resource?Tool: actionResource: readable dataDoes it change state or just expose it?
Schema or validation?Schema: shapeValidation: truthValid JSON can still contain a wrong value.
In-context or external?In-context: fast, volatileExternal: durable, explicitMust it survive a restart?
Prompt or enforcement?Prompt: guidanceEnforcement: denial in codeIs the action irreversible?
Confidence or calibration?Confidence: a numberCalibration: number matches realityHas it been checked on outcomes?
Summary or fact block?Summary: lossy proseFact block: preserved valuesAre exact identifiers essential?
Retry or fix?Retry: repeatFix: make safe or correct firstIs the operation idempotent?
Random or stratified?Random: represents majorityStratified: represents slicesIs the severe case rare?

Scenario-answer method in four lines

  1. Name the failure or risk in one sentence.
  2. Locate the owning boundary: model, tool, orchestrator, harness, or human.
  3. Choose the cheapest control that genuinely fixes the root cause.
  4. Keep a trace, a version, and a reason for the decision.

Options to treat with suspicion

  • "Add more detail to the prompt" when a code-level gate is required.
  • "Add another agent" when a branch would settle the decision.
  • "Retry unconditionally" when the operation may duplicate an effect.
  • "Increase the context window" when the real problem is bloat.
  • "Summarise more" when exact facts are being lost.
  • "Use a stronger model" when evidence is missing from context.
  • "Trust the confidence score" without calibration evidence.
  • "Pick the more confident wording" when sources disagree.
  • "Give every agent every tool" for convenience.
  • "Measure only final accuracy" when retrieval could be the problem.

Last-minute recall prompts

  • State three reasons a workflow beats an agent.
  • List five fields in a handoff payload.
  • Explain why a schema is not a truth check.
  • Name four properties of a useful tool description.
  • Describe the difference between stop conditions and budgets.
  • Explain why summaries lose facts.
  • List the filter–reference–summarise order and why it matters.
  • State what least privilege means for tool scoping.
  • Explain why stratified sampling is used for rare failures.
  • Describe what a claim-to-source mapping proves.
Exercise C.1 — Two-minute drill. Set a timer for two minutes and answer the first five recall prompts aloud. Repeat with the second five.
Exercise C.2 — Wrong-option hunt. For each suspicious option above, write one sentence explaining what correct control it is trying to imitate.
