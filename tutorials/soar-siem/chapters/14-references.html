SOAR & SIEM Cheatsheet

ConceptQuick Reference
SIEMSecurity Information and Event Management — centralized log analytics, correlation, alerting
SOARSecurity Orchestration, Automation, and Response — connects tools, automates tasks, manages cases
SOCSecurity Operations Center — the team/process layer that runs detection and response
MTTDMean Time to Detect — attack start to detection
MTTAMean Time to Acknowledge — alert to analyst engagement
MTTRMean Time to Respond/Resolve — detection to containment/resolution
EPSEvents Per Second — the standard SIEM throughput unit
Use caseA plain-language statement of what you want to detect and why
Correlation ruleA detection pattern that produces an alert when matched
SigmaPortable, open-source detection rule format convertible to many SIEM languages
Detection as codeManaging detection rules in git with CI testing and version control
PlaybookExecutable automation of an incident-response procedure
RunbookHuman-readable incident-response documentation
ArtifactA discrete piece of evidence from an alert (IP, hash, domain, user)
ConnectorA SOAR integration exposing actions to call an external tool
IOCIndicator of Compromise — IP, domain, hash, etc. tied to malicious activity
STIXStructured Threat Information Expression — JSON format for threat data
TAXIITransport protocol for exchanging STIX intelligence
UEBAUser and Entity Behavior Analytics — ML-based baseline deviation detection
XDRExtended Detection and Response — cross-domain detection and automated response
MITRE ATT&CKAdversary tactics and techniques knowledge base
FP / TPFalse Positive (benign, matched) / True Positive (real malicious)
Automation rate% of alerts handled without human intervention
Blast radiusThe potential damage if an automated action fails or misfires

Glossary

CEFCommon Event Format — key=value event encoding used across vendors
CSPMCloud Security Posture Management — detects cloud misconfigurations
EnrichmentAdding context (reputation, geo, asset info) to an alert or artifact
False PositiveAn alert that fired but represents benign activity

Useful Resources

  • Frameworks: MITRE ATT&CK (attack.mitre.org), NIST SP 800-61 Incident Handling Guide, NIST Cybersecurity Framework.
  • Detection: SigmaHQ/sigma, Atomic Red Team, MITRE ATT&CK Navigator, Sigma conversion tools (pySigma, uncoder.io).
  • Learning platforms: TryHackMe, LetsDefend, CyberDefenders, Blue Team Labs Online, DetectionLab.
  • Open-source tools: Elastic Security, Wazuh, Shuffle, TheHive + Cortex, dfir-iris, MISP, OpenCTI.
  • Vendor docs: Microsoft Sentinel (Ninja training, free tier), Splunk e-learning, XSOAR docs, Palo Alto Cortex documentation.
  • Communities: Detection Engineering community, r/securityoperations, ISSA/OWASP chapters, DEF CON Blue Team Village.

Key Industry Reports & Reading

  • Gartner Market Guides for SIEM and SOAR (updated annually).

  • Microsoft Digital Defense Report — threat landscape and trends.
  • MITRE ATT&CK evaluations — detection capability benchmarks.
  • SANS SOC survey reports — team structure and tooling benchmarks.

You now understand how the SOC operates, how a SIEM turns raw logs into detections, how a SOAR turns detections into orchestrated response, and how they integrate to shrink MTTD, MTTA, and MTTR. Final Challenge

Build the complete closed loop once more, from scratch, in your lab: generate telemetry → detect with a rule → push to SOAR → enrich with intel → take an automated action → document the case → report the metrics. If you can repeat that loop reliably, you are ready to be productive in a modern SOC.
