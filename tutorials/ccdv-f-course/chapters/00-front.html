Claude Certified Developer — Foundations (CCDV-F) Course

An independent, original course companion

This book is a self-contained course companion for a foundations-level certification on designing and building applications with a large-language-model assistant, its API, and its developer tooling. It is written to be read cover to cover, used as a reference during revision, and printed or exported as a PDF.

Important: This is an independent, original study guide. It is not affiliated with, sponsored by, endorsed by, or approved by any certification body, cloud provider, or AI vendor. It does not reproduce, summarize, or replace any paid course, lecture recording, or official training material. Every chapter was written from first principles for this project. The exam code used in the title is used descriptively; no official status is claimed.

How this book is organized

The material has been deliberately arranged in a different order from typical lecture lists, so that ideas build on one another:

Part Chapters What you will be able to do
I — Orientation 1–3 Understand the exam, the platform, and how to read the code
II — Requests and Applications 4–7 Build requests, applications, requirements, and evaluations
III — Data in Motion 8–9 Stream responses and choose a hosting path
IV — Prompts and Output 10–12 Write instructions and consume structured output safely
V — Tools and Connectors 13–16 Connect the model to actions and reusable capabilities
VI — Agents and Workflows 17–20 Choose a shape and build a reliable agent loop
VII — Models and Cost 21–24 Pick models and control tokens, spend, and caching
VIII — Tooling and Configuration 25–26 Work in a repository and configure an assistant
IX — Quality and Security 27–29 Diagnose failures and defend against attacks
X — Exam Readiness 30 Consolidate with simulators and a quick reference

How to use each chapter

Each chapter follows the same rhythm:

  1. Learning objectives tell you what should be different after reading.
  2. Key concepts carry the explanation, with tables and code where useful.
  3. Practice lab gives you a small hands-on exercise to try in a scratch project.
  4. Worked scenario models the reasoning an exam question is testing.
  5. Common mistakes flags the traps that appear in distractor options.
  6. Chapter summary gives you a revision sheet.
  7. Checkpoint questions let you test yourself immediately; every answer has a rationale, including why the other options are wrong.

A suggested approach: read the objectives, skim the summary, read the chapter, then answer the checkpoint questions without looking at the answers. Write down any option you got wrong and revisit it the next day.

Exam preparation plan

A realistic eight-week plan for a working developer:

Week Focus Chapters
1 Orientation and how models work 1–3
2 Requests, applications, and evaluations 4–6
3 Data, prompts, and output 7–12
4 Tools and connectors 13–16
5 Agents and workflows 17–20
6 Models, cost, and tooling 21–26
7 Quality, security, and distinctions 27–30
8 Simulators, review, and rest 30

If you have less time, prioritize Chapters 4, 6, 10, 12, 13, 17, 21, 27, and 29. Those topics generate the largest share of scenario questions.

Conventions used in this book

  • Exam note — a fact that is frequently tested.
  • Common mistake — a wrong answer that looks plausible.
  • Try it — a small exercise you can perform in a scratch project.
  • Code blocks use Python, JSON, bash, or plain text, and are illustrative; they are not meant to be copied into production unchanged.
  • Where a vendor option is discussed, the principle is stated first and the product name second. The exam rewards principle-level reasoning.

A note on scope

A foundations exam tests judgment: which shape of solution fits the constraint you were given, and what trade-off you are accepting. It does not reward memorizing product trivia. When two answers both sound reasonable, ask yourself which one actually satisfies every constraint in the scenario, especially the constraints about safety, cost, and reliability. That habit is the single most useful preparation strategy this book can offer.
