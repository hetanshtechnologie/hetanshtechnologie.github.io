6. Data Visualization

Chapter 6

Why Visualization is a Core Skill

A good chart compresses thousands of rows into one clear story. Visualization is used for exploration (finding patterns yourself) and communication (convincing others). The best charts are honest and simple: they reveal the data, not the tooling.

Chart Selection Guide

What you want to showBest chart
Distribution of one numeric variableHistogram, box plot, violin plot, KDE
Counts of a categoryBar chart (ordered)
Change over timeLine chart
Relationship between two numericsScatter plot (add regression line)
Numeric vs categorical (compare groups)Box plot, violin plot, bar of means
Part of a wholeStacked bar (avoid pie > 5 slices)
Two categoricalsHeatmap of counts / stacked bars
Correlation matrixCorrelation heatmap
Geographic dataChoropleth / scatter on map

matplotlib Basics

import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_parquet("data/clean/customers.parquet")

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(df["month"], df["revenue"], marker="o", linewidth=2)
ax.set_title("Monthly Revenue")
ax.set_xlabel("Month")
ax.set_ylabel("Revenue (₹)")
ax.grid(alpha=0.3)
plt.tight_layout()
plt.show()
Style tip: set a consistent style once for the notebook so every chart shares the same fonts and palette: 
plt.rcParams.update({
    "figure.dpi": 120,
    "axes.grid": True,
    "grid.alpha": 0.3,
    "font.size": 11
})

seaborn for Statistical Charts

seaborn sits on matplotlib and makes statistical charts one line:

import seaborn as sns

# Distribution
sns.histplot(df["spend"], kde=True)

# Relationship by group
sns.scatterplot(x="age", y="spend", hue="plan", data=df)

# Compare groups
sns.boxplot(x="plan", y="spend", data=df)

# Correlation heatmap
sns.heatmap(df.select_dtypes("number").corr(), annot=True, cmap="RdBu_r")

interactive with plotly

For dashboards and exploration, interactive charts (hover, zoom, filter) add a lot:

import plotly.express as px

fig = px.scatter(df, x="age", y="spend", color="plan",
                 title="Spend by age and plan")
fig.show()

# Animated line over time
px.line(df, x="month", y="revenue", color="plan")

Design Principles

  • Label everything. Title, axes, units, and legend must be self-explanatory.
  • Start axes at zero unless there is a reason not to — and if you truncate, say so.
  • Order bars by value; sort categorical bars so the eye reads the pattern fast.
  • Limit colors. Use one accent color against neutrals; never rely on color alone (accessibility).
  • Avoid pie charts for many categories — humans judge areas poorly.
  • Remove clutter: unnecessary gridlines, borders, and 3D effects hide the data.
  • Honesty: never cherry-pick time ranges, drop outliers silently, or use a misleading axis.
Common deception: a truncated y-axis can make a 2% change look like a 100% change. In your own charts, let the scale tell the truth; when reading others' charts, check the axis first.

Dashboards & Reports

Beyond notebooks, dashboards share insights with stakeholders:

  • Streamlit — build data apps in pure Python (recommended starting point).
  • Panel / Dash — flexible Python dashboards.
  • Metabase / Superset — SQL-first BI tools.
  • Looker Studio — free Google BI with BigQuery integration.
