Where Data Comes From

Every project starts with getting data into a form you can analyze. Common sources:

SourceExamplesTypical Format
Flat filesCSV, Excel, JSON, Parquet, log filesFiles on disk or in cloud storage
DatabasesPostgreSQL, MySQL, SQLite, warehousesSQL queries
APIsREST/GraphQL endpoints, public datasetsJSON/XML over HTTP
WebPublic pages, review sitesHTML (scraped)
StreamingClickstreams, IoT, financial feedsEvent streams (Kafka, WebSockets)
Surveys/experimentsQuestionnaires, lab logsStructured tables

Reading Flat Files with pandas

import pandas as pd

# CSV
df = pd.read_csv("data/sales.csv")

# Excel (needs openpyxl: pip install openpyxl)
df = pd.read_excel("data/sales.xlsx", sheet_name="2025")

# JSON
df = pd.read_json("data/events.json")

# Parquet (fast columnar, pip install pyarrow)
df = pd.read_parquet("data/events.parquet")

# Inspect what you got
print(df.shape)      # (rows, columns)
print(df.head())
print(df.dtypes)
Always inspect before assuming: print df.shape and df.dtypes immediately. Files often contain extra header rows, encoding surprises, or unexpected delimiters. Use sep=";", encoding="utf-8-sig", or skiprows=2 as needed.

Querying Databases

import sqlite3
import pandas as pd

conn = sqlite3.connect("data/app.db")
df = pd.read_sql_query("SELECT * FROM orders WHERE created_at > '2025-01-01'", conn)
conn.close()

For PostgreSQL and other servers, use connection strings and a driver such as psycopg2 or SQLAlchemy. SQL itself is covered in depth in Chapter 9 — this chapter focuses on getting the data out.

Never put credentials in code. Use environment variables or a secrets manager: 
import os
DATABASE_URL = os.environ["DATABASE_URL"]

Fetching Data from APIs

Many services expose data over HTTP. The requests library makes calls easy:

import requests

resp = requests.get(
    "https://api.open-meteo.com/v1/forecast",
    params={"latitude": 21.17, "longitude": 72.83, "hourly": "temperature_2m"}
)
resp.raise_for_status()          # raise on HTTP errors
data = resp.json()               # parsed JSON
df = pd.DataFrame(data["hourly"])

Public dataset catalogs you can start with:

  • Kaggle Datasets — kaggle.com/datasets (requires free account)
  • UCI Machine Learning Repository — archive.ics.uci.edu
  • Google Dataset Search — datasetsearch.research.google.com
  • Awesome Public Datasets — github.com/awesomedata/awesome-public-datasets
  • Open-Meteo / OpenWeatherMap — free weather APIs
  • Government open data — e.g., data.gov.in, data.gov
Respect the API: read the terms of service, use authentication tokens when required, and be polite with rate limits (a time.sleep(0.5) between calls is common). Public APIs are shared infrastructure.

Web Scraping (Carefully)

When no API exists, scraping can collect public data:

from bs4 import BeautifulSoup
import requests

resp = requests.get("https://example.com/reviews")
soup = BeautifulSoup(resp.text, "html.parser")

titles = [el.text.strip() for el in soup.select("h2.review-title")]
print(titles[:5])
Scraping ethics: only scrape data you have permission to use. Check the site's terms, robots.txt, and the jurisdiction's data laws. Never scrape login-walled or personal data. For practice, prefer datasets or well-documented APIs.

Data Provenance & Documentation

Record where each dataset came from, when you downloaded it, its version, and its license. This matters for reproducibility and for legal/ethical use of the data.

# A tiny data source note you can keep beside your data
# Source: Open-Meteo archive (CC-BY-4.0)
# Downloaded: 2026-08-15
# Columns: time (ISO8601), temperature_2m (degC), humidity (percent)
Practice Task: Choose two sources from different categories (e.g., an API and a CSV dataset). Load both into pandas, save each to data/raw/, and write a short sources.md documenting provenance and license. Verify with df.info() that column types look sane.
