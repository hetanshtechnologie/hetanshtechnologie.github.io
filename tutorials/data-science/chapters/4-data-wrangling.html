4. Data Wrangling & Cleaning

Chapter 4

Why Cleaning Takes Most of Your Time

Real data is messy: missing values, inconsistent formats, duplicates, outliers, and impossible values. Practitioners commonly spend 60–80% of a project cleaning and preparing data. This chapter gives you a repeatable checklist.

The Wrangling Checklist

  1. Look at the shape and types (df.info()).
  2. Check for missing values (df.isna().sum()).
  3. Remove or fix duplicates (df.duplicated()).
  4. Standardize formats (dates, strings, categoricals).
  5. Handle outliers and impossible values.
  6. Engineer the columns you need (Ch. 15).

First Look

import pandas as pd
df = pd.read_csv("data/customers.csv")

df.info()                    # columns, non-null counts, dtypes
df.isna().sum()              # missing values per column
df.nunique()                 # distinct values per column
df.duplicated().sum()        # duplicate rows

Handling Missing Values

Missingness matters: why a value is missing changes what you should do.

TypeMeaningCommon Strategy
Missing at randomUnrelated to the value itselfDrop rows or impute
Missing systematicallyRelated to the value (rich people don't answer income)Add an "is missing" flag; model separately
Not applicableAbsence has meaning (no phone = no mobile)Fill with a sentinel like "none"
# How much is missing
missing = df.isna().sum()
print(missing[missing > 0])

# Drop rows missing a critical column
df = df.dropna(subset=["customer_id"])

# Impute numeric columns with the median (robust to outliers)
for col in ["income", "age"]:
    df[col] = df[col].fillna(df[col].median())

# Impute categorical columns with the mode
df["city"] = df["city"].fillna(df["city"].mode()[0])
Do not impute blindly: imputation adds information you invented. For machine learning, a principled approach is to keep missingness and model it (a missing-value indicator column, or a model that handles NaN natively such as many tree models).

Duplicates

# Show duplicate rows
print(df[df.duplicated()])

# Drop exact duplicates
df = df.drop_duplicates()

# Drop duplicates on a key column, keeping the latest
df = df.sort_values("created_at").drop_duplicates(subset=["customer_id"], keep="last")
Duplicates are not always bad: in transactional data, two identical rows may be legitimate (two identical purchases). Only dedupe when the rows truly represent the same entity.

Types, Dates & Strings

# Convert to proper types
df["price"] = pd.to_numeric(df["price"], errors="coerce")
df["joined"] = pd.to_datetime(df["joined"], errors="coerce")

# Clean strings
df["city"] = (df["city"]
              .str.strip()            # trim whitespace
              .str.lower()            # normalize case
              .str.replace(r"\s+", "_", regex=True))

# Fix inconsistent categorical values
mapping = {"M": "Male", "F": "Female", "m": "Male", "f": "Female", "O": "Other"}
df["gender"] = df["gender"].map(mapping)

# Extract date parts
df["year"] = df["joined"].dt.year
df["weekday"] = df["joined"].dt.day_name()

Outliers & Impossible Values

First decide whether a value is an error or an extreme but real observation. A salary of ₹1,00,00,000 may be real; an age of 250 is impossible.

# Summary statistics expose impossibilities
print(df.describe())

# Flag impossible values
df.loc[df["age"] > 120, "age"] = pd.NA

# The IQR rule — a rough outlier screen (not a definition of "bad")
q1, q3 = df["spend"].quantile([0.25, 0.75])
iqr = q3 - q1
outside = (df["spend"] < q1 - 1.5 * iqr) | (df["spend"] > q3 + 1.5 * iqr)
print(df.loc[outside, "spend"])
Never silently delete outliers. An outlier often marks a data error, a segment worth studying, or a fraud signal. Investigate before you drop, and document the decision.

Normalization & Encoding

Numeric features on different scales distort distance-based algorithms and can slow training.

from sklearn.preprocessing import StandardScaler, MinMaxScaler

# Standardize to mean 0, std 1 (default for many models)
scaler = StandardScaler()
df[["income", "age"]] = scaler.fit_transform(df[["income", "age"]])

# Min-max scale to [0,1]
df[["income", "age"]] = MinMaxScaler().fit_transform(df[["income", "age"]])

Categorical features must be converted to numbers for most algorithms:

# One-hot encoding: city -> city_mumbai, city_delhi, ...
df = pd.get_dummies(df, columns=["city"], prefix="city")

# Ordinal encoding for ordered categories
from sklearn.preprocessing import OrdinalEncoder
df["education"] = OrdinalEncoder().fit_transform(df[["education"]])

Save Clean Data Separately

Keep raw data untouched and write the cleaned version to a new file. This preserves provenance and lets you re-run cleaning when you improve your logic.

df.to_parquet("data/clean/customers.parquet")
# or df.to_csv("data/clean/customers.csv", index=False)
