8. Hypothesis Testing & A/B Testing

Chapter 8

From Question to Hypothesis

A hypothesis test answers: "Is the difference I see in my sample real, or could it be chance?" The machinery:

  • Null hypothesis (H₀): no effect — e.g., "the new checkout converts at the same rate as the old one."
  • Alternative hypothesis (H₁): there is an effect — "the new checkout converts at a different rate."
  • Test statistic: a number computed from the data whose distribution under H₀ is known.
  • p-value: the probability of seeing a statistic at least as extreme as yours, if H₀ were true.

If the p-value is small (below your threshold, usually 0.05), you reject H₀ — the data are unlikely under "no effect," so you act as if there is an effect.

p-value myths: the p-value is not the probability that H₀ is true, and it is not the probability that you made a mistake. It is purely conditional on H₀. "Statistically significant" says nothing about practical importance — a tiny effect can be "significant" with a large sample.

Type I and Type II Errors

  • α = probability of Type I error (significance level, commonly 0.05).
  • β = probability of Type II error; power = 1 − β.

A t-test in Python

from scipy import stats
import numpy as np

# Two independent samples
new = np.random.normal(loc=3.2, scale=1.1, size=200)
old = np.random.normal(loc=3.0, scale=1.1, size=200)

t_stat, p_value = stats.ttest_ind(new, old, equal_var=False)
print(f"t = {t_stat:.3f}, p = {p_value:.4f}")
# p < 0.05 -> reject H0: the means differ

A/B Testing in Practice

An A/B test is just a hypothesis test run on a real system: randomly split users into a control (old version) and treatment (new version), measure a key metric, and compare.

Design checklist:

  1. Choose one primary metric (e.g., conversion rate). Pre-decide it before the test.
  2. Randomize at the user level (not the session level — sessions are not independent).
  3. Run a power analysis to size the experiment before starting.
  4. Run to completion. Never stop early because results "look done" — early stopping inflates false positives.
  5. Watch for peeking and repeated testing — every look uses up your error budget.
  6. Check for interference between groups and novelty effects.
# Power analysis to size an A/B test (conversion-rate example)
from statsmodels.stats.power import TTestIndPower

# Baseline 10% -> treatment 12%, alpha 0.05, power 0.8
effect = abs(0.12 - 0.10) / np.sqrt(0.10 * 0.90)
n = TTestIndPower().solve_power(effect_size=effect,
                                alpha=0.05, power=0.8)
print(f"per group ~{int(n)} users")
Bootstrap as a robust alternative: when you doubt normality assumptions, you can bootstrap the difference of means and read the confidence interval directly — no formulas required: 
rng = np.random.default_rng(42)
diffs = []
for _ in range(2000):
    s1 = rng.choice(new, size=len(new), replace=True)
    s2 = rng.choice(old, size=len(old), replace=True)
    diffs.append(s1.mean() - s2.mean())
lo, hi = np.percentile(diffs, [2.5, 97.5])
print(f"95% bootstrap CI of difference: ({lo:.3f}, {hi:.3f})")
If the interval excludes zero, the difference is real.

Multiple Comparisons

If you test 20 hypotheses at α = 0.05, you expect about 1 false positive by chance. Corrections control this:

  • Bonferroni: divide α by the number of tests (simple, conservative).
  • Benjamini-Hochberg (FDR): controls the expected fraction of false discoveries — standard in modern practice.
