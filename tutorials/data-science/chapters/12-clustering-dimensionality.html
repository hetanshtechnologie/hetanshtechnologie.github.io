12. Clustering & Dimensionality Reduction

Chapter 12

Unsupervised Learning

Without labels, we look for structure: groups of similar customers, low-dimensional views of high-dimensional data, or anomalies. Clustering and dimensionality reduction are the two workhorses.

K-Means Clustering

from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

X = StandardScaler().fit_transform(df[["spend", "tenure", "support_tickets"]])

model = KMeans(n_clusters=4, n_init=10, random_state=42)
df["cluster"] = model.fit_predict(X)

# Profile the segments
print(df.groupby("cluster")[["spend", "tenure", "support_tickets"]].mean())
Scale before clustering: k-means minimizes Euclidean distance, so a variable measured in rupees dominates one measured in years. Always standardize continuous features first.

Choosing the Number of Clusters

k-means needs k up front. Heuristics:

  • Elbow method: plot inertia vs k; pick the "elbow" where gains flatten.
  • Silhouette score: measure how tight clusters are vs how far apart they are; higher is better.
  • Domain sense: clusters must map to actionable segments — 4 clear business segments beat 12 statistically optimal ones.
from sklearn.metrics import silhouette_score

for k in range(2, 9):
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    labels = km.fit_predict(X)
    print(k, round(silhouette_score(X, labels), 3))

Hierarchical Clustering

Agglomerative clustering builds a tree (dendrogram) of nested clusters. It needs no k in advance and gives interpretable structure — great for taxonomies and small-to-medium data.

from scipy.cluster.hierarchy import linkage, fcluster, dendrogram
import matplotlib.pyplot as plt

Z = linkage(X, method="ward")
dendrogram(Z, truncate_mode="level", p=5)
plt.title("Dendrogram")
plt.show()

DBSCAN (Density-Based)

DBSCAN finds clusters as dense regions separated by sparse ones. It does not force every point into a cluster — points in low-density areas become noise. That makes it ideal when data has outliers or arbitrary shapes.

from sklearn.cluster import DBSCAN

db = DBSCAN(eps=0.5, min_samples=5)
labels = db.fit_predict(X)         # -1 means "noise"
df["cluster"] = labels
print(df["cluster"].value_counts())

Dimensionality Reduction: PCA

Principal Component Analysis projects data onto the directions of greatest variance, reducing the number of columns while keeping most of the information.

from sklearn.decomposition import PCA

pca = PCA(n_components=2)
X2d = pca.fit_transform(X)
print(pca.explained_variance_ratio_.sum())   # variance kept by 2 components

Uses: denoising, visualization of high-dimensional data, and speed. Caution: principal components are combinations of features and are not directly interpretable in business terms.

Embeddings & Modern Representations

Beyond PCA, modern tools learn dense vector representations:

  • Text embeddings (e.g., from sentence-transformers) map words/sentences to vectors so similarity becomes distance — used for search, clustering documents, and topic discovery.
  • t-SNE / UMAP produce striking 2D visualizations of high-dimensional structure (great for exploration, less good for clustering decisions).
# UMAP for exploration visualization
# pip install umap-learn
import umap
embedding = umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=42).fit_transform(X)

Segment Validation

Clusters are only useful if they differ in ways you can act on. Validate with:

  • Distribution plots comparing clusters on key metrics.
  • Stability: re-run with different seeds/params — do the segments persist?
  • Business check: can you name each cluster and suggest a strategy for it?
Practice Task: Cluster your customers (or another natural unit) with k-means. Choose k with the elbow and silhouette methods, profile each segment, and give each a memorable business name and a one-line strategy. Then use DBSCAN on the same data and compare which points are treated as noise. Finally, visualize the segments with PCA or UMAP.
