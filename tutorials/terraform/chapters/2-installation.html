Chapter 2: Terraform Installation & Setup

2.1 Installation Options

Terraform is distributed as a single binary. You can install it via package managers, direct download, or use Terraform Cloud.

Option 1: Direct Download (All Platforms)

# Download from https://developer.hashicorp.com/terraform/install
# Or use the CLI:

# Windows (PowerShell)
Invoke-WebRequest -Uri "https://releases.hashicorp.com/terraform/1.9.8/terraform_1.9.8_windows_amd64.zip" -OutFile "terraform.zip"
Expand-Archive -Path "terraform.zip" -DestinationPath "$env:USERPROFILE\AppData\Local\Microsoft\WindowsApps"
terraform version

# Linux (x64)
curl -fsSL https://releases.hashicorp.com/terraform/1.9.8/terraform_1.9.8_linux_amd64.zip -o terraform.zip
unzip terraform.zip
sudo mv terraform /usr/local/bin/
terraform version

# macOS (Apple Silicon)
curl -fsSL https://releases.hashicorp.com/terraform/1.9.8/terraform_1.9.8_darwin_arm64.zip -o terraform.zip
unzip terraform.zip
sudo mv terraform /usr/local/bin/
terraform version

Option 2: Package Managers

# Windows (Chocolatey)
choco install terraform

# Windows (winget)
winget install HashiCorp.Terraform

# macOS (Homebrew)
brew tap hashicorp/tap
brew install hashicorp/tap/terraform

# Ubuntu/Debian
wget -O- https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt update && sudo apt install terraform

# RHEL/CentOS
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://rpm.releases.hashicorp.com/RHEL/hashicorp.repo
sudo yum install terraform

# Alpine
apk add --no-cache terraform

Option 3: Terraform Version Manager (tfenv)

# Install tfenv (like nvm but for Terraform)
git clone https://github.com/tfutils/tfenv.git ~/.tfenv
echo 'export PATH="$HOME/.tfenv/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

# Install and use specific versions
tfenv install 1.9.8
tfenv install latest
tfenv use 1.9.8
terraform version

# Check version
terraform version

2.4 Project Structure

Recommended Terraform Project Structure: my-infra/ ├── main.tf # Primary resource definitions ├── variables.tf # Input variable declarations ├── outputs.tf # Output value declarations ├── providers.tf # Provider configuration and versions ├── backend.tf # Remote state backend configuration ├── versions.tf # Required provider versions ├── terraform.tfvars # Variable values (DO NOT commit secrets) ├── .gitignore # Ignore .terraform/, *.tfstate ├── modules/ # Reusable modules │ ├── networking/ │ │ ├── main.tf │ │ ├── variables.tf │ │ └── outputs.tf │ ├── compute/ │ └── database/ ├── environments/ # Per-environment configs │ ├── dev/ │ │ ├── main.tf │ │ ├── terraform.tfvars │ │ └── backend.tf │ ├── staging/ │ └── prod/ └── README.md

2.5 First Terraform Configuration

# providers.tf — Lock provider versions
terraform {
  required_version = ">= 1.5.0"

  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "~> 3.85"
    }
    random = {
      source  = "hashicorp/random"
      version = "~> 3.6"
    }
  }
}

provider "azurerm" {
  features {}
  subscription_id = var.subscription_id
}

# variables.tf
variable "subscription_id" {
  description = "Azure subscription ID"
  type        = string
}

variable "resource_group_name" {
  description = "Name of the resource group"
  type        = string
  default     = "rg-terraform-demo"
}

variable "location" {
  description = "Azure region"
  type        = string
  default     = "East US"
}

# main.tf — Create a resource group and storage account
resource "azurerm_resource_group" "demo" {
  name     = var.resource_group_name
  location = var.location

  tags = {
    Environment = "demo"
    ManagedBy   = "terraform"
  }
}

resource "random_string" "suffix" {
  length  = 8
  special = false
  upper   = false
}

resource "azurerm_storage_account" "demo" {
  name                     = "st${random_string.suffix.result}"
  resource_group_name      = azurerm_resource_group.demo.name
  location                 = azurerm_resource_group.demo.location
  account_tier             = "Standard"
  account_replication_type = "LRS"

  tags = azurerm_resource_group.demo.tags
}

# outputs.tf
output "resource_group_name" {
  value = azurerm_resource_group.demo.name
}

output "storage_account_name" {
  value = azurerm_storage_account.demo.name
}

output "storage_account_primary_blob_endpoint" {
  value = azurerm_storage_account.demo.primary_blob_endpoint
}

2.9 Troubleshooting Installation

Common Issues:
  • "terraform not found" — Ensure /usr/local/bin or the install directory is in your PATH
  • "provider not found" — Run terraform init to download providers
  • "version mismatch" — Check required_version constraint in your config
  • "permission denied" — On Linux, use sudo mv terraform /usr/local/bin/
  • "SSL certificate" — Corporate proxies may block downloads; set HTTPS_PROXY env var
Exercise:
  1. Install Terraform on your system using your preferred method
  2. Verify the installation with terraform version
  3. Set up VS Code with the HashiCorp Terraform extension
  4. Create a project with providers.tf, variables.tf, main.tf, and outputs.tf
  5. Run terraform init and verify the .terraform/ directory is created
Summary & Checklist:
  • Install Terraform via package manager or direct download
  • Verify installation with terraform version
  • Set up IDE with Terraform extension for syntax highlighting and validation
  • Follow standard project structure (main.tf, variables.tf, outputs.tf, providers.tf)
  • Configure authentication for your cloud provider
  • Create a .gitignore to exclude .terraform/ and state files
  • Learn the core commands: init, plan, apply, destroy, fmt, validate
