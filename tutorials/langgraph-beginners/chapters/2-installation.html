Installation & Environment Setup

Prerequisites

  • Python 3.9 or newer — check with python --version (use python3 on macOS/Linux).
  • pip (bundled with Python).
  • An LLM to power the agent. Two easy paths:
    • OpenAI — sign up at platform.openai.com, create an API key (paid, but cheap for experiments).
    • Ollama (free, local) — run a model on your own machine; no API key required. Perfect for this tutorial.

Step 1: Create a virtual environment

A virtual environment keeps this project's dependencies isolated from your system Python.

# Windows (PowerShell)
python -m venv .venv
.venv\Scripts\Activate.ps1

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

After activating, your shell prompt should start with (.venv). You can leave the environment any time with deactivate.

Step 2: Install LangGraph

pip install langgraph langchain-core langchain-openai python-dotenv
  • langgraph — the graph engine.
  • langchain-core — messages (HumanMessage, AIMessage), tools, model interfaces.
  • langchain-openai — OpenAI chat model integration.
  • python-dotenv — loads .env files so your API key stays out of code.
Already using a local model? Skip langchain-openai and install pip install langchain-ollama instead — then use ChatOllama below.

Step 3: Store your API key safely

Create a file named .env in your project root:

OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxx

Add this to your .gitignore so the key is never committed:

# .gitignore
.env
.venv/
Never hardcode keys in source code or paste them into git history. Use .env + environment variables.

Step 4: Choosing your LLM provider

LangGraph works with any chat model. The examples in this tutorial use OpenAI, but the same graph code runs against a local model by swapping one line.

OpenAI (recommended for simplicity)

from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

Free local alternative: Ollama

Install Ollama, pull a small model, then use a drop-in replacement:

pip install langchain-ollama
# Terminal
ollama pull llama3.2
from langchain_ollama import ChatOllama

model = ChatOllama(model="llama3.2", temperature=0)

Everything else in this tutorial stays identical. (Groq and other OpenAI-compatible providers also work through langchain-groq or ChatOpenAI(base_url=...).)

Step 5 (optional): LangSmith for tracing

LangSmith gives you a debugger that shows every graph step, token usage, and latency. For local experiments you can enable it with a free developer account:

# .env
LANGCHAIN_TRACING_V2=true
LANGCHAIN_API_KEY=lsv2_xxxxxxxx
LANGCHAIN_PROJECT=langgraph-beginners

Step 6: Verify the install

Run this sanity check. If it prints a friendly message, your environment is ready for Chapter 3:

from langgraph.graph import StateGraph, START, END
from langchain_openai import ChatOpenAI

class State(dict):
    pass

def greet(state):
    return {"msg": "Hello from LangGraph!"}

g = StateGraph(State)
g.add_node("greet", greet)
g.add_edge(START, "greet")
g.add_edge("greet", END)
app = g.compile()

print(app.invoke({})["msg"])  # Hello from LangGraph!
Note: Using a dict-based state with no reducers is fine for testing; in Chapter 3 we switch to a proper TypedDict with an add_messages reducer.

Common setup problems

SymptomFix
ModuleNotFoundError: langgraphActivate the venv first (source .venv/bin/activate).
OpenAI API key error / 401Check that .env is loaded (load_dotenv()) and the key has no quotes or trailing spaces.
gpt-4o-mini does not existYour account may restrict model access; use gpt-3.5-turbo or gpt-4o, or switch to Ollama.
Ollama connection refusedEnsure ollama serve (or the desktop app) is running and the model is pulled.
Python too oldLangGraph requires 3.9+; install a newer Python or use a version manager.
