Lab - Mask-based image modification

Prompt-driven editing works well when the whole image or a large region needs to change. But sometimes you need surgical control: replace only the area a model missed, remove a single object, or fill a gap. Mask-based editing gives you that control. You provide a black-and-white mask alongside the image, and the model is only allowed to regenerate the region the mask marks. In this lab you will implement mask-based editing in Python.

What You Need Before Starting

  • Python 3.9 or newer and VS Code.
  • An image model deployment that supports masks, such as gpt-image-1.
  • Your endpoint URL and API key as environment variables.
  • An input image, for example sample_background.png, and a mask image, for example mask_region.png, both from the section download.

Understanding the Mask

A mask is a second image the same size as the original. Its pixels tell the model which areas are locked and which are free to be redrawn:

  • Black (or transparent) pixels protect the original content — the model must leave them unchanged.
  • White pixels mark the region the model regenerates based on your prompt.

For the lab, mask_region.png marks a blank region of sample_background.png that you will fill with a new object. The original scene around the mask stays intact, so the new content should blend in naturally.

You can create masks yourself with any image editor: open the original image, paint the region you want to change white on a new layer, fill everything else black, and export a PNG. The two images must share the same dimensions.

Run a Mask-Based Edit

Step 1 - Create the project folder

Create a folder named ai103-lab119 and open it in VS Code. Create a file called edit_mask.py. Copy sample_background.png and mask_region.png into the folder.

Step 2 - Set your environment variables

$env:AZURE_OPENAI_ENDPOINT = "https://YOUR-RESOURCE.openai.azure.com/"
$env:AZURE_OPENAI_KEY = "YOUR_KEY"

Step 3 - Paste the script

Paste the following code and replace YOUR_IMAGE_DEPLOYMENT_NAME with your deployment's name. Both the image and the mask are passed as base64 data URIs:

from openai import AzureOpenAI
import os
import base64
import requests

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

def to_data_uri(file_name):
    with open(file_name, "rb") as image_file:
        encoded = base64.b64encode(image_file.read()).decode("utf-8")
    return f"data:image/png;base64,{encoded}"

result = client.images.generate(
    model="YOUR_IMAGE_DEPLOYMENT_NAME",
    prompt="A bright yellow vintage scooter parked in the blank area",
    image=[{"type": "image_url", "image_url": {"url": to_data_uri("sample_background.png")}}],
    mask=[{"type": "image_url", "image_url": {"url": to_data_uri("mask_region.png")}}],
    size="1024x1024",
)

url = result.data[0].url
with open("inpainted_result.png", "wb") as out_file:
    out_file.write(requests.get(url).content)

print("Saved to inpainted_result.png")

Step 4 - Run the script

python edit_mask.py

Open inpainted_result.png. The scooter should appear only inside the masked region, and the surrounding background should remain unchanged.

What Good Mask Results Look Like

When a mask-based edit works well, you can barely tell the region was regenerated:

  • The new content respects the size and shape of the mask — it fills the region without overflowing it.
  • Lighting and perspective match the surrounding scene.
  • Colors and texture blend across the mask boundary.

If the output looks pasted on top of the image instead of painted into it, the mask was probably too tight or the prompt described content that does not fit the region's proportions. Enlarge the mask slightly and adjust the prompt.

Removing an Object with a Mask

Masks are also the standard way to remove an unwanted object. Point the prompt at the surrounding scene and let the model rebuild what the object covered:

result = client.images.generate(
    model="YOUR_IMAGE_DEPLOYMENT_NAME",
    prompt="Continue the sidewalk and grass naturally, no object here",
    image=[{"type": "image_url", "image_url": {"url": to_data_uri("sample_background.png")}}],
    mask=[{"type": "image_url", "image_url": {"url": to_data_uri("mask_region.png")}}],
    size="1024x1024",
)

Use PNG for masks. JPEG compression introduces fringing around the black and white boundary, which can cause the model to regenerate pixels outside your intended region.

Summary

You have implemented mask-based image editing. You supplied an input image, a black-and-white mask marking the region to regenerate, and a prompt describing the new content, then saved the result. This gives you precise control over where the model is allowed to draw, which is the key technique for object removal and surgical edits.
