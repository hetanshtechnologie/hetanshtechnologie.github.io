Lab - Translating Text

Translation is the transformation task in the text-analysis family. Because chat models are trained on multilingual text, translating between languages is often as simple as asking. In this lab you will translate text with prompts, control register and audience, and then consider when a prompt-based approach is the right choice versus a dedicated translation service.

Prerequisites

  • The environment and client setup from the earlier text-analysis labs.
  • A deployed chat model with a known deployment name.

Step 1: Translate with a Plain Prompt

Exercise 1: One text, one target language

Create translate_chat.py:

import os

from dotenv import load_dotenv
from openai import AzureOpenAI

load_dotenv()

client = AzureOpenAI(
    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("AZURE_OPENAI_KEY"),
    api_version="2024-06-01",
)

DEPLOYMENT = "YOUR_DEPLOYMENT_NAME"

source = (
    "The inspection drone uses a stereo camera to map pipe surfaces "
    "and flags corrosion zones before they become critical."
)


def translate(text: str, language: str) -> str:
    response = client.chat.completions.create(
        model=DEPLOYMENT,
        messages=[
            {
                "role": "system",
                "content": (
                    "You are a professional translator. Translate the user's "
                    "text into the requested language. Preserve the meaning "
                    "and technical terms; return only the translation."
                ),
            },
            {"role": "user", "content": f"Target language: {language}\n\n{text}"},
        ],
    )
    return response.choices[0].message.content


print(translate(source, "Spanish"))
print(translate(source, "German"))
print(translate(source, "Japanese"))
  1. Run the script and review the three translations. Technical terms such as "stereo camera" and "corrosion zones" should stay accurate across languages.
  2. Translate the output of one language into another, for example Spanish back to English, and compare the round trip with the original. Small wording differences are normal; a changed fact means the prompt needs tightening.

Step 2: Control Register and Audience

Exercise 2: Translate for an audience

Add a register parameter to the translation function:

def translate_for(text: str, language: str, style: str) -> str:
    response = client.chat.completions.create(
        model=DEPLOYMENT,
        messages=[
            {
                "role": "system",
                "content": (
                    "You are a professional translator. Translate the text "
                    "into the target language. Match the requested register "
                    "exactly. Return only the translation."
                ),
            },
            {
                "role": "user",
                "content": (
                    f"Target language: {language}\n"
                    f"Register: {style}\n\n{text}"
                ),
            },
        ],
    )
    return response.choices[0].message.content


support_note = (
    "Your order was delayed because the warehouse lost the package. "
    "We are shipping a replacement today."
)
print(translate_for(support_note, "French", "warm, apologetic customer-service tone"))
print(translate_for(support_note, "French", "brief, neutral official notice"))
  1. Run the script and compare the two French versions. They should translate the same facts but with very different word choices and structure.
  2. Try a technical document with the style "simple language for a general audience" and then "formal engineering report". Note how sentence length and vocabulary shift.

This audience control is the prompting approach's signature advantage: a general-purpose model can adapt a translation to a register, audience, or brand voice. A pure translation service returns one faithful version and leaves the rest to you.

Step 3: Batch-Translate a Short Document

Exercise 3: Translate several paragraphs

Loop over a list of paragraphs to translate a small document:

document = [
    "The sensor array reports every 30 seconds.",
    "Alerts are grouped by severity on the dashboard.",
    "Operators can acknowledge alarms with one click.",
]

for para in document:
    print(translate(para, "Italian"))
  1. Run the script. Each paragraph should be translated independently and printed in order.
  2. Change the system prompt to "Translate the whole document and return it as one continuous text" and pass all paragraphs joined by a newline instead. Compare the result with the per-paragraph loop.
  3. Notice any terminology drift: in a real multi-paragraph translation, a phrase translated one way in paragraph one may come back differently in paragraph two unless you ask the model to keep terminology consistent.

For high-volume production translation, compare the cost-per-character of a chat model against Azure Translator. The translator lab later in this section shows the dedicated service, which is typically faster and cheaper for bulk work but does not offer register control.

Step 4: Detect Issues in the Output

Machine translation occasionally drops or adds meaning. Two cheap checks catch most problems:

  • Round trip: translate the output back to the original language and compare with the source. Any fact that changed in the round trip is a translation error or a prompt problem.
  • Terms list: ask the model to keep a small glossary of key terms fixed, then spot-check that the glossary terms appear in every translation.
glossary = "stereo camera = camera stereo; corrosion zones = zonas de corrosión"
print(translate_for(source, "Spanish", f"use this glossary: {glossary}"))

Summary

You translated text with a plain prompt, controlled register and audience, batch-processed a short document, and applied round-trip and glossary checks to catch errors. Prompt-based translation is flexible and context-aware; later in this section you will meet Azure Translator as the dedicated, high-throughput alternative.
