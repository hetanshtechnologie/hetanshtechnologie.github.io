Lab - Computer Vision - Python - Object Detection

Tagging and captioning describe the whole image. Object detection answers a more precise question: where are the objects? For every object it finds, the service returns a label and a bounding box — four coordinates that define a rectangle around the object in the image. In this lab you will run object detection from Python and print each object with its location and confidence.

What You Need

  • Your Computer Vision endpoint and key.
  • Python 3 with the requests package installed.
  • A test image containing one or more recognizable objects, such as test.jpg.

Write the Object Detection Code

import os
import requests

ENDPOINT = os.environ["COMPUTER_VISION_ENDPOINT"]
KEY = os.environ["COMPUTER_VISION_KEY"]

ANALYZE_URL = ENDPOINT.rstrip("/") + "/computervision/imageanalysis:analyze"
params = {
    "api-version": "2024-02-01",
    "features": "objects",
}

with open("test.jpg", "rb") as f:
    image_data = f.read()

headers = {
    "Content-Type": "application/octet-stream",
    "Ocp-Apim-Subscription-Key": KEY,
}

response = requests.post(ANALYZE_URL, params=params, headers=headers, data=image_data)
response.raise_for_status()

result = response.json()
for obj in result["objectsResult"]["values"]:
    name = obj["name"]
    confidence = obj["confidence"]
    box = obj["boundingBox"]
    print(f"{name:<15} conf={confidence:.2f}  box={box}")

Run and Observe

Exercise 1: Detect objects in a local image

  1. Save the script as vision_objects.py.
  2. Set the two environment variables and run python vision_objects.py.
  3. Read the output. For each object you should see its name, a confidence score, and a bounding box of four numbers.
  4. Try an image with multiple subjects — for example a room with several chairs, or a park with people and dogs. Watch how the service returns one entry per detected object.
  5. Check the bounding boxes: a box for a person should cover the full person, not just the face or torso.

Understanding the Bounding Box

The boundingBox is a list of four integers: x, y, width, height. The top-left corner of the image is at (0, 0); x is the horizontal offset, y the vertical offset, and width and height are measured in pixels. With these four numbers you can draw a rectangle on the image with any graphics library.

from PIL import Image, ImageDraw

image = Image.open("test.jpg")
draw = ImageDraw.Draw(image)

for obj in result["objectsResult"]["values"]:
    x, y, w, h = obj["boundingBox"]
    draw.rectangle([x, y, x + w, y + h], outline="red", width=3)

image.save("annotated.jpg")
print("Saved annotated.jpg with boxes drawn.")

This snippet uses the Pillow library (pip install pillow) purely for visualization. The analysis itself is done entirely by the Computer Vision service — Pillow is only drawing the boxes the service returned.

What the Response Looks Like

{
  "metadata": {"width": 640, "height": 480},
  "objectsResult": {
    "values": [
      {"name": "person", "confidence": 0.95, "boundingBox": [150, 60, 180, 300]},
      {"name": "dog", "confidence": 0.88, "boundingBox": [400, 250, 120, 150]}
    ]
  }
}

Reading Results Critically

  • Confidence varies per object. A small object in the background usually scores lower than the clear foreground subject.
  • Overlapping objects can share boxes or cause the service to merge them. Bounding boxes are estimates, not exact silhouettes.
  • The same object can appear multiple times if the image contains several instances — expect one entry per detected instance.

Object detection counts and coordinates are predictions, and they can be wrong. In applications that count inventory or people, treat the results as an estimate and validate them against a sample before making business decisions on them.

Summary

You ran object detection from Python, read each object's name, confidence, and bounding box, and learned to draw the boxes back onto the image for visualization. Object detection turns an image into structured geometry your application can act on — the same idea carries into brand detection in a later lab.
