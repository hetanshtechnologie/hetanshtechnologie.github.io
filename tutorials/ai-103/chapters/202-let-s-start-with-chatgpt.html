Let's start with ChatGPT

By far the most famous generative AI product in the world is ChatGPT. It is the chatbot that put large language models into the hands of hundreds of millions of people, and it is the perfect place to start experiencing generative AI first-hand. This chapter explains what ChatGPT is, how to use it, what it does well, and where its limits are.

What ChatGPT Is

ChatGPT is a conversational product built on top of a large language model made by OpenAI. Underneath the chat window is a model that has been trained on enormous amounts of text and then refined to behave like a helpful assistant in a back-and-forth conversation. The product handles the interface — sending your message, managing the conversation thread, and rendering the reply — while the model does the actual thinking.

An important distinction: ChatGPT is a product, not the model itself. The same class of models that powers ChatGPT is also available through the OpenAI API, which you will use later in this section to build your own applications.

Starting a Conversation

You can use ChatGPT in a web browser or through a mobile app. To begin:

  1. Open the ChatGPT website in your browser.
  2. Create an account or sign in with an existing one. Signing up needs only an email address or a Google/Microsoft account.
  3. You will land on a chat screen with a text box at the bottom.
  4. Type a message and press Enter. The assistant replies, and the conversation continues as a thread.

Treat the first conversation as a test drive. Ask the assistant to explain a concept you already understand, to write a short story, to plan a meal, or to debug a piece of code. Trying a variety of requests shows you the range of what it can do.

What You Can Ask It

ChatGPT is a general-purpose assistant. Common uses include:

  • Explaining: "Explain how a database index works in simple terms."
  • Writing: "Draft a friendly reminder email to a client about a late invoice."
  • Planning: "Create a one-week study plan for the AI-103 exam."
  • Brainstorming: "Give me ten product names for a coffee subscription service."
  • Coding: "Write a Python function that reverses a string without using slicing."
  • Summarising: "Summarise this article in three bullet points."

Conversation Context

The chat window keeps the whole conversation as context. The assistant can refer back to earlier messages, so you can refine an answer without starting over:

You: Write a short poem about the sea.
Assistant: [a poem about the sea]
You: Make it rhyme.
Assistant: [the same poem, now with rhyme]
You: Now write it from the perspective of a lighthouse.
Assistant: [a rhyming poem from a lighthouse's point of view]

This back-and-forth is the core pattern you will later automate with the API: a growing list of messages that the model reads before producing its next reply.

What ChatGPT Does Not Do Well

  • It can be wrong with confidence. Factual claims must be checked, especially dates, figures, and niche topics.
  • Its knowledge has a cutoff. It may not know recent events unless live web search is enabled.
  • It cannot truly reason. It produces text that looks like reasoning, which is usually good enough but not guaranteed to be correct.
  • It follows instructions too literally. An ambiguous prompt can produce an answer that misses what you actually meant.

Do not paste confidential company data, passwords, or personal information into a public chatbot. Whatever you type may be used to improve the service, so treat it like a public forum.

Free Versus Paid

ChatGPT is available in a free tier with generous limits and in paid tiers that add higher usage caps, access to the latest models, and extra features such as image generation and voice. For learning the fundamentals in this section, the free tier is more than enough — the point is to experience how conversational generative AI behaves, not to measure throughput.

Later in this section you will sign up for the OpenAI API platform. That is a separate account with separate billing from ChatGPT. The chatbot you use here is free and does not require API credits; the API is metered and billed per request.

Summary

ChatGPT is a conversational product wrapped around a large language model. You start a conversation, ask in plain language, and refine through follow-ups, and it can explain, write, plan, brainstorm, and code. It is powerful but imperfect: it makes confident mistakes, has a knowledge cutoff, and should never receive confidential information.
