Lab - Moderating images using Azure AI Content Safety

In this lab you will send images to the Azure AI Content Safety resource you built in the previous chapter and read back the per-category severity scores. This is the code that powers the portal experience: any image your application accepts can be checked the same way before it is stored, displayed, or passed to a model. By the end you will have a script that moderates a local image and a threshold that decides whether it is allowed.

What You Need Before Starting

  • Python 3.9 or newer and VS Code.
  • Your Content Safety resource from the previous lab, with endpoint and key set as environment variables.
  • The azure-ai-contentsafety package installed.
  • A test image, for example sample_photo.jpg from the section download.

Install the SDK

If you completed the text moderation lab, the SDK is already present. If not, install it now:

pip install azure-ai-contentsafety

The Image Moderation Request

Image analysis follows the same shape as text analysis. The main differences are the options type and the way the image is supplied:

  1. Read the image file in binary mode.
  2. Wrap the bytes in an ImageData object.
  3. Put that inside an AnalyzeImageOptions request.
  4. Call analyze_image and read the per-category results.

Moderate an Image

Step 1 - Create the project folder

Create a folder named ai103-lab125 and open it in VS Code. Create a file called moderate_image.py and copy sample_photo.jpg into the folder.

Step 2 - Set your environment variables

$env:CONTENT_SAFETY_ENDPOINT = "https://YOUR_CONTENT_SAFETY.cognitiveservices.azure.com/"
$env:CONTENT_SAFETY_KEY = "YOUR_KEY"

Step 3 - Paste the script

from azure.ai.contentsafety import ContentSafetyClient
from azure.ai.contentsafety.models import AnalyzeImageOptions, ImageData
from azure.core.credentials import AzureKeyCredential
import os

endpoint = os.environ["CONTENT_SAFETY_ENDPOINT"]
key = os.environ["CONTENT_SAFETY_KEY"]

client = ContentSafetyClient(endpoint, AzureKeyCredential(key))

with open("sample_photo.jpg", "rb") as image_file:
    image_bytes = image_file.read()

request = AnalyzeImageOptions(
    image=ImageData(content=image_bytes),
)

response = client.analyze_image(request)

for item in response.categories_analysis:
    print(item.category, "- severity:", item.severity)

Step 4 - Run the script

python moderate_image.py

For a normal everyday photo, every category should report severity 0. Try the script again with a different image to see how the scores move.

Reading the Results

The response mirrors the text moderation response. Each entry in response.categories_analysis reports one harm category and its severity on the 0-to-6 scale. A photo of a landscape scores 0 everywhere. Content that violates a category scores 1 through 6 depending on how severe the service judges it.

  • Category names come from the TextCategory-style enums in the SDK, for example Hate, Sexual, Violence, and SelfHarm.
  • Severity 0 means nothing of that kind was found.
  • Higher severities indicate stronger signals of harmful content.

Deciding Whether to Allow the Image

Turn the scores into a decision with the same threshold pattern you used for text:

BLOCK_THRESHOLD = 2

blocked = any(
    item.severity is not None and item.severity >= BLOCK_THRESHOLD
    for item in response.categories_analysis
)

if blocked:
    print("Image blocked.")
else:
    print("Image allowed.")

Log the category and severity with every decision. When you later tune thresholds, the logs tell you exactly which categories are producing false positives in your real traffic.

Moderating Many Images

For a batch of images, loop and collect the verdicts:

for file_name in ["sample_photo.jpg", "other_photo.png"]:
    with open(file_name, "rb") as image_file:
        payload = AnalyzeImageOptions(
            image=ImageData(content=image_file.read()),
        )
    result = client.analyze_image(payload)
    worst = max(
        (item.severity or 0 for item in result.categories_analysis),
        default=0,
    )
    print(f"{file_name}: worst severity {worst}")

Keeping Files Under the Limits

The image API has a maximum file size for analysis. If you run into a size error, resize the image before sending it:

pip install pillow

from PIL import Image

image = Image.open("sample_photo.jpg")
image.thumbnail((1280, 1280))
image.save("sample_photo_small.jpg", "JPEG")

Troubleshooting Common Errors

Error you may seeMost likely causeFix
400 Image too largeThe file exceeds the API size limit.Resize or recompress the image with Pillow.
401 Invalid keyThe endpoint or key is wrong.Re-copy the key and reset the environment variables.
InvalidRequest for imageThe resource kind is not Content Safety.Verify the resource was created with --kind ContentSafety.

Summary

You have moderated images with the Azure AI Content Safety API. You read an image's bytes, sent them through analyze_image, read the severity score per category, and applied a threshold to make an allow or block decision. Combined with the text moderation and Prompt Shields work from earlier chapters, you now have a complete safety layer for both the content your models see and the content your users upload.
