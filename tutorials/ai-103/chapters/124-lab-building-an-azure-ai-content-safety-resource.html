Lab - Building an Azure AI Content Safety resource

Every Content Safety API call in this section needs a resource to talk to. An Azure AI Content Safety resource is a paid Azure service that hosts the moderation endpoints — text analysis, image analysis, and Prompt Shields. In this lab you will create that resource, first walking through the Azure portal and then using the Azure CLI so the whole process is repeatable from the command line.

What You Need Before Starting

  • An Azure subscription with permission to create resources. The free account you set up in earlier chapters works.
  • Either the Azure portal in a browser or the Azure CLI installed locally.
  • A naming scheme so your resource is easy to find later — this lab uses ai103-content-safety.

Create the Resource in the Portal

If you prefer the portal, this is the fastest path:

  1. Sign in to the Azure portal and click Create a resource.
  2. Search for Azure AI Content Safety and select it.
  3. On the create blade, fill in the basics:
    • Subscription: your active subscription.
    • Resource group: create a new one, for example ai103-content-safety-rg.
    • Region: a region where Content Safety is available.
    • Name: ai103-content-safety.
    • Pricing tier: F0 (free) for this course.
  4. Click Review + create, then Create.
  5. Wait for the deployment to finish, then open the new resource.

The free tier F0 is enough for every lab in this course. If it is not available in your region, choose the cheapest standard tier and remember to clean the resource up afterwards.

Create the Resource with the Azure CLI

The portal is fine for a one-off, but the CLI is scriptable and documents your setup. Run the whole lab from a terminal.

Step 1 - Sign in and set your subscription

az login

A browser window opens. Sign in with your Azure account, then verify the subscription you want to use:

az account show --query name

Step 2 - Create the resource group

az group create --name ai103-content-safety-rg --location eastus

Step 3 - Create the Content Safety resource

Create the resource inside the group with the ContentSafety kind and the free tier:

az cognitiveservices account create `
    --name ai103-content-safety `
    --resource-group ai103-content-safety-rg `
    --kind ContentSafety `
    --sku F0 `
    --location eastus

The backtick character continues the command across lines in PowerShell. On other shells, replace it with the shell's line-continuation character.

Step 4 - Confirm the deployment

List the resources in the group to confirm the account exists:

az cognitiveservices account show `
    --name ai103-content-safety `
    --resource-group ai103-content-safety-rg `
    --query "properties.provisioningState"

The output should read Succeeded.

Collect the Endpoint and Key

Your code needs two values from this resource: the endpoint URL and an API key. Fetch both with the CLI:

az cognitiveservices account show `
    --name ai103-content-safety `
    --resource-group ai103-content-safety-rg `
    --query "properties.endpoint"

az cognitiveservices account keys list `
    --name ai103-content-safety `
    --resource-group ai103-content-safety-rg `
    --query "key1"

In the portal you can find the same values on the resource's Keys and Endpoint page.

Treat the key like a password. The labs read it from environment variables, and you should never commit it to source control or paste it into shared documents.

Store the Values as Environment Variables

Set the two values so your moderation scripts can pick them up:

$env:CONTENT_SAFETY_ENDPOINT = "https://YOUR_CONTENT_SAFETY.cognitiveservices.azure.com/"
$env:CONTENT_SAFETY_KEY = "YOUR_KEY"

Keep the endpoint and key handy: the text moderation lab and the image moderation lab both depend on them.

Cleaning Up Later

When you finish the course section, delete the resource group to avoid ongoing charges. This deletes the resource and everything in the group:

az group delete --name ai103-content-safety-rg --yes

Write the az` group create and az` cognitiveservices account create commands into a shell script or a notebook cell. If you need to rebuild the environment in another subscription or region, you can rerun the whole setup in seconds.

Summary

You have created an Azure AI Content Safety resource, both through the portal and with the Azure CLI. You confirmed its provisioning state, collected its endpoint and key, stored them as environment variables, and noted how to delete everything when the course is over. In the final lab of this section you will put the resource to work by moderating images.
