What are the objectives we are going to cover in this section

This short chapter is a roadmap. Before the next lecture, it sets out exactly what you will learn in this section about agents, what you will build, and what you should be able to do by the end of it.

The Objectives of This Section

  • Understand agentic AI: explain what makes a system an agent rather than a single model call, and where this trend comes from.
  • Use the OpenAI SDK for agents: build your first agent in Python with the official SDK, using your Foundry deployment as the model.
  • Define and attach tools: give an agent real capabilities by describing functions it can call.
  • Run the agent loop: understand how an agent plans, calls tools, and finishes.
  • Apply the foundation: reuse the endpoint, key, and client patterns from the previous section inside agent code.

What You Will Build

Over the coming chapters you will assemble a working agent that can answer questions, decide when it needs outside help, and use a tool to get it. You will start with a minimal agent that holds a conversation, then attach a tool and watch the agent call it automatically. The pattern you build is the seed of the CloudXeus course assistant used later in the course.

How This Section Is Organised

  1. A lecture on the rise of agentic AI and what makes systems agentic.
  2. A lecture introducing the OpenAI SDK's agent model, with small illustrative code samples.
  3. A hands-on lab in which you build and run your first agent against your Foundry deployment.

Prerequisites

  • Your Foundry endpoint and key saved as environment variables.
  • A deployed chat model such as gpt-4o-mini.
  • Python with the openai package installed.
  • Comfort with the chat completions pattern from the previous section.

What You Should Be Able to Do at the End

  • Explain, in your own words, why agents are more capable than single model calls.
  • Create an agent object, run it, and retrieve its final output.
  • Attach a custom tool and confirm the agent uses it when appropriate.
  • Describe the loop of planning, tool calling, and answering.

None of this requires retraining a model. Every capability in this section is orchestration: you are composing existing model power with code that decides, calls, and remembers.

Summary

This section takes you from single calls to agents. The objectives are concrete: understand agentic AI, build a first agent with the OpenAI SDK, attach tools, and run the loop. Next you begin with the story of why agents exist.
