Trying to moderate image content

Text moderation is only half of the content-safety problem. Many applications accept images too: profile photos, product listings, forum attachments, generated artwork. Harmful imagery needs to be caught the same way harmful text is. Azure AI Content Safety can analyze images and score them across the same harm categories, and this chapter explains how it works, what the scores mean, and how to try it in the portal before you write any code.

Why Image Moderation Matters

Images carry information differently from text. A harmful image is not always easy to describe in words, and keywords alone will not catch it. Applications that let users upload pictures need an automated check because:

  • Manual review does not scale to high-volume uploads.
  • Uploaded images may violate the law or platform rules.
  • Models can generate images that must be checked before they are shown publicly.
  • Harmful images often arrive alongside harmless text, so text filtering alone is not enough.

How Image Moderation Works

Image moderation sends the actual image pixels to a vision-based classifier. The classifier looks for the visual signals associated with each harm category — gestures, nudity, graphic violence, self-harm indicators — and returns a severity score per category, the same 0-to-6 scale you saw for text. Because the analysis is on the image content itself, it works regardless of what any accompanying text says.

The moderation service does not store or return your images. Your code sends the image bytes, gets back category scores, and the image is not retained by the service beyond the request handling.

Supported Image Formats

The image analysis endpoint accepts the common formats your application is likely to meet:

FormatNotes
JPEGMost common format; keep photos under the size limit
PNGFull support, including transparency
GIFStatic frames can be analyzed
WebPSupported in recent API versions

For this course, JPEG and PNG cover everything you will work with. If your image is another format, convert it before analysis.

The Harm Categories for Images

Image moderation scores the same core categories as text, adapted to visual content:

  • Hate: imagery promoting hate or denigrating a group.
  • Sexual: nudity or sexually explicit imagery.
  • Violence: graphic or glorified violence.
  • Self-harm: imagery depicting or encouraging self-harm.

Some resources also surface non-sexual explicit content and other configurable categories, depending on the API version and resource configuration.

Trying It in the Portal

Before writing code, get comfortable with the results by using the Content Safety Studio:

  1. Open the Azure AI Content Safety Studio and select the Moderate image content experience.
  2. Choose the Content Safety resource you want to use.
  3. Upload an image from your machine, or use one of the provided samples.
  4. Run the analysis and look at the per-category severity scores.
  5. Upload different images and watch the scores change — a landscape photo should score near zero everywhere, while a problematic image will score high in specific categories.

Do not upload images containing real personal information or images you do not have rights to. The studio displays the image and its scores to you; keep your testing to your own images or the provided samples.

Severity and Your Blocking Policy

Interpreting the scores is the same as for text. The decisions you make will differ by product:

Product typeTypical policy
Kids' appBlock any category at severity 1 or higher
General social appBlock severity 2 and above; flag 1 for review
News/documentary siteAllow low severities with age gates; block 3 and above

There is no single correct threshold. Start strict, review the false positives your product produces, and loosen gradually while monitoring complaint and escalation rates.

Limits and Practical Considerations

  • There is a maximum image file size for analysis — resize large uploads before sending them.
  • Very dark or heavily compressed images can reduce detection confidence.
  • Image moderation costs per call, so cache results for images you have already checked.
  • Combine image moderation with text moderation on any caption or filename that accompanies the image.

Summary

Image moderation runs a vision classifier over uploaded images and returns severity scores across the same harm categories used for text. It works regardless of accompanying text, does not retain your images, and its scores feed the same threshold logic you already applied to text.
