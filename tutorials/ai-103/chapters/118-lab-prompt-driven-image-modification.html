Lab - Prompt-driven image modification

In this lab you will modify an existing image by describing the change in words. You will send a local photo to an image model that supports editing, along with an instruction such as "swap the sky to sunset colors," and save the modified picture to disk. This is the same technique used behind product try-on tools, background switchers, and quick design mockups.

What You Need Before Starting

  • Python 3.9 or newer and VS Code.
  • An image model deployment that supports editing, such as gpt-image-1.
  • Your endpoint URL and API key as environment variables.
  • The openai and requests packages installed.
  • An input image, for example sample_room.jpg from the section download.

Editing support varies by model. Check the documentation of the image model you deployed to confirm that it accepts an input image. If your deployment does not support it, deploy a model that does before continuing.

How the Request Is Structured

An editing request reuses the images.generate method, but the call includes an extra image argument containing the original picture. The prompt then describes the change rather than the whole scene:

result = client.images.generate(
    model="YOUR_IMAGE_DEPLOYMENT_NAME",
    prompt="Replace the plain curtains with teal velvet curtains",
    image=[{"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{image_data}"}}],
    size="1024x1024",
)

The image is passed as a base64 data URI, exactly the way you attached images to chat messages in the vision lab.

Run a Prompt-Driven Edit

Step 1 - Create the project folder

Create a folder named ai103-lab118 and open it in VS Code. Create a file called edit_prompt.py and copy sample_room.jpg into the folder.

Step 2 - Set your environment variables

$env:AZURE_OPENAI_ENDPOINT = "https://YOUR-RESOURCE.openai.azure.com/"
$env:AZURE_OPENAI_KEY = "YOUR_KEY"

Step 3 - Paste the script

Paste the following code and replace YOUR_IMAGE_DEPLOYMENT_NAME with your deployment's name:

from openai import AzureOpenAI
import os
import base64
import requests

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

with open("sample_room.jpg", "rb") as image_file:
    image_data = base64.b64encode(image_file.read()).decode("utf-8")

result = client.images.generate(
    model="YOUR_IMAGE_DEPLOYMENT_NAME",
    prompt="Replace the plain curtains with teal velvet curtains",
    image=[{"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{image_data}"}}],
    size="1024x1024",
)

url = result.data[0].url
with open("edited_room.png", "wb") as out_file:
    out_file.write(requests.get(url).content)

print("Saved to edited_room.png")

Step 4 - Run the script

python edit_prompt.py

Open edited_room.png and compare it with the original. The curtains should be changed while the rest of the room stays recognizable.

Experimenting with Instructions

Editing quality depends heavily on how you phrase the change. Try these variations to feel the difference:

  • Global change: "Repaint the walls a warm cream color."
  • Object swap: "Replace the sofa with a leather armchair."
  • Atmosphere change: "Make the room feel brighter, morning light through the window."
  • Preservation hint: "Keep the layout and furniture identical, only change the floor to light wood."

State both what to change and what to keep. Prompts that describe the desired end state ("the curtains are now teal velvet") tend to produce cleaner edits than vague commands ("make it nicer").

Handling the Response

Just like pure generation, the edit call returns each image in result.data. Depending on the model, the image arrives as a url or as b64_json. The download logic you wrote in the generation lab works here unchanged, so reuse it when you want a robust script.

Troubleshooting Common Errors

You passed the original picture as a base64 data URI, sent it through the images.generate call together with a change-focused prompt, and saved the result.
