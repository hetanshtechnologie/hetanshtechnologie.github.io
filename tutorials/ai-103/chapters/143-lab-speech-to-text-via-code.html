Lab - Speech to Text via Code

In this lab you will transcribe a pre-recorded audio file using the Azure Speech SDK from Python. This is the batch-style workflow: you point the SDK at a local audio file, it runs recognition, and you print the transcript together with confidence scores and word-level timings. You will need an Azure AI Speech resource with its key and region, which you can create in the portal or with the Azure CLI.

What You Will Build

You will write a small Python program that:

  • Loads a WAV audio file from disk.
  • Sends it to the Speech service for recognition.
  • Prints the recognized text and the overall confidence.
  • Prints per-word detail, including start and end times.

Exercise: Transcribing an audio file with the Speech SDK

Step 1 — Create the Speech resource

If you do not already have a Speech resource, create one. From the Azure portal, search for Speech services and create a new resource, or run this from your terminal:

az cognitiveservices account create \
  --name speech103 \
  --resource-group rg-ai103 \
  --kind SpeechServices \
  --sku F0 \
  --location eastus \
  --yes

Note the endpoint, key, and region of the resource — you will paste them into the script as environment variables.

Step 2 — Prepare the audio file

Create a folder for the lab and place an audio recording of clear speech in it, for example sample.wav. You can record a short sentence with any recorder and export it as a WAV file. Keep it short — a few seconds of clean speech is enough for this exercise.

Step 3 — Install the Speech SDK

Create a Python virtual environment and install the Speech package:

python -m venv .venv
.\.venv\Scripts\activate
pip install azure-cognitiveservices-speech

Step 4 — Write the transcription script

Create a file named transcribe_file.py with the code below. The script reads the key and region from environment variables, so no secret is hard-coded.

import os

import azure.cognitiveservices.speech as speechsdk

SPEECH_KEY = os.environ.get("YOUR_SPEECH_KEY", "")
SPEECH_REGION = os.environ.get("YOUR_SPEECH_REGION", "")
AUDIO_FILE = os.environ.get("AUDIO_FILE", "sample.wav")

if not SPEECH_KEY or not SPEECH_REGION:
    raise SystemExit("Set YOUR_SPEECH_KEY and YOUR_SPEECH_REGION first.")

speech_config = speechsdk.SpeechConfig(
    subscription=SPEECH_KEY,
    region=SPEECH_REGION,
)
speech_config.speech_recognition_language = "en-US"

audio_config = speechsdk.audio.AudioConfig(filename=AUDIO_FILE)
recognizer = speechsdk.SpeechRecognizer(
    speech_config=speech_config,
    audio_config=audio_config,
)

result = recognizer.recognize_once()

if result.reason == speechsdk.ResultReason.RecognizedSpeech:
    print("Transcript:", result.text)
    print("Confidence:", result.properties[
        speechsdk.PropertyId.SpeechServiceResponse_JsonResult
    ])
elif result.reason == speechsdk.ResultReason.NoMatch:
    print("No speech was recognized.")
elif result.reason == speechsdk.ResultReason.Canceled:
    cancellation = speechsdk.CancellationDetails(result)
    print(f"Canceled: {cancellation.reason}")
    print("Error details:", cancellation.error_details)

Step 5 — Run it

Set the environment variables and run the script:

$env:YOUR_SPEECH_KEY = "PASTE_YOUR_KEY_HERE"
$env:YOUR_SPEECH_REGION = "eastus"
$env:AUDIO_FILE = "sample.wav"
python transcribe_file.py

You should see the transcript of your recording printed to the console.

Reading the Detailed Result

The printed confidence value is the raw JSON payload the service returned. Open it up and you will find not only the full transcript but also NBest alternatives and a Words array with each word's Offset and Duration, expressed in hundreds of nanoseconds. That timing information is what lets you build word-for-word subtitles or jump a video to the moment a specific phrase was spoken.

To see the structured payload on its own, add a couple of lines that parse it with json and pretty-print it. Inspecting the raw result is the fastest way to learn what the service gives you beyond the plain text.

What Can Go Wrong

  • Authentication errors: double-check the key and region; the key must come from the Speech resource, not a generic AI services key.
  • Empty results: your audio may be too quiet, too short, or in a language other than the configured recognition language.
  • Unsupported format: if you point the SDK at a format it cannot parse, try converting the file to PCM WAV at 16 kHz first.

Summary

You transcribed a pre-recorded audio file with the Azure Speech SDK using SpeechConfig, AudioConfig, and SpeechRecognizer. The recognize_once pattern is the simplest request-response call in the SDK. In the next lab you will move from files to a live microphone, where results stream back in real time.
