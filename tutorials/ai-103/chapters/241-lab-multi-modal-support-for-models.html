Lab - Multi-Modal support for models

Until now your prompts have been text only. Many of the models in Microsoft Foundry are multimodal, which means they can read text and images in the same conversation. In this lab you will attach real image files to chat requests and ask the model questions about what it sees, using the same deployment and SDK you already know.

What Multimodal Means in Practice

A multimodal chat model accepts multiple kinds of input inside one message. Instead of a single string, a user message becomes a list of parts: text, an image, and sometimes audio. The model reasons across all of them together, so you can ask questions like "look at this diagram and explain the flow" or "read the price on this photo and convert it to euros."

This capability unlocks a whole family of applications that text-only models cannot handle: document inspection, screenshot analysis, receipt parsing, UI review, and visual QA, to name a few.

Multimodal input requires a deployment of a model that supports vision, such as gpt-5 or gpt-4o. A text-only model will either reject the request or ignore the image parts. Check the model card in the Foundry catalog before you start.

How Images Travel in a Request

Two formats are commonly supported for image parts:

  • Public URL: You pass the image's web address. The service fetches it on your behalf. Simple, but the URL must be publicly reachable.
  • Base64 data URI: You encode the file's bytes as base64 and inline them directly in the message. This works for local files and private storage.

For local images, the base64 data URI is the reliable choice because it does not depend on network access to your file. The pattern is always the same: read the file, base64-encode it, and build a part that points at the encoded string.

Step 1: Prepare a Test Image

Exercise 1: Send a local image with a question

  1. Create a folder named ai103-lab241 and open it in VS Code.
  2. Place a small image file (a screenshot, a photo, or any JPG/PNG you have) next to your script and call it sample.png.
  3. Create vision.py and set your environment variables:
$env:AZURE_OPENAI_ENDPOINT = "https://YOUR-RESOURCE.openai.azure.com/"
$env:AZURE_OPENAI_KEY = "YOUR_KEY"
  1. Paste this script and replace YOUR_DEPLOYMENT_NAME with your vision-capable chat deployment:
import base64
import os
from openai import AzureOpenAI

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

with open("sample.png", "rb") as f:
    image_bytes = f.read()

data_uri = "data:image/png;base64," + base64.b64encode(image_bytes).decode()

response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Describe what is in this image in two sentences."},
                {"type": "image_url", "image_url": {"url": data_uri}},
            ],
        }
    ],
)

print(response.choices[0].message.content)
  1. Run the script:
python vision.py

If everything is wired correctly, the model describes the image you attached.

The MIME type in the data URI must match the file. If your image is a JPEG, use data:image/jpeg;base64,.... Mismatched types cause the request to be rejected by the service.

Step 2: Ask a Targeted Question About the Image

Describing the image is the simplest test. The real value comes from asking questions that require reading specific details. The model treats the image as visual context, so you can ask it to count, extract, compare, or explain.

Exercise 2: Extract a specific fact from the image

Create extract.py that reuses the same image-loading code but asks a factual question:

import base64
import os
from openai import AzureOpenAI

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

with open("sample.png", "rb") as f:
    data_uri = "data:image/png;base64," + base64.b64encode(f.read()).decode()

response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": (
                        "Look carefully at this image and answer exactly three things: "
                        "the main subject, the dominant colors, and any text you can read in it."
                    ),
                },
                {"type": "image_url", "image_url": {"url": data_uri}},
            ],
        }
    ],
)

print(response.choices[0].message.content)

python extract.py

Try the same question with a different image. Notice how the answer changes completely when the picture changes — the model is genuinely reading the image you sent, not guessing from the question.

Step 3: Mix Text and Multiple Images

A single message can contain more than one image part. Put two images into the same request and compare them in one turn.

Exercise 3: Compare two images in one call

Add a second image file named second.png and build a request with two image parts:

import base64
import os
from openai import AzureOpenAI

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

def to_data_uri(path: str, mime: str) -> str:
    with open(path, "rb") as f:
        return f"data:{mime};base64," + base64.b64encode(f.read()).decode()

first = to_data_uri("sample.png", "image/png")
second = to_data_uri("second.png", "image/png")

response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Compare these two images. What is similar and what is different?"},
                {"type": "image_url", "image_url": {"url": first}},
                {"type": "image_url", "image_url": {"url": second}},
            ],
        }
    ],
)

print(response.choices[0].message.content)

python compare.py

Images count toward your token usage. A large photograph can consume far more tokens than the text around it, and several images multiply that quickly. Resize images to the minimum resolution that still answers your question, and cache any images you process repeatedly.

Summary

You made your first multimodal calls: you attached a local image to a chat request using a base64 data URI, asked the model to describe it and to extract specific facts, and compared two images in a single turn. The message content array — mixing text and image_url parts — is the same structure you will use for every vision-capable deployment.
