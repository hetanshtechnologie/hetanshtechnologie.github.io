Lab - Detecting Sentiment and Tone

Sentiment analysis answers a question every support team asks: is this message positive, negative, or neutral? Tone analysis goes one step further and describes the emotional register — frustrated, sarcastic, grateful, urgent. In this lab you will use a chat model for both, and you will learn why the model's ability to explain its judgment is often more valuable than the label itself.

Prerequisites

  • The environment and client setup from the earlier text-analysis labs.
  • A deployed chat model with a known deployment name.
  • A handful of realistic sample texts to analyze — review comments, support tickets, or social media posts work well.

Step 1: Single-Text Sentiment

Exercise 1: Label one message

Create sentiment.py:

import os

from dotenv import load_dotenv
from openai import AzureOpenAI

load_dotenv()

client = AzureOpenAI(
    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("AZURE_OPENAI_KEY"),
    api_version="2024-06-01",
)

DEPLOYMENT = "YOUR_DEPLOYMENT_NAME"


def analyze(text: str) -> str:
    response = client.chat.completions.create(
        model=DEPLOYMENT,
        messages=[
            {
                "role": "system",
                "content": (
                    "You classify the sentiment of messages. Return the "
                    "sentiment label (positive, negative, or neutral) and "
                    "a one-sentence explanation quoting the words that "
                    "justify it."
                ),
            },
            {"role": "user", "content": text},
        ],
    )
    return response.choices[0].message.content


message = (
    "I have called three times about this invoice and nobody has "
    "answered. This is getting really frustrating."
)
print(analyze(message))
  1. Run the script. You should see the label negative alongside a short explanation that points at words like "frustrating" and "nobody has answered".
  2. Swap in a positive message, such as a review praising fast shipping, and confirm the label flips and the explanation changes.
  3. Swap in a neutral message, such as "The package is scheduled for delivery tomorrow", and confirm it is classified neutral rather than positive or negative.

Step 2: Add Tone Detection

Exercise 2: Sentiment and tone in one pass

Extend the prompt to ask for tone as well:

def analyze_tone(text: str) -> str:
    response = client.chat.completions.create(
        model=DEPLOYMENT,
        messages=[
            {
                "role": "system",
                "content": (
                    "Analyze messages and report three things: a sentiment "
                    "label (positive, negative, neutral), a tone label "
                    "(for example: frustrated, sarcastic, grateful, urgent, "
                    "neutral), and a one-sentence justification."
                ),
            },
            {"role": "user", "content": text},
        ],
    )
    return response.choices[0].message.content


tricky = (
    "Oh great, another 'important' update that fixes nothing and "
    "breaks my workflow. Thanks for that."
)
print(analyze_tone(tricky))
  1. Run the script on the sarcastic message. The model should detect sarcasm — a case where tone disagrees sharply with the surface words.
  2. Test a message where the words are polite but the meaning is urgent, such as "Would it be possible to look into this today? It is quite time sensitive."
  3. Observe how the justification explains the gap between the literal words and the tone.

This is where a generative model pulls ahead of a simple polarity scorer. "Thanks for that" is positive vocabulary, but in context it is sarcastic. The model reasons over the full passage and its explanation lets a human verify the reasoning — something a numeric score alone cannot provide.

Step 3: Score a Small Batch

Exercise 3: Loop over several messages

Add a list of messages and a loop that classifies each one:

batch = [
    "The new dashboard is beautiful and the charts load instantly.",
    "Please send the updated contract. The deadline is Friday.",
    "Why is my account blocked again? I already verified my identity twice.",
    "It arrived. Everything works as described.",
    "No change to report on the migration.",
]

for i, msg in enumerate(batch, start=1):
    print(f"\n--- Message {i} ---")
    print(msg)
    print(analyze(msg))
  1. Run the script and review all five classifications. Note where the tone-only messages (urgent request, frustrated question) are labeled relative to their surface wording.
  2. Collect the results into a plain-text summary or a small CSV using Python's standard csv module if you want a reusable report.
  3. Re-run the script and compare the batch against the previous run. Labels should be stable, but the exact wording of explanations will vary.

For high-volume, round-the-clock sentiment scoring, the dedicated Azure AI Language sentiment feature is cheaper and returns a standardized schema with confidence scores. Use this prompting approach when you want tone, justification, or custom categories that the prebuilt feature does not cover.

Step 4: Ask for a Structured Report

To make the batch output machine-readable, combine this lab's analysis with the JSON techniques from the previous lab. Ask the model to return a JSON array of records with sentiment, tone, and justification fields, set response_format={"type": "json_object"}, and parse with json.loads. The result is a table your application can store or visualize directly.

Summary

You classified sentiment and tone with prompts, handled sarcasm and context-sensitive cases, scored a batch of messages, and learned how to shape the analysis into structured output.
