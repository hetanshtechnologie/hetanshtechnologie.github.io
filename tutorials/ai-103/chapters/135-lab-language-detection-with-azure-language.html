Lab - Language Detection with Azure Language

Before you can translate, summarize, or route a document, you often need to know what language it is written in. Azure AI Language detects the language of a text and returns the language code plus a confidence score. In this lab you will detect languages for single documents and batches, and interpret confidence to decide when a result is trustworthy.

Prerequisites

  • The Azure AI Language resource, endpoint, and key from the previous lab.
  • The text analytics SDK installed in your ai103-language environment.

Step 1: Set Up the Client

Exercise 1: Create the detection script

Create lang_detect.py:

import os

from azure.ai.textanalytics import TextAnalyticsClient
from azure.core.credentials import AzureKeyCredential
from dotenv import load_dotenv

load_dotenv()

client = TextAnalyticsClient(
    endpoint=os.getenv("AZURE_LANGUAGE_ENDPOINT"),
    credential=AzureKeyCredential(os.getenv("AZURE_LANGUAGE_KEY")),
)

Run the file once to confirm the client builds without error.

Step 2: Detect a Single Document's Language

Exercise 2: Detect and report

Append the detection call:

text = "Die Prüfung der Rohrleitungen ist für Montag geplant."

result = client.detect_language(documents=[text])[0]
if result.is_error:
    print("Error:", result.error.code, result.error.message)
else:
    print("Language code:", result.primary_language.iso6391_name)
    print("Language name:", result.primary_language.name)
    print("Confidence:", result.primary_language.confidence_score)
  1. Run the script. The service should return de for German with a confidence near 1.0.
  2. Swap in sentences in English, Spanish, Japanese, and French and note how the iso6391_name changes.

The detection result is a scored object, not prose: a language code, a human-readable name, and a confidence score. That fixed shape is exactly why this job suits a dedicated service — no prompt parsing, no JSON negotiation, just fields.

Step 3: Detect Languages for a Batch

Exercise 3: One call, many documents

Pass a list of documents to a single call:

batch = [
    "The quarterly earnings report is ready for review.",
    "Der neue Sensor wird nächste Woche installiert.",
    "La factura fue enviada por correo electrónico.",
    "商品は明日発送されます。",
    "Rapport mensuel disponible sur le portail.",
]

results = client.detect_language(documents=batch)
for i, res in enumerate(results, start=1):
    if res.is_error:
        print(f"Doc {i}: error {res.error.code}")
    else:
        lang = res.primary_language
        print(f"Doc {i}: {lang.iso6391_name} ({lang.name}) "
              f"confidence={lang.confidence_score:.2f}")
  1. Run the script. Each document should be classified with its own language code and confidence.
  2. Add a short English sentence such as "Hello, how are you?" and observe how the confidence drops on very short or ambiguous texts compared with longer passages.

Short texts are the hardest case for any language detector — a single word can be shared by many languages. When you route on language, apply a confidence threshold (for example, 0.8) and send low-confidence documents to a human or a fallback queue instead of guessing.

Step 4: Route by Language

Exercise 4: Build a tiny router

Use the detected code to pick a downstream handler:

def route(text: str) -> str:
    res = client.detect_language(documents=[text])[0]
    if res.is_error:
        return "unclassified"
    lang = res.primary_language.iso6391_name
    if res.primary_language.confidence_score < 0.8:
        return "needs-human-review"
    mapping = {"en": "english-pipeline", "de": "german-pipeline", "fr": "french-pipeline"}
    return mapping.get(lang, "other-language-pipeline")


samples = [
    "Refund approved, money returns in five days.",
    "Le remboursement est approuvé.",
    "Kurze Nachricht.",
]
for s in samples:
    print(f"{s[:30]!r:35s} -> {route(s)}")
  1. Run the script. Long, clear sentences route to their pipeline; the very short German phrase should drop below the threshold and be flagged for review.
  2. Adjust the threshold and rerun to see how the routing decision flips for borderline texts.

Summary

You detected the language of single documents and batches with Azure AI Language, read the language code, name, and confidence score, and used those fields to route documents by language with a confidence threshold. In the next lab you will use the same client to extract named entities from text.
