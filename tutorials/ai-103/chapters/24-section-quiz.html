Section Quiz

This quiz checks your understanding of the material in this section: API calls, controlling model behaviour, reasoning effort, multi-modal input, and tools. Read each question, pick the best answer, and check yourself against the answer key at the end.

The Quiz

  1. Which message role sets the persistent rules and identity of the assistant for the whole conversation?
    • A) user
    • B) system (correct)
    • C) tool
    • D) assistant
  2. In the chat completions API, which field contains the model's visible reply?
    • A) response.choices[0].message.content (correct)
    • B) response.messages[0]
    • C) response.output.text
    • D) response.reply
  3. You want the most deterministic, repeatable answers for a factual task. Which sampling setting is most appropriate?
    • A) temperature = 0.9
    • B) temperature = 0.0 (correct)
    • C) max_tokens = 5
    • D) frequency_penalty = 2
  4. What does finish_reason = "length" tell you?
    • A) The conversation is complete.
    • B) The model hit the max_tokens limit and the answer is truncated. (correct)
    • C) The API rejected the request.
    • D) The model refused to answer.
  5. Which parameter controls how much a reasoning model thinks before answering?
    • A) temperature
    • B) reasoning_effort (correct)
    • C) seed
    • D) top_p
  6. How are images sent to a vision-capable chat model?
    • A) As a file upload parameter.
    • B) As a base64 data URI inside the user message content. (correct)
    • C) As a URL in the system prompt.
    • D) Images are never supported in chat APIs.
  7. In a tool-call loop, who executes the tool?
    • A) The model.
    • B) Your application code. (correct)
    • C) The Foundry portal.
    • D) The reasoning engine.
  8. After the model requests a tool call, how do you give the result back to the model?
    • A) In a message with role tool and the matching tool_call_id. (correct)
    • B) In the system prompt.
    • C) As a second user message with no identifier.
    • D) The model does not need the result.

Answer Key

QuestionAnswerWhy
1BThe system message carries the assistant's persistent identity and rules.
2AThe reply text lives in message.content of the first choice.
3BA temperature of 0 makes token selection nearly deterministic.
4Blength signals truncation at the token limit.
5Breasoning_effort sets thinking time on reasoning models.
6BImages are embedded as base64 data URIs in the message content list.
7BThe model requests; your code runs the function and returns the result.
8ATool results go back in a tool message bound to the original call id.

If you missed more than two questions, revisit the matching chapters before continuing. The next section builds agents on top of these fundamentals, and shaky basics make the later labs harder than they need to be.
