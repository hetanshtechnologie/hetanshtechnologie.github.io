Introduction

This chapter opens a new section of the course focused on OpenAI fundamentals and Azure OpenAI. Until now you have worked mostly at the level of Microsoft Foundry and Azure AI Foundry — deploying models, building agents, and wiring up services. This section steps back and builds the conceptual foundation underneath all of it: what machine learning and generative AI really are, what ChatGPT is, how large language models work, what the term GPT means, and how to get hands-on with the OpenAI API platform.

Why This Section Matters

Understanding the ideas behind the tools makes you a better builder. When you know how a model is trained and how it generates text, you can write better prompts, choose the right model, and predict why an answer came out the way it did. This section also prepares you for the chapters that follow, where you will move from the OpenAI API platform to Azure OpenAI and Azure AI Foundry — the enterprise versions of the same ideas.

The Objectives of This Section

  • Understand machine learning: explain what it means for a program to learn from data instead of following hand-written rules.
  • Define generative AI: describe what generative models do and how they differ from predictive or classification models.
  • Use ChatGPT: get comfortable chatting with a modern AI assistant and learn what it can and cannot do.
  • Explain large language models: describe tokens, context windows, training, and why models generate text one piece at a time.
  • Decode GPT: break down the acronym into Generative, Pre-Trained, and Transformer.
  • Understand the model lineup: compare the different model families OpenAI offers and when to use each.
  • Use the OpenAI API platform: sign up for an account, explore the playground, and learn to work with system messages.

How This Section Is Organised

  1. Conceptual lectures on machine learning, generative AI, and ChatGPT.
  2. Focused explanations of large language models, GPT, and the model lineup.
  3. Hands-on chapters where you sign up for the OpenAI API platform, use the playground, and experiment with system messages.

Prerequisites

  • No special software is required for most of the section — a browser is enough.
  • Familiarity with the earlier chapters of this course will help you connect the concepts.
  • For the platform chapters you will need an email address and a payment method to verify your identity.

You can work through this section completely for free. The platform chapters use free credits and the playground, and none of the conceptual material requires spending money.

What You Should Be Able to Do at the End

  • Explain machine learning and generative AI in plain language.
  • Describe how ChatGPT, large language models, and GPT relate to one another.
  • Choose an appropriate model family for a given task.
  • Sign in to the OpenAI API platform and make your first calls using the playground and system messages.

Summary

This section builds the conceptual foundation of the course: machine learning, generative AI, ChatGPT, large language models, GPT, the model lineup, and the OpenAI API platform. By the end you will understand how these ideas fit together and be ready to apply them in Azure OpenAI and Azure AI Foundry. The next chapter starts at the very beginning with a brief understanding of machine learning.
