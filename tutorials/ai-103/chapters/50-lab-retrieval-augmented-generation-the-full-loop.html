Lab - Retrieval Augmented Generation - The Full Loop

Retrieval finds the right passages; the last step is generation. This lab combines everything into one script: embed the question, search the index, assemble a grounded prompt from the top chunks, and call a chat model that answers strictly from that context. When it works, you will have a complete RAG assistant for CloudXeus.

How the Loop Fits Together

  1. Take the user's question.
  2. Embed it and run a hybrid search against cloudxeus-docs.
  3. Collect the top-k chunks into a context block.
  4. Send a system prompt, the context, and the question to the chat model.
  5. Print the answer together with the sources that grounded it.

The Context Assembly

The prompt tells the model exactly how to behave. The key instruction: answer only from the supplied context, and say when the context does not contain the answer.

def build_prompt(question: str, chunks: list[dict]) -> str:
    context = "\n\n".join(
        f"Document: {c['title']}\n{c['content']}" for c in chunks
    )
    return (
        "You are the CloudXeus support assistant. Answer the question "
        "using ONLY the context below. If the context has no answer, say "
        "so honestly. Quote the source document when you use it.\n\n"
        f"CONTEXT:\n{context}\n\nQUESTION: {question}"
    )

The Chat Call

The chat model receives the assembled prompt in a single user message. A low temperature keeps the answer close to the supplied facts:

chat_client = AzureOpenAI(
    api_key=os.getenv("AZURE_OPENAI_KEY", "YOUR_KEY"),
    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT", "YOUR_ENDPOINT"),
    api_version="2024-06-01",
)
CHAT_DEPLOYMENT = "gpt-4o-mini"

def generate_answer(prompt: str) -> str:
    response = chat_client.chat.completions.create(
        model=CHAT_DEPLOYMENT,
        messages=[{"role": "user", "content": prompt}],
        temperature=0.2,
    )
    return response.choices[0].message.content

The Complete Script

Assemble everything into scripts/rag_assistant.py, reusing the search client, embed_query, and imports from the previous labs. The main function ties the pieces together:

from azure.search.documents.models import RawVectorQuery

def rag_answer(question: str, top: int = 4):
    vector = embed_query(question)
    vector_query = RawVectorQuery(vector=vector, k=top, fields="content_vector")
    results = client.search(search_text=question, vector_queries=[vector_query], top=top)

    chunks = [
        {"title": r["title"], "content": r["content"]}
        for r in results
    ]
    prompt = build_prompt(question, chunks)
    answer = generate_answer(prompt)

    print("ANSWER:", answer)
    print()
    print("SOURCES:")
    for c in chunks:
        print("-", c["title"])

Run the Assistant

Exercise — Ask the Assistant Questions

  1. Combine the code blocks from this chapter into scripts/rag_assistant.py, adding the imports and client setup from the search lab.
  2. Add a call at the bottom: rag_answer("How do I reset the EdgeCam 300?").
  3. Run python scripts/rag_assistant.py.
  4. Ask two or three more questions, including one the documents do not cover, and check that the assistant says it lacks the information rather than inventing it.

Diagnosing Bad Answers

  • No relevant chunk returned: revisit chunking and consider hybrid search with a higher top.
  • The answer ignores the context: strengthen the system prompt and lower the temperature.
  • The answer is shallow: the top chunk may be too short; merge adjacent chunks or increase the chunk size.
  • Wrong sources: check whether your index actually contains the right documents and that re-embedding used the same model.

Every RAG system needs iteration. Log the retrieved chunks alongside each answer during testing; when an answer is wrong, the log tells you whether retrieval or generation was at fault.

Summary

You now have a working RAG assistant: it retrieves relevant CloudXeus passages, grounds the answer in them, and cites its sources. This full loop is the pattern behind most knowledge assistants you will build.
