Lab - Using python and models to generate images

In this lab you will write your first programmatic image generation script. You will call the image endpoint of a model deployed in Microsoft Foundry, receive a newly created picture, and save it to disk. By the end you will have a reusable script that turns any text prompt into an image file, with parameters you can tune for size, quality, and style.

What You Need Before Starting

  • Python 3.9 or newer and VS Code.
  • An image generation model deployed in Microsoft Foundry, such as gpt-image-1 or dall-e-3.
  • Your endpoint URL and API key, stored as environment variables.
  • The openai package and the requests package installed.

Installing the Required Packages

You already know the OpenAI SDK from earlier labs. For downloading the generated image you will also use the small requests library. Install both in one command:

pip install openai requests

Find Your Image Deployment

Open your Foundry project and check the Models or Deployments page for an image model. Copy the deployment name exactly as it appears — this is what your code passes as the model argument, and it is not necessarily the same as the underlying model name.

Image deployments are separate from chat deployments. Even if you have gpt-4o deployed for chat, you still need a dedicated deployment of an image model before the code in this lab will run.

Generate Your First Image

Step 1 - Create the project folder

Create a folder named ai103-lab116 and open it in VS Code. Inside it, create a file called generate_image.py.

Step 2 - Set your environment variables

$env:AZURE_OPENAI_ENDPOINT = "https://YOUR-RESOURCE.openai.azure.com/"
$env:AZURE_OPENAI_KEY = "YOUR_KEY"

Step 3 - Paste the script

Paste the following code and replace YOUR_IMAGE_DEPLOYMENT_NAME with the name of your image deployment:

from openai import AzureOpenAI
import os

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

result = client.images.generate(
    model="YOUR_IMAGE_DEPLOYMENT_NAME",
    prompt="A cozy reading nook by a rainy window, watercolor style",
    size="1024x1024",
    quality="standard",
    n=1,
)

image_url = result.data[0].url
print("Generated image URL:", image_url)

Step 4 - Run the script

python generate_image.py

The script prints a URL pointing to your freshly generated image. Open it in a browser to see the result.

Saving the Image to Disk

A URL is handy for a one-off check, but applications usually need the image as a file. Download the bytes from the URL and write them to disk with requests. Add this to your script:

import requests

image_url = result.data[0].url
image_bytes = requests.get(image_url).content

with open("cozy_nook.png", "wb") as image_file:
    image_file.write(image_bytes)

print("Saved to cozy_nook.png")

Some image deployments return the image directly as a base64 string instead of a URL. To handle both cases, check whether result.data[0].b64_json is present and decode it:

import base64

b64 = result.data[0].b64_json
if b64:
    image_bytes = base64.b64decode(b64)
else:
    image_bytes = requests.get(result.data[0].url).content

Tuning the Output

Experiment with the parameters to see how they change the result:

  • Change prompt to a completely different scene and rerun the script.
  • Set quality="hd" and compare the detail and the generation time.
  • Try other size values such as 1792x1024 for a wide landscape.
  • Where the model supports it, add a style such as "vivid" for more dramatic colors.

Write the prompt into a variable at the top of the script. It makes the script easier to read, and you can later build prompts dynamically from user input or from data in your application.

Troubleshooting Common Errors

Error you may seeMost likely causeFix
404 deployment not foundThe model argument names a chat deployment, not an image deployment.Use the exact name of your image model deployment.
400 Invalid sizeThe requested size is not supported by the model.Use a size documented for your model, such as 1024x1024.
Content filteredThe prompt tripped a content filter.Reword the prompt and follow responsible use guidelines.
NameError: requestsThe requests package is not installed.Run pip install requests and try again.

Summary

You have generated an image from a text prompt with Python, downloaded it to disk, and learned how to handle both URL-based and base64-based responses. You also saw how the size and quality parameters shape the output. In the next chapter you will go one step further and modify images that already exist, rather than starting from a blank canvas.
