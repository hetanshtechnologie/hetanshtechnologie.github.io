Section Quiz

This quiz reviews the Azure AI Search arc: data sources, indexes, indexers, AI enrichment with skillsets, queries, and connecting search to an agent. There are seven questions. The correct answer is marked on each question, and a full answer key follows at the end of the page.

Quiz

Question 1. Which component of the indexing pipeline is responsible for moving documents from a blob container into a search index?

  • A. The data source
  • B. The indexer (correct)
  • C. The skillset
  • D. The field mapping

Question 2. What does the searchable attribute on an index field control?

  • A. Whether the field can be used in filter expressions
  • B. Whether the field appears in query results
  • C. Whether the field can be matched by search queries (correct)
  • D. Whether the field is encrypted at rest

Question 3. Which query mode is generally the strongest default for a RAG assistant that must match both exact product names and paraphrased questions?

  • A. Keyword search only
  • B. Vector search only
  • C. Simple regex search
  • D. Hybrid search, combining keyword and vector (correct)

Question 4. In a chunking-and-embedding skillset, which skill produces the pieces of text that the embedding skill later vectorizes?

  • A. Text Split (correct)
  • B. Entity Recognition
  • C. Document Extraction
  • D. Language Detection

Question 5. Where do a skillset's produced values get written when the indexer finishes running?

  • A. Directly into the source blobs
  • B. Only into the index via output field mappings (and optionally a knowledge store) (correct)
  • C. Into the chat model's training set
  • D. Into the data source definition

Question 6. Which credential is appropriate for a read-only application that queries an index, and should never be used for writes?

  • A. The admin key
  • B. A query key (correct)
  • C. The storage connection string
  • D. The embedding model's API key

Question 7. When an agent is connected to a search index as a tool, who decides whether a user's question triggers a search?

  • A. The indexer, on its schedule
  • B. The data source connector
  • C. The model, based on the tool description and instructions (correct)
  • D. The skillset, before the conversation starts

Answer Key

QuestionAnswerExplanation
1BThe indexer reads from the data source and writes into the index; it is the only component that actively moves data.
2CFields marked searchable participate in matching; other attributes control filtering, sorting, and retrieval.
3DHybrid search runs keyword and vector queries and reranks the combined results, covering exact terms and meaning.
4AThe Text Split skill chunks content into pages of a configured length, which the embedding skill consumes one at a time.
5BSkill outputs flow into the index through output field mappings; a knowledge store can also persist them to Azure Storage.
6BQuery keys allow read-only search requests; the admin key grants full control and must never ship in client code.
7CThe tool description and system instructions let the model judge when to call search and what to query for.

Summary

If you answered most questions correctly, you understand how data sources, indexes, and indexers form the pipeline, how skillsets add chunks and vectors, how query modes change retrieval, and how an agent decides to use the index. If any answers surprised you, revisit the corresponding labs: data sources, index creation, the indexer, enrichment, queries, and the agent connection.
