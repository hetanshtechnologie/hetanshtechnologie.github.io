Lab - Running a simple Python program

With Python and VS Code installed, it is time to run a real program. This lab walks through the edit-run-debug loop you will use for every script in the course: write a file, run it from the terminal, read its output, and fix any errors. You will also install your first Python package — the one that later talks to your GPT model deployment.

What You Will Need

  • Python installed and on your PATH (Lab 233).
  • Visual Studio Code with the Python extension (Lab 234).
  • The ai103-lab workspace folder opened in VS Code.

Step 1: Write a Simple Program

Exercise 1: Create and run your first script

  1. In VS Code, create a new file in ai103-lab and name it hello.py.
  2. Type the following program:
name = input("What is your name? ")
greeting = f"Hello, {name}! Welcome to the AI-103 labs."
print(greeting)
print("Python is working correctly.")
  1. Run it with the play button in the top-right corner.
  2. When the terminal asks for your name, type yours and press Enter.

If everything works you will see a personalized greeting. The input() call pauses the program until you type, so a script that uses input needs the terminal — it cannot just print a result.

Step 2: Run from the Terminal

Now run the same file directly with Python so you become comfortable with the command line:

# Windows PowerShell
python hello.py

# macOS / Linux
python3 hello.py

Both routes run the identical file. The play button is a convenience wrapper around this exact command — knowing the raw command matters because later labs pass arguments and set environment variables before running.

You may see a file called __pycache__ appear in the folder after running. It holds compiled bytecode and is normal — you can ignore it, or add __pycache__/ to a .gitignore if you version-control your work.

Step 3: Read and Fix a Syntax Error

Programs rarely work perfectly the first time. Practice the debugging loop on purpose:

  1. Edit hello.py and remove the closing parenthesis from the print call.
  2. Run the file again. Python stops with a SyntaxError and points at the offending line.
  3. Restore the parenthesis and rerun to confirm the fix.
File "hello.py", line 3
    print(greeting
                ^
SyntaxError: '(' was never closed

Read error messages from the bottom up. The last line names the error type and the line above names the file and line number. Ninety percent of beginner errors are typos like the one you just fixed.

Step 4: Install a Package with pip

Now install the library that will call your model deployment. Open the VS Code terminal and run:

python -m pip install openai

pip downloads the package and its dependencies from the Python Package Index. Verify the installation:

python -c "import openai; print(openai.__version__)"

Always prefer python -m pip over a bare pip. The python -m form guarantees you install into the interpreter you actually run, which eliminates the classic "pip installed it but Python cannot import it" confusion.

Step 5: Write a Program That Uses the Package

Confirm the package works from a real script. Create check_lib.py:

try:
    import openai
    print("openai package version:", openai.__version__)
    print("Import successful - ready for the GPT API labs.")
except ImportError:
    print("The openai package is not installed.")
    print("Run: python -m pip install openai")

Run it with the play button or from the terminal. The import line at the top is the same import every API lab in this course starts with.

If you use a virtual environment, install packages inside it rather than system-wide. The pattern python -m venv .venv, then activating the environment, then python -m pip install openai keeps each project's dependencies isolated. It is best practice, though optional for this course's single-project setup.

Summary

You wrote a script with input and output, ran it from both the editor and the terminal, fixed a syntax error by reading the error message, and installed the openai package that powers the coming API labs. Your environment is fully proven end to end. Next you will call the GPT model directly over HTTP using a REST API.
