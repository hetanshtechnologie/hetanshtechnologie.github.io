Capstone Project - Resources

This page gathers everything you need to start the capstone project: the list of resources you should have created across the course, the Azure services the project uses, the setup commands to prepare your environment, and a checklist you can tick off as you go. Download the capstone bundle if it is provided with your course materials, or reconstruct the files from the labs in this section.

Resources You Should Have by Now

The capstone assumes you completed the core labs and kept the following resources:

ResourceUsed for
Microsoft Foundry resource and projectHosting model deployments, the agent, and project connections
Deployed chat modelAnswering learner questions in the assistant
Deployed embedding modelVectorizing course chunks for retrieval
Azure Blob Storage account with a containerHolding the raw course PDFs
Azure AI Search service with a chunked indexRetrieving relevant course content
Azure CLI signed in, with the search extensionProvisioning and configuring resources

The capstone runs real paid services: model inference for every question, embeddings for every chunk, search indexing, and storage. Keep the corpus small — a handful of course PDFs is plenty — and delete the resource group when the project is complete to avoid ongoing charges.

Setup Checklist

Before building, confirm your environment is ready:

  • Python 3.9 or later with a virtual environment active.
  • Core packages installed: pip install azure-ai-projects azure-identity azure-search-documents azure-storage-blob
  • az login completed so DefaultAzureCredential can authenticate.
  • Your Foundry project connection string saved (do not commit it).
  • Your search service name, index name, and a query key saved.
  • Your blob container name and the path to your local course PDFs.

Use a single set-env.ps1 script or a local .env file that is never committed to hold all your endpoints, names, and keys. The capstone chapters reference environment variables, so centralizing them at the start keeps every later command simple.

Quick Reference Commands

These commands re-establish the working variables if you start a new terminal:

$rg = "rg-ai103"
$searchName = "srch-ai103-<yourname>"
$indexName = "docs-index-chunked"
$storageName = "saai103<yourname>"
$containerName = "docs"

az login
az extension add --name azure-search --only-show-errors

# fetch your admin/query keys when needed
az search query-key list --service-name $searchName --resource-group $rg

What the Capstone Builds

The capstone is the CloudXeus AI Course Assistant: an agent that answers questions about the AI-103 course from its own documents. It retrieves from a search index populated from course PDFs, grounds every answer in that content, and cites the source file. The chapters ahead walk through each piece: data preparation, knowledge bases, model deployment, permissions, and finally the assistant itself.
