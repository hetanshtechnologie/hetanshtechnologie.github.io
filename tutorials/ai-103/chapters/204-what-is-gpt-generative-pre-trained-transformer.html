What is GPT(Generative Pre-Trained Transformer)

GPT stands for Generative Pre-Trained Transformer. It is the name OpenAI gave to its family of large language models, and each word in the acronym describes an important part of how these models work. If you understand the three words, you understand the essence of modern generative AI. This chapter unpacks the acronym piece by piece.

G: Generative

The model's job is to generate — to produce new text rather than to classify or label text. Given a prompt, GPT produces the most likely continuation, token by token. This is what separates it from older natural-language models that mainly detected sentiment or categorised documents.

Being generative means the model is creative by construction. It samples from a probability distribution, so the same prompt can yield different answers. The amount of variety is tunable through parameters such as temperature, which you have already met earlier in this course.

P: Pre-Trained

Before the model is used, it is trained — pre-trained — on a massive corpus of text gathered from books, websites, articles, and code. This happens in two broad stages:

  • Pre-training: the model learns language patterns from raw text by predicting the next token. This stage is enormous in scale and compute and produces a general-purpose model.
  • Fine-tuning: the model is further refined on curated data — for example, examples of helpful conversational responses — so that it behaves as a useful assistant rather than a raw text predictor.

The result of pre-training is what you deploy and call: a model that already knows language, facts, and patterns, which you steer through prompts. This is why you never need to retrain a model to use it.

T: Transformer

Transformer is the neural network architecture that makes GPT possible. It was introduced in a 2017 research paper titled "Attention Is All You Need," and it replaced earlier architectures that struggled with long sequences of text.

The key mechanism in a transformer is self-attention. When the model reads a sentence, it computes how much each word should "pay attention to" every other word in the sentence. This allows the model to handle relationships between distant words, which is essential for understanding language.

Consider the sentence: "The dog chased the ball, and then it disappeared." The word "it" refers to the ball, but the word that resolves the reference is far away in the sentence. Attention lets the model connect "it" to "ball" even across many words — a task earlier architectures handled poorly.

Transformers are also the architecture behind the language models used in Microsoft Foundry and Azure OpenAI. When you deploy a GPT model in this course, you are deploying a transformer-based, pre-trained, generative model.

How GPT Generates Text

The generation loop is simple to describe and happens rapidly in practice:

  1. Your prompt is converted into tokens.
  2. The model reads all the tokens and computes, for each possible next token, a probability.
  3. The model picks a token according to those probabilities.
  4. The chosen token is appended to the sequence, and the process repeats.
  5. Generation stops when the model produces an end-of-sequence token or hits a length limit.

This is why a long answer is really a chain of hundreds of small predictions. It also explains the two levers you control: how the model picks each token (sampling parameters) and how long it is allowed to keep going (max_tokens).

What This Means for You

Understanding GPT's three parts changes how you work with it:

  • Because it is generative, you tune its creativity rather than its accuracy directly.
  • Because it is pre-trained, your job is prompt design and orchestration, not training.
  • Because it is a transformer, it works best when you keep your most important instructions and context close to the question, and use attention-friendly, well-structured prompts.

Summary

GPT stands for Generative Pre-Trained Transformer. The model generates text by sampling one token at a time, it learned language by pre-training on enormous text corpora before any fine-tuning, and it uses the transformer architecture's attention mechanism to understand relationships between words. Together, these three ideas explain how the model works and how to work with it. The next chapter looks at the model lineup — the different GPT and related models OpenAI offers.
