Installing Python and VS Code

Every coding chapter in this course needs a working Python environment and an editor. This chapter walks you through installing Python and Visual Studio Code, then verifies the setup with a tiny script so you know everything works before the labs begin. You will only need to do this once.

Why Python and VS Code

Python is the de facto language for AI development because of its readable syntax and its ecosystem of libraries for HTTP, data, and machine learning. Visual Studio Code (VS Code) is a free, lightweight editor that works well with Python thanks to first-class extensions. Together they give you a professional development setup with nothing to pay and no heavy IDE to wrestle with.

Install Python

Python runs on every major operating system. The download steps differ slightly per platform, but the principle is the same: install the latest stable Python 3 release from the official distribution.

  • Windows: Download the installer from the official Python site. During setup, check the box that says Add python.exe to PATH — skipping this is the most common cause of "python is not recognized" errors.
  • macOS: Download the installer from the official site, or use a package manager such as Homebrew if you already have it.
  • Linux: Use your distribution's package manager. On Ubuntu-family systems the command is sudo apt install python3 python3-pip.

Download Python only from the official source. Third-party "fast download" sites have been known to bundle unwanted software. If the URL does not belong to the Python Software Foundation, it is the wrong place.

Verify the Installation

After installing, open a terminal and confirm both the interpreter and the package installer respond:

python --version
pip --version

You should see a version number for each, such as Python 3.12.x. On some systems the command is python3 instead of python — if one fails, try the other. If neither works on Windows, re-run the installer and confirm Add python.exe to PATH is checked, then open a new terminal.

The latest stable release is the right choice for this course. Do not install the newest pre-release or an obsolete legacy version — either can reject packages or behave differently from the rest of the class examples.

Install VS Code

Visual Studio Code is a single download that installs like any desktop application. After installation, add two extensions that make Python development smooth:

  1. Python (from Microsoft): adds IntelliSense, debugging, and environment management for Python.
  2. Pylance (usually bundled with the Python extension): provides fast, accurate code completion and type checking.

Open the Extensions panel, search for Python, and click Install. The editor handles the rest.

Create a Virtual Environment

Projects in Python should each use a virtual environment — an isolated folder that holds the packages for that project. This prevents one project's dependencies from conflicting with another's. From your project folder:

# Create the virtual environment
python -m venv .venv

# Activate it
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

Once activated, your prompt shows (.venv) in front. Now install the packages this course needs and record them in requirements.txt:

pip install requests python-dotenv
pip freeze > requirements.txt

requests makes HTTPS calls easy, and python-dotenv loads your .env secret file. When you activate the environment before running a script, both packages are available; when you close the terminal, the environment stays on disk for next time.

Verify Everything with a Test Script

The fastest way to know your setup works is to run a script. Create a file named hello.py with this content and run it:

import platform
import sys

print(f"Python: {sys.version_info.major}.{sys.version_info.minor}")
print(f"Running on: {platform.system()} {platform.release()}")

try:
    import requests
    print("requests: installed")
except ImportError:
    print("requests: MISSING - run: pip install requests")
python hello.py

If you see the Python version, your operating system, and requests: installed, your environment is ready. If a dependency is missing, install it inside the active virtual environment and run the script again.

Make it a habit to create a virtual environment in every new project and to run scripts only with the environment activated. This one habit eliminates the most common "works on my machine" failures when you move between projects.

Optional: Set Up VS Code for the Project

For the best experience, tell VS Code which interpreter to use. Open your project folder in VS Code, then press the keyboard shortcut to open the command palette and choose Python: Select Interpreter; pick the interpreter inside your .venv folder. VS Code will then use the correct environment for running and debugging your scripts automatically.

Summary

You installed Python and VS Code, verified both respond on the command line, created an isolated virtual environment, installed the two packages this course uses, and ran a test script that confirmed everything works. Your machine is now ready for the first API-call lab, where you will connect this environment to your Foundry deployment.
