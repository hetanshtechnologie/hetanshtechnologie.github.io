Lab - Computer Vision - Python - Image Tagging

In this lab you move from the browser to Python. You will send an image file to your Computer Vision resource using the requests library, request the tags feature, and print every detected tag with its confidence score. This is the pattern you will reuse in every remaining vision lab, with only the feature name and the response parsing changing.

What You Need

  • Your Computer Vision endpoint and key from the resource lab.
  • Python 3 with the requests package installed.
  • A local test image, for example test.jpg in the same folder as your script.

Set Up the Script

Create a file vision_tags.py. Store the endpoint and key in environment variables so they never sit in the source file:

set COMPUTER_VISION_ENDPOINT=https://YOURNAME.cognitiveservices.azure.com/
set COMPUTER_VISION_KEY=YOUR_KEY

The endpoint is the base URL without a trailing path — for example https://cv-ai103-demo.cognitiveservices.azure.com/. The script appends the image analysis path itself.

Write the Tagging Code

import os
import requests

ENDPOINT = os.environ["COMPUTER_VISION_ENDPOINT"]
KEY = os.environ["COMPUTER_VISION_KEY"]

ANALYZE_URL = ENDPOINT.rstrip("/") + "/computervision/imageanalysis:analyze"
params = {
    "api-version": "2024-02-01",
    "features": "tags",
}

with open("test.jpg", "rb") as f:
    image_data = f.read()

headers = {
    "Content-Type": "application/octet-stream",
    "Ocp-Apim-Subscription-Key": KEY,
}

response = requests.post(ANALYZE_URL, params=params, headers=headers, data=image_data)
response.raise_for_status()

result = response.json()
for tag in result["tagsResult"]["values"]:
    print(f"{tag['name']:<20} {tag['confidence']:.2f}")

Run and Observe

Exercise 1: Tag a local image

  1. Save the script above as vision_tags.py.
  2. Place your test image next to the script and name it test.jpg, or change the filename in the script.
  3. Open a terminal, set the two environment variables, and run python vision_tags.py.
  4. Read the printed output. Each line shows a tag and its confidence. The most confident tags should describe the main subject of the image.
  5. Repeat with a second, different image and compare the tag lists.

How the Code Works

  • Request body: The raw image bytes are sent as the request body with a Content-Type of application/octet-stream. You can also send a public image URL as JSON instead — the service accepts both.
  • Query parameters: features=tags tells the service to run only tagging, which keeps the response small and the call cheap.
  • Authentication: The Ocp-Apim-Subscription-Key header carries your key. Azure validates it before processing the image.
  • Response shape: Tags live under tagsResult.values, each with name and confidence.

Sending an Image URL Instead

If your image is already hosted on the web, you can skip reading the file and send a URL in JSON:

import os
import requests

ENDPOINT = os.environ["COMPUTER_VISION_ENDPOINT"]
KEY = os.environ["COMPUTER_VISION_KEY"]

ANALYZE_URL = ENDPOINT.rstrip("/") + "/computervision/imageanalysis:analyze"
headers = {"Content-Type": "application/json", "Ocp-Apim-Subscription-Key": KEY}
params = {"api-version": "2024-02-01", "features": "tags"}
body = {"url": "https://example.com/photos/sample.jpg"}

response = requests.post(ANALYZE_URL, params=params, headers=headers, json=body)
response.raise_for_status()

for tag in response.json()["tagsResult"]["values"]:
    print(f"{tag['name']:<20} {tag['confidence']:.2f}")

When you send an image by URL, make sure the host allows Azure to fetch it. Some sites block automated downloads or require authentication, which shows up as an error in the response.

Common Issues

  • 401 Unauthorized: the key is wrong or contains a stray space. Re-copy it from the Keys and Endpoint page.
  • 404 Not Found: the endpoint is malformed or the API version is unsupported. Check the exact URL your script builds.
  • 429 Too Many Requests: you hit the resource rate limit, usually on the free tier. Wait a minute and retry.
  • KeyError: 'tagsResult': the response did not contain tags. Confirm the features parameter value is exactly tags.

Summary

You built a complete Python tagging pipeline: read an image, POST it to the Image Analysis endpoint with the tags feature, and print each tag with its confidence. This endpoint, feature list, and parsing pattern carry over directly into the caption, object detection, OCR, and brand detection labs that follow.
