Lab - Computer Vision - Image Tagging

With a Computer Vision resource in place, you can start asking it to look at images. In this lab you will run the image tagging capability from the browser, using the Vision Studio web portal. Tagging answers the question "what is in this picture?" by returning a list of descriptive words — like person, dog, outdoor — each with a confidence score. This is your first practical look at how the service behaves before you move on to calling it from code.

What Tagging Returns

Unlike a single label, tagging returns a list. A photo of a birthday party might be tagged people, celebration, cake, and indoors at the same time. Each tag comes with a confidence score between 0 and 1 that tells you how sure the model is about that tag. The service also returns a short caption separately; in this lab you focus on the tags themselves.

What You Need

  • Your Computer Vision resource created in the previous lab.
  • A test image. Use a photo from your own computer, or fetch a public image from the web.

Pick an image with a clear subject: a single object on a plain background produces crisp, obvious tags and is easier to interpret than a cluttered scene.

Step-by-Step: Tag an Image in Vision Studio

Exercise 1: Tag an image through the Vision Studio portal

  1. Open a browser and go to Vision Studio at https://portal.vision.cognitive.azure.com/. Sign in with your Azure account.
  2. If prompted, choose the directory and the Azure subscription that contains your Computer Vision resource.
  3. On the home page, select the Image analysis tile to open the image analysis features.
  4. In the image analysis screen, find the Try with one of your images area. Browse for a local image or paste the URL of a public image.
  5. Confirm the resource selector at the top is pointed at the Computer Vision resource you created in the previous lab.
  6. In the Features panel, make sure Extract common tags is enabled. Click Run analysis.
  7. Read the Detected tags results. You will see each tag with a confidence score. Compare how confident the model is about the main subject versus the background elements.
  8. Run the analysis again with a different image and watch how the tag list changes. Notice whether any tags are wrong or unexpected — that is normal, and it is why confidence scores matter.

Vision Studio calls the exact same REST API your code will call in later labs. Everything you see in the browser — the tags, the confidence scores — comes from the same JSON response your applications will parse. The portal is simply a friendly front end for the service.

What the Response Looks Like

Under the hood, the portal sends an analysis request and receives JSON. The tags appear in a tagsResult block:

{
  "metadata": {"width": 640, "height": 480},
  "tagsResult": {
    "values": [
      {"name": "outdoor", "confidence": 0.99},
      {"name": "mountain", "confidence": 0.97},
      {"name": "sky", "confidence": 0.95},
      {"name": "hiking", "confidence": 0.82},
      {"name": "person", "confidence": 0.61}
    ]
  }
}

Notice how the tags are ordered by confidence. The subject of the image tops the list, and less certain tags fall to the bottom. Applications commonly keep only the tags above a threshold, such as 0.7, to filter out noise.

Reading the Results Critically

  • Tags are predictions, not facts. A tag with a high score can still be wrong for an unusual image.
  • Tags describe the whole image, not the position of things inside it. Locating where objects are is object detection, which comes in a later lab.
  • Compare tags across several images to develop a feel for how the model generalizes.

Do not use raw tags as user-facing classifications without review. A retail app that auto-categorizes products by tags will occasionally mislabel an item; add a confidence threshold and a manual review path before trusting tags for decisions that matter.

Summary

You used Vision Studio to run image tagging against your Computer Vision resource and saw how tags come back as a confidence-scored list. You also learned to read the underlying JSON that applications will parse. In the next lab you will reproduce this exact capability in Python.
