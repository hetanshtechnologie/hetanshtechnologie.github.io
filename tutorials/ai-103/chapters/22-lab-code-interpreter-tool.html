Lab - Code Interpreter Tool

In this lab you will give the model the ability to write and run code. The code interpreter tool takes a piece of Python as input, executes it in a sandboxed process, and returns the standard output to the model. With this tool the model can perform arithmetic, analyze data, and generate charts instead of merely describing how to do so.

What You Need

  • Your endpoint and key environment variables.
  • A deployed chat model.
  • Python installed (the same installation you run your scripts with).

Running code that a model writes is risky if that code comes from an untrusted source. The lab executes code in a temporary file with a timeout, but a production system should run generated code in a proper sandbox, container, or dedicated execution service with no access to secrets.

The Tool Implementation

Create code_interpreter.py in a folder ai103-lab22. The implementation writes the incoming code to a temporary file, runs it with a fresh Python process, and returns the captured output:

import subprocess
import tempfile
import os

def run_python(code: str) -> str:
    with tempfile.NamedTemporaryFile("w", suffix=".py", delete=False) as f:
        f.write(code)
        path = f.name
    try:
        result = subprocess.run(
            ["python", path], capture_output=True, text=True, timeout=30
        )
        output = result.stdout
        if result.stderr:
            output += "\nSTDERR:\n" + result.stderr
        return output
    except subprocess.TimeoutExpired:
        return "Error: the script timed out after 30 seconds."
    finally:
        os.unlink(path)

Keep the return value compact. The model will read whatever string you return, so returning only stdout and a short error message keeps the tool cheap and reliable.

Advertise the Tool to the Model

Add the schema so the model knows run_python exists, plus the client and the message list:

from openai import AzureOpenAI

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

tools = [
    {
        "type": "function",
        "function": {
            "name": "run_python",
            "description": "Execute Python code and return its standard output. Use this for calculations and data processing.",
            "parameters": {
                "type": "object",
                "properties": {
                    "code": {"type": "string", "description": "The complete Python source to execute."}
                },
                "required": ["code"],
            },
        },
    }
]

messages = [
    {"role": "system", "content": "When a task involves exact calculation or data processing, write and run Python code with the run_python tool."},
    {"role": "user", "content": "Compute the first 12 numbers in the Fibonacci sequence and print them one per line."},
]

Drive the Loop

The loop is identical to the web search lab. Run the model, and if it requests the tool, execute the generated code and feed the output back:

import json

response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    messages=messages,
    tools=tools,
)

message = response.choices[0].message
messages.append(message)

if message.tool_calls:
    for call in message.tool_calls:
        print("Code generated by the model:\n" + call.function.arguments)
        arguments = json.loads(call.function.arguments)
        result = run_python(arguments["code"])
        print("--- tool output ---")
        print(result)
        messages.append({
            "role": "tool",
            "tool_call_id": call.id,
            "content": result,
        })

final_response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    messages=messages,
    tools=tools,
)
print("--- final answer ---")
print(final_response.choices[0].message.content)

Step 1 - Run the Fibonacci example

python code_interpreter.py

You should see the model's generated code, the printed Fibonacci numbers as the tool output, and then a final answer from the model that summarizes the result.

Step 2 - Ask for a chart

Replace the user question with: "Write Python code that creates a bar chart of the sales values [12, 19, 7, 25] and saves it as chart.png." The model will generate matplotlib code, your script will run it, and you can open chart.png afterwards.

When the generated code needs a library, the model may import it for you. Make sure the needed packages, such as matplotlib, are installed in the Python environment that runs the tool. Install with pip install matplotlib if the chart step fails on import.

Common Issues

  • ModuleNotFoundError in the tool output: the library is not installed in the executing environment — install it.
  • Timeout: generated code loops forever — lower the timeout or cap the iterations.
  • Empty output: the model wrote to a file instead of printing — ask it to print() results.
  • Charts are invisible: the file is created in the working directory — add a print() of the absolute path or read the file yourself.

Summary

You have given the model a code interpreter: a tool that writes Python, runs it in a subprocess, and returns the output. With it the model can compute exact answers and generate files such as charts. Combined with web search, you now have a model that can gather current information and perform computation — the two capabilities at the heart of agentic systems.
