Lab - Azure AI Custom Vision - Image classification model

Now that both Custom Vision resources exist, you will build your first image classification model in the Custom Vision portal. You will create a project, upload and tag example images, run a training job, look at the evaluation results, and publish the best iteration to a prediction endpoint. By the end you will have a model your applications can call with a normal image URL or image bytes.

Prepare a Small Dataset

For this lab you need two categories with enough variety that a model can actually learn them. A classic starter project is dogs vs. cats, or anything with two visually distinct classes you can photograph or download:

  • 30 or more images per class — start small but not tiny. Ten images per class will train, but the metrics will be noisy.
  • Vary the background, lighting, and angle within each class. A model trained on one background will fail in the real world.
  • Keep the subject prominent. The object you want to classify should fill most of the frame.

Training uses an automatic split of your uploaded images — roughly 80% to learn and 20% to evaluate. The evaluation numbers only mean something if the images in each class come from a reasonably varied set, because the split picks random images rather than curated ones.

Create the Project

Step 1 - Open the Custom Vision portal

Browse to customvision.ai and sign in with the same Azure identity you used to create the resources. On first sign-in you will be asked to select an Azure account for training and one for prediction.

Step 2 - Assign the resources

In the settings, choose cv-training-ai103 as the training resource and cv-prediction-ai103 as the prediction resource. If they do not appear in the dropdown, sign out and sign back in, then re-select your directory.

Step 3 - Create a new project

Click New project and configure it:

  • Name: ai103-dogs-vs-cats
  • Project type: Classification
  • Classification types: Multiclass (single tag per image)
  • Domains: General

Create the project and you will land on the image-upload screen.

Upload and Tag Images

Step 4 - Add the first class

Click Add images, select all of your dog pictures, and type the tag dog in the My Tags box before uploading. Repeat for the cat pictures with the tag cat.

Tag in the same upload dialog, not after. When you type the tag name while uploading, the portal assigns it to every image in that batch automatically. Adding tags later, image by image, is slower and easier to get wrong.

Step 5 - Review the tags

Switch the filter at the top to each tag in turn and check the images look correct. A single image tagged with the wrong class quietly poisons the training data. Untag and re-tag any mistakes by selecting the image and using the Edit tags action.

Train the Model

Step 6 - Start training

Click the Train button at the top of the page, leave the default settings (fast training, no advanced options), and confirm. Training takes a few minutes for a small dataset — the page will show a spinner and then the evaluation results.

Read the Evaluation Results

The results page reports precision and recall for the whole model and per tag:

  • Precision — of everything the model called a dog, how much was really a dog?
  • Recall — of all the real dogs in the test set, how many did the model catch?
  • AP (Average Precision) — the area under the precision-recall curve, a single summary number.

For a first model with a small dataset, precision and recall in the 80s is a good sign. If one class scores far worse than the other, the usual causes are too few images for that class, images that look too similar to each other, or a class that overlaps visually with the other.

Publish the Iteration

Step 7 - Publish to the prediction endpoint

Every training run creates a numbered iteration. To call the model from an application you must publish the current iteration:

  1. Click Publish (or Prediction URL in older versions of the portal).
  2. Give the published model a name, for example dogs-cats-v1.
  3. Choose cv-prediction-ai103 as the prediction resource.

Once published, the Prediction URL dialog shows the exact endpoint URL for both the URL and image-file modes. Copy these — the Python lab uses them.

Test with a New Image

In the portal, use Quick Test on the Predictions tab. Upload an image neither used in training and check the confidence scores. A confident, correct prediction confirms the whole pipeline works before you touch any code.

Summary

You built and published your first Custom Vision classification model: you created a project, uploaded and tagged a small dataset, trained an iteration, read its precision and recall, and published it to the prediction resource. This trained iteration is now an HTTP endpoint. The next chapter explains what the evaluation numbers mean in detail, and the Python lab after that shows you how to call the published endpoint from code.
