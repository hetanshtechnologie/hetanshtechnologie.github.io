Lab - Python - Azure AI Content Safety as a service - Detect Harmful images

Content Safety can analyze images as well as text. The image moderation API examines visual content and reports severity scores for harmful categories such as hate, violence, sexual content, and self-harm. In this lab you will call the service from Python to detect whether an image is safe, using the official Azure SDK.

Prerequisites

  • The Content Safety resource from an earlier lab, with its endpoint and key.
  • Python 3.8 or later installed on your machine.
  • A test image — any JPG or PNG file — stored in a known path on disk.

Installing the SDK

Install the Content Safety client library into your environment:

pip install azure-ai-contentsafety azure-core

Run this in the same virtual environment you will use for the lab. If you prefer to avoid a global install, create a virtual environment first with python -m venv .venv and activate it before running pip.

Writing the Detection Script

Step 1 — Create the script

Create a file named detect_image.py with the following code:

from azure.ai.contentsafety import ContentSafetyClient
from azure.core.credentials import AzureKeyCredential
from azure.ai.contentsafety.models import AnalyzeImageOptions, ImageData

ENDPOINT = "YOUR_ENDPOINT"
KEY = "YOUR_KEY"
IMAGE_PATH = r"C:\path\to\your\test.jpg"

client = ContentSafetyClient(
    endpoint=ENDPOINT,
    credential=AzureKeyCredential(KEY),
)

with open(IMAGE_PATH, "rb") as image_file:
    image_bytes = image_file.read()

request = AnalyzeImageOptions(
    image=ImageData(content=image_bytes)
)

result = client.analyze_image(options=request)

for analysis in result.categories_analysis:
    label = analysis.category
    severity = analysis.severity
    status = "flagged" if severity > 0 else "clean"
    print(f"{label}: severity {severity} ({status})")

Step 2 — Substitute your values

  1. Replace YOUR_ENDPOINT with your resource endpoint URL.
  2. Replace YOUR_KEY with one of your resource keys.
  3. Point IMAGE_PATH at a real image on your machine.

Step 3 — Run the script

python detect_image.py

You should see one line per category. A completely safe image prints a severity of 0 for every category.

Interpreting the Output

Each result entry contains a category name and a severity score:

  • Severity 0: nothing detected for that category.
  • Higher severity: the more severe the content, the larger the number. Your application sets a threshold and reacts when any category crosses it.

A typical output for a safe image:

Hate: severity 0 (clean)
Sexual: severity 0 (clean)
Violence: severity 0 (clean)
SelfHarm: severity 0 (clean)

Adding a Policy Layer

Raw scores are only useful with a decision rule. Extend the script to block anything above your chosen threshold:

THRESHOLD = 2

blocked = False
for analysis in result.categories_analysis:
    if analysis.severity > THRESHOLD:
        blocked = True
        print(f"Blocked: {analysis.category} severity {analysis.severity}")

if blocked:
    print("Image rejected: content exceeds threshold")
else:
    print("Image accepted")

Start with a conservative threshold during development and relax it only after testing against a set of known-good and known-bad images. What feels like a minor tweak can flip an image from accepted to rejected.

The free tier has rate limits measured in requests per minute. If you loop over many images during testing you may see throttling errors. Add a small sleep between calls or use a paid tier for load testing.

Summary

You called Azure AI Content Safety from Python to analyze an image, read the per-category severity scores, and added a threshold-based policy that accepts or rejects the image. This same pattern — submit content, parse severity, apply a rule — is the foundation for every Content Safety integration you build.
