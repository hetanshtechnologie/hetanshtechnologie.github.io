Lab - Speech Synthesis Markup Language

Plain text synthesis gives you a voice, but not full control over that voice. Speech Synthesis Markup Language (SSML) is an XML vocabulary that tells the service exactly how to speak: which voice to use, how fast and how high, where to pause, and even what emotional style to adopt. In this lab you will write an SSML document by hand, send it through the Speech SDK, and hear how fine-grained markup changes the delivery.

Exercise: Controlling synthesis with SSML

Step 1 — Understand the SSML structure

An SSML document is a <speak> root element that wraps a <voice> element. Inside the voice you can add <prosody> for rate and pitch, <break> for pauses, and <mstts:express-as> for emotional styles. The example below reads at a slowed pace, drops the pitch slightly, pauses after the first phrase, and adds a breath before the last line.

Step 2 — Write the SSML document

Create ssml_demo.py with the following content. Note that the angle brackets inside the Python string are escaped so the XML reaches the service intact.

import os

import azure.cognitiveservices.speech as speechsdk

SPEECH_KEY = os.environ.get("SPEECH_KEY", "YOUR_SPEECH_KEY")
SPEECH_REGION = os.environ.get("SPEECH_REGION", "YOUR_SPEECH_REGION")

speech_config = speechsdk.SpeechConfig(subscription=SPEECH_KEY, region=SPEECH_REGION)
audio_config = speechsdk.audio.AudioOutputConfig(filename="ssml_demo.wav")
synthesizer = speechsdk.SpeechSynthesizer(speech_config=speech_config, audio_config=audio_config)

ssml = """<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis"
         xmlns:mstts="https://www.w3.org/2001/mstts" xml:lang="en-US">
  <voice name="en-US-AriaNeural">
    <mstts:express-as style="friendly">
      <prosody rate="0.8" pitch="-2st">
        Thanks for completing this exercise.<break time="700ms"/>
        Now the audio matches exactly what we designed.
      </prosody>
    </mstts:express-as>
  </voice>
</speak>"""

result = synthesizer.speak_ssml_async(ssml).get()

if result.reason == speechsdk.ResultReason.SynthesizingAudioCompleted:
    print("Saved to ssml_demo.wav")
else:
    cancellation = speechsdk.CancellationDetails(result)
    print(f"Canceled: {cancellation.reason}; {cancellation.error_details}")

Step 3 — Run and listen

python ssml_demo.py

Play ssml_demo.wav next to the plain clip you generated in the previous lab. The marked-up version uses a different voice, speaks more slowly, sits slightly lower in pitch, pauses deliberately between the two sentences, and carries a warmer tone.

Common SSML Elements

A few elements cover most of what you will want to control:

ElementWhat it controlsExample
<prosody>Rate, pitch, and volumerate="0.9", pitch="-2st"
<break>Pauses between wordstime="500ms"
<emphasis>Stress on a wordlevel="strong"
<mstts:express-as>Emotional stylestyle="cheerful"
<phoneme>Forced pronunciationIPA alphabet spelling

Checking Which Voices Support Which Styles

Not every neural voice supports every emotional style. The list of styles is part of each voice's metadata, and the service exposes a REST endpoint that returns the full voice catalog, including which styles are available per voice. Trying a style the voice does not support produces an error or silently ignores the element, so always verify against the catalog when you pick a style in production.

Speech Studio can preview SSML directly: paste your document into the editor on the Text to Speech page and press play. This is a fast way to iterate on markup before wiring it into code.

Do not paste unescaped SSML into a web page without care. If your application accepts SSML from users and renders it in HTML, treat it like any untrusted input and escape it — otherwise a crafted string could break out of your markup.

Summary

You wrote an SSML document by hand, passed it to the Speech SDK, and heard how rate, pitch, pauses, and emotional style change the delivery. SSML is the mechanism that takes synthesized speech from functional to polished. In the next chapter you turn the direction around and start transcribing audio back into text.
