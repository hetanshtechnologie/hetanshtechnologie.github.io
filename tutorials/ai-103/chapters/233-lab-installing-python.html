Lab - Installing Python

Every Python lab in the rest of this course runs against a local Python installation. This lab installs Python on your machine and verifies that it works from the command line. Whether you use Windows, macOS, or Linux, the goal is the same: a python command on your PATH that you can invoke from any terminal.

What You Will Need

  • A computer with at least 2 GB of free disk space.
  • Permission to install software on that computer.
  • An internet connection to download the installer.

Step 1: Check What Is Already Installed

Exercise 1: Detect an existing Python installation

  1. Open a terminal. On Windows, open PowerShell; on macOS, open Terminal.
  2. Type the following command and press Enter:
python --version
  1. If you see a version number like Python 3.12.x, Python is already installed. Verify it is modern enough:
python --version
python -c "print('hello')"
  1. If the command is not found, try python3 --version — some systems name the binary python3.

If python is missing but py works on Windows, you have the Python launcher instead. The command py --version should report a version; you can still proceed to the next lab using py in place of python, or install a proper version below.

Step 2: Download the Installer

If Python is not installed (or the version is older than 3.9), install a current version:

  1. Open the official Python downloads page in your browser (python.org/downloads).
  2. Choose the latest stable release and download the installer for your operating system.
  3. On Windows, select the 64-bit installer (Windows installer (64-bit)). On macOS, download the universal2 installer for the current major release.

Only download Python from python.org or your operating system's package manager. Third-party sites sometimes bundle unwanted software with their installers.

Step 3: Install Python

Exercise 2: Install with the recommended settings

  1. Run the installer you downloaded.
  2. On Windows, tick the box Add python.exe to PATH at the bottom of the first screen. This is the most common reason installs fail later.
  3. Click Install Now and wait for the installer to finish.
  4. Close the installer when it reports success.
# macOS alternative using Homebrew
brew install python
# Ubuntu / Debian Linux alternative
sudo apt update
sudo apt install python3 python3-pip

You only need one working Python. The official installer and the package-manager routes both give you a usable python (or python3) command plus the pip package manager that installs libraries like the OpenAI SDK.

Step 4: Verify the Installation

Close and reopen your terminal so the new PATH settings take effect, then confirm everything works:

python --version
python -c "print(2 + 2)"
python -m pip --version

You should see a Python version, the number 4, and a pip version line. That combination means the interpreter and the package installer are both on your PATH and ready to use.

Keep a note of your exact Python version. If a later lab behaves unexpectedly, the version number is the first thing to mention when you ask for help.

Troubleshooting

  • "python is not recognized" (Windows): reopen the terminal, or reinstall and confirm Add python.exe to PATH was checked.
  • python3 needed on macOS/Linux: if python is absent but python3 works, use python3 everywhere this course writes python.
  • pip not found: run python -m ensurepip --upgrade, then retry the pip check.

Summary

You checked for an existing Python, downloaded and installed a current version, added it to your PATH, and verified the interpreter and pip both run from a terminal. Your machine is now ready for the editor in the next lab, where you will build a proper workspace for writing Python.
