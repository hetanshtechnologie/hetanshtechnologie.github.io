Lab - Speech Translation

In this lab you will build the speech-native translation path from the previous chapter: a Python program that listens to spoken English and streams the translation into Spanish, both as text on the console and as synthesized audio. This is the same architecture that powers live multilingual captions, and it uses the Speech SDK's translation recognizer.

What the Translation Recognizer Does

The SpeechTranslationRecognizer combines three jobs in one object. It recognizes the source-language speech, translates each recognized phrase into the target language, and optionally synthesizes the translation into audio. Events fire as translations are produced, so you can render captions live just as you did with plain recognition in an earlier lab.

Exercise: Streaming speech translation with the SDK

Step 1 — Set the target language

You need your Speech key and region, plus a target language code. Spanish uses es-ES (Castilian) or es-MX (Mexican) — pick one. The source language is detected from the configured recognition language.

Step 2 — Write the translation script

Create translate_speech.py with the following code. It captures from the default microphone, prints partial translations as you speak, and synthesizes each final translation into an audio file.

import os

import azure.cognitiveservices.speech as speechsdk

SPEECH_KEY = os.environ.get("YOUR_SPEECH_KEY", "")
SPEECH_REGION = os.environ.get("YOUR_SPEECH_REGION", "")
TARGET_LANGUAGE = "es-ES"
VOICE_NAME = "es-ES-ElviraNeural"

speech_config = speechsdk.SpeechConfig(
    subscription=SPEECH_KEY,
    region=SPEECH_REGION,
)
speech_config.speech_recognition_language = "en-US"

audio_config = speechsdk.audio.AudioConfig(use_default_microphone=True)

translation_config = speechsdk.translation.SpeechTranslationConfig(
    subscription=SPEECH_KEY,
    region=SPEECH_REGION,
)
translation_config.speech_recognition_language = "en-US"
translation_config.add_target_language(TARGET_LANGUAGE)
translation_config.speech_synthesis_voice_name = VOICE_NAME

recognizer = speechsdk.translation.TranslationRecognizer(
    translation_config=translation_config,
    audio_config=audio_config,
)

def on_partial(evt):
    translation = evt.result.translations.get(TARGET_LANGUAGE, "")
    print(f"\rpartial: {evt.result.text}  >  {translation}", end="", flush=True)

def on_recognized(evt):
    result = evt.result
    if result.reason == speechsdk.ResultReason.TranslatedSpeech:
        translation = result.translations.get(TARGET_LANGUAGE, "")
        print(f"\rfinal:   {result.text}  >  {translation}")
    elif result.reason == speechsdk.ResultReason.NoMatch:
        print("\r(no speech heard)")

recognizer.recognizing.connect(on_partial)
recognizer.recognized.connect(on_recognized)

print("Speak English now. Translations will appear as you talk.")
print("Press Ctrl+C to stop.")
recognizer.start_continuous_recognition()

import time
try:
    while True:
        time.sleep(0.5)
except KeyboardInterrupt:
    recognizer.stop_continuous_recognition()
    print("\nSession stopped.")

Step 3 — Run the live translation

python translate_speech.py

Speak a few short English sentences. You should see the Spanish translation appear live on the console, updating as partial results arrive. Press Ctrl+C to stop.

Step 4 — Save translated audio

To also hear the translation, modify on_recognized so each final translation is synthesized to a numbered file:

import threading

_audio_lock = threading.Lock()
_audio_index = 0

def save_translation_audio(text):
    global _audio_index
    with _audio_lock:
        _audio_index += 1
        synthesizer = speechsdk.SpeechSynthesizer(speech_config=speech_config)
        result = synthesizer.speak_text_async(text).get()
        if result.reason == speechsdk.ResultReason.SynthesizingAudioCompleted:
            speechsdk.AudioDataStream(result).save_to_file(
                f"translation_{_audio_index:03d}.wav"
            )

Call save_translation_audio(translation) inside on_recognized, then rerun the lab. Each final phrase produces a WAV file with the Spanish voice reading the translation.

Understanding the Events

As with plain recognition, partial events arrive continuously while you speak. Each event's result.translations is a dictionary keyed by target language code, which is why the code looks up [TARGET_LANGUAGE]. If you add more than one target language, each event carries a translation for every language you registered — one session, many languages.

Try registering two target languages, for example es-ES and fr-FR, and print both. You will see the same sentence translated to both languages in a single event stream — a preview of how a single source language can feed captions in many languages simultaneously.

Comparing with the LLM Path

This lab is the "speech-native" architecture from the comparison chapter. Notice what you did not write: no JSON call to a translation model, no prompt, no glossary, no waiting for a full transcript before anything appeared. The trade-off, as discussed, is that you have no style or terminology control. If you translate "our net promoter score rose to 62" through this lab, the speech service will translate it plainly; an LLM could be told to keep the metric name exact and explain it for a marketing audience.

Summary

You built a streaming speech translation application with SpeechTranslationConfig and TranslationRecognizer. It recognizes spoken English, translates it live into Spanish, prints partial translations, and synthesizes the results into audio files.
