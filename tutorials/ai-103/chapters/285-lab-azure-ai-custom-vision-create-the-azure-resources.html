Lab - Azure AI Custom Vision - Create the Azure resources

Before any Custom Vision project can exist, you need the two Azure resources that power it: one for training and one for prediction. In this lab you will create both with the Azure CLI, fetch their keys and endpoints, and verify they are reachable. Everything you create here is reused by the following labs, so keep the values handy.

What You Need Before Starting

  • An Azure subscription and the Azure CLI signed in.
  • Permission to create Cognitive Services resources.
  • A note-taking tool for your endpoint, keys, and resource names.

Create the Resource Group

Step 1 - Create a resource group

az group create --name rg-cv-ai103 --location eastus

Both Custom Vision resources will live in this group so they can be cleaned up together.

Create the Training Resource

The training resource has the CustomVision.Training kind. It is the account that owns projects, uploaded images, and trained iterations.

Step 2 - Create the training account

az cognitiveservices account create \
    --name cv-training-ai103 \
    --resource-group rg-cv-ai103 \
    --kind CustomVision.Training \
    --sku S0 \
    --location eastus

Step 3 - List its key

az cognitiveservices account keys list \
    --name cv-training-ai103 \
    --resource-group rg-cv-ai103

Depending on which Azure region the account lands in, the training endpoint may be hosted on the regional Custom Vision domain rather than the standard cognitiveservices.azure.com domain. The Azure CLI returns the exact endpoint in the account details — always copy it from there instead of guessing the host.

Create the Prediction Resource

The prediction resource has the CustomVision.Prediction kind. This is the endpoint your application calls at runtime to classify new images, so you can scale or secure it independently of training.

Step 4 - Create the prediction account

az cognitiveservices account create \
    --name cv-prediction-ai103 \
    --resource-group rg-cv-ai103 \
    --kind CustomVision.Prediction \
    --sku S0 \
    --location eastus

Step 5 - List its key and endpoint

az cognitiveservices account show \
    --name cv-prediction-ai103 \
    --resource-group rg-cv-ai103

az cognitiveservices account keys list \
    --name cv-prediction-ai103 \
    --resource-group rg-cv-ai103

Record the Connection Details

You now have the pieces your code and the portal need. Write these values down or store them as environment variables:

$env:CV_TRAINING_KEY   = "YOUR_TRAINING_KEY"
$env:CV_PREDICTION_KEY = "YOUR_PREDICTION_KEY"
$env:CV_PREDICTION_ENDPOINT = "https://YOUR-REGION.api.cognitive.microsoft.com/"

The prediction key and the training key are different secrets on different accounts. Mixing them up is the most common mistake in the Custom Vision SDKs — a training call authenticated with the prediction key fails immediately with an access error.

Verify the Resources Are Ready

Do a quick connectivity check against each account before moving on. Both kinds expose a simple /customvision/v3.3/training/projects style surface — the training one should list projects (an empty array is fine):

curl -X GET "https://YOUR-REGION.api.cognitive.microsoft.com/customvision/v3.3/Training/projects" -H "Training-key: YOUR_TRAINING_KEY"

And the prediction one should accept a project listing request when given a project — it will return an error listing the missing project id, which still proves the endpoint authenticated:

curl -X GET "https://YOUR-REGION.api.cognitive.microsoft.com/customvision/v3.3/Prediction/projects" -H "Prediction-key: YOUR_PREDICTION_KEY"

Clean Up When Done

If you ever want to remove everything created in this lab, delete the resource group:

az group delete --name rg-cv-ai103 --yes

Summary

You created a dedicated resource group, provisioned the Custom Vision training and prediction accounts, and captured their keys and endpoints. The training key belongs to the training workflow you will use next, and the prediction key belongs to the runtime API your applications will call. With these two accounts in place you are ready to build your first image classification model.
