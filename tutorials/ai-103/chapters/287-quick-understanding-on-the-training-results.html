Quick understanding on the training results

After training finishes, the portal shows a page of numbers that can look intimidating at first. This chapter translates those numbers into plain language. The goal is simple: by the end you should be able to look at an evaluation result, decide whether the model is good enough, and know what to change when it is not.

The Confusion Matrix Behind the Metrics

Every classification metric is built on four counts. For the tag dog, the possible outcomes are:

OutcomeMeaning
True positive (TP)Actually a dog, and the model said dog.
False positive (FP)Actually a cat, but the model said dog.
True negative (TN)Actually a cat, and the model said cat.
False negative (FN)Actually a dog, but the model said cat.

Everything else is a ratio built from these four numbers. There is no single number that tells the whole story — that is why the portal shows several.

Precision

Precision answers: when the model claims a dog, how often is it right? It is calculated as the true positives divided by everything the model predicted as positive:

Precision = TP / (TP + FP)

High precision means the model rarely makes false alarms. It is the metric to watch when a wrong guess is expensive — for example, flagging a good part as defective.

Recall

Recall answers: of all the real dogs in the test set, how many did the model catch? It is the true positives divided by all actual positives:

Recall = TP / (TP + FN)

High recall means the model rarely misses the target class. It is the metric to watch when a missed detection is the expensive failure — for example, failing to flag a genuinely defective part.

Precision and recall pull against each other. If you raise the confidence threshold, the model makes fewer predictions overall: precision usually goes up because the guesses it does make are safer, but recall goes down because it also declines some correct guesses. Choose the metric that matches the cost of the failure mode you care about.

Average Precision (AP)

The AP is a single score that combines precision and recall across every confidence threshold at once. Rather than picking one cutoff, the service computes the precision-recall curve over all thresholds and reports the area under it. A perfect classifier scores 1.0; a useless one scores near 0. The portal shows an AP for each tag, which makes it the fastest way to spot which class is dragging the model down.

Per-Tag Results in the Portal

In the evaluation page you will see a table with one row per tag. The columns typically include:

  • Tag — the class name.
  • Precision and Recall — as defined above.
  • AP — the threshold-independent summary.

Alongside the table there is a set of example images the model classified, both correctly and incorrectly. The Misclassified list is the most valuable part of the page: every wrong example is a direct clue about a missing pattern in your training set.

When a misclassified image appears, ask why the model could not tell. Common answers: too few examples of that appearance, the class looks similar to the other class, or the image contains background that the model latched onto as a shortcut. Fix the dataset, retrain, and compare the new AP with the old one.

Guidelines for Interpreting the Numbers

AP rangeWhat it usually meansNext step
0.9 or aboveThe class is well separated from the others.Validate on genuinely new images, then publish.
0.7 – 0.9Workable, but there is room to improve.Add varied images and inspect the misclassified set.
0.5 – 0.7Weak separation between classes.Expand the dataset substantially and reconsider overlapping classes.
Below 0.5The class is not being learned well at all.Re-check labels, gather more images, or simplify the class definition.

These numbers describe performance on the held-out test images, not the real world. A model can score 0.98 on the portal and still fail on photos taken with a different camera or in a different environment. The final acceptance test is always a set of fresh images the model has never seen.

Summary

The training results are built from four counts — true and false positives, true and false negatives — and three ratios: precision, recall, and average precision. Precision guards against false alarms, recall guards against misses, and AP summarises the trade-off across all thresholds. Use the per-tag numbers to find the weak class, inspect the misclassified images to understand why, and fix the dataset rather than the settings.
