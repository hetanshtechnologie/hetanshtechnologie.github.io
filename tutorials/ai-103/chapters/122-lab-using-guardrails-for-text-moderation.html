Lab - Using Guardrails for Text Moderation

Prompt Shields protects against injected instructions. Text moderation protects against harmful content itself. Azure AI Content Safety can examine any text and score it across a set of harm categories, from hate speech to self-harm. In this lab you will call the text moderation API from Python, read the severity scores, and use them to decide whether to allow content into your application.

What You Need Before Starting

  • Python 3.9 or newer and VS Code.
  • An Azure AI Content Safety resource with its endpoint and key. If you do not have one, complete the resource-creation lab later in this section first, or create the resource as described there.
  • Your endpoint and key available as environment variables.

Install the Content Safety SDK

Azure AI Content Safety has its own Python package. Open a terminal in VS Code and install it:

pip install azure-ai-contentsafety

The Text Moderation Request

A text moderation call wraps your text in an AnalyzeTextOptions object and sends it to the analyze_text method. The service breaks the text into the harm categories it knows about and scores each one. The code pattern is:

  1. Create a ContentSafetyClient with your endpoint and key.
  2. Build an AnalyzeTextOptions with the text to check.
  3. Call analyze_text.
  4. Inspect the per-category results.

Moderate Some Text

Step 1 - Create the project folder

Create a folder named ai103-lab122 and open it in VS Code. Create a file called moderate_text.py.

Step 2 - Set your environment variables

Use the endpoint and key of your Content Safety resource:

$env:CONTENT_SAFETY_ENDPOINT = "https://YOUR_CONTENT_SAFETY.cognitiveservices.azure.com/"
$env:CONTENT_SAFETY_KEY = "YOUR_KEY"

Step 3 - Paste the script

from azure.ai.contentsafety import ContentSafetyClient
from azure.ai.contentsafety.models import AnalyzeTextOptions
from azure.core.credentials import AzureKeyCredential
import os

endpoint = os.environ["CONTENT_SAFETY_ENDPOINT"]
key = os.environ["CONTENT_SAFETY_KEY"]

client = ContentSafetyClient(endpoint, AzureKeyCredential(key))

text = "I am so angry I could do something terrible to this system."

request = AnalyzeTextOptions(text=text)

response = client.analyze_text(request)

for item in response.categories_analysis:
    print(item.category, "-", item.severity)

Step 4 - Run the script

python moderate_text.py

You should see one line per category, each with a severity score. The violent and self-harm categories should score higher than the others.

Understanding the Output

Each category is scored on a severity scale from 0 to 6 (in current API versions):

SeverityMeaning
0No content of this kind detected
1Mild — safe to display to most audiences
2Borderline — typically requires caution
3Moderate — generally not safe to display without age checks
4-6Severe to extreme — typically blocked

The categories returned reflect the configuration of your resource. The standard harm categories are:

  • Hate: content that promotes hate or violence against a group.
  • Sexual: sexually explicit or inappropriate content.
  • Violence: content describing or promoting violence.
  • Self-harm: content encouraging or describing self-harm.

Applying a Threshold

Raw scores are useful, but applications usually need a yes/no decision. Pick a severity threshold and block anything at or above it:

BLOCK_THRESHOLD = 2

blocked = any(
    item.severity is not None and item.severity >= BLOCK_THRESHOLD
    for item in response.categories_analysis
)

if blocked:
    print("Content blocked.")
else:
    print("Content allowed.")

Choose your threshold per category if your product rules differ. A family-friendly chat app may block everything at severity 2, while a news site quoting an article may want to allow severity 1 references.

Moderating Several Strings

Real applications check many messages. Loop over your text inputs and record the verdict for each:

samples = [
    "Great job on the presentation today.",
    "I hope someone does something violent to that server room.",
    "You are welcome to join the call tomorrow.",
]

for sample in samples:
    result = client.analyze_text(AnalyzeTextOptions(text=sample))
    worst = max(
        (item.severity or 0 for item in result.categories_analysis),
        default=0,
    )
    print(f"Severity {worst}: {sample}")
