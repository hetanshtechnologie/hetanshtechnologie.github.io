Visual Understanding with Image Analyzers

Documents are not the only content that needs understanding. Photos, product shots, diagrams, screenshots, and graphics carry information that is entirely visual. Azure Content Understanding addresses this with image analyzers — configurations that look at a picture and describe what it shows, label the objects and people in it, read any text embedded in it, and return all of that as structured JSON. This chapter explains what image analyzers do and how they fit into the analyzer framework you already know.

What an Image Analyzer Produces

An image analyzer takes a single image and produces a structured description of it. Depending on how the analyzer is configured, the output can include several kinds of information:

  • Caption — a short sentence describing the overall scene.
  • Dense captions — captions for each important region of the image, not just the whole.
  • Tags — a list of relevant words or concepts, such as beach, umbrella, or vehicle.
  • People — bounding boxes for detected persons.
  • OCR — any text visible in the image, with its position.
  • Objects — detected objects with their locations.
CapabilityWhat it answersTypical output
CaptionWhat is going on in this image?One descriptive sentence
Dense captionWhat details exist in each region?Multiple region captions with boxes
TagWhat concepts appear here?List of labels
PeopleWhere are people located?Bounding boxes
OCRWhat text is on the image?Words with coordinates

How Image Analyzers Work

An image analyzer follows the same architecture as a document analyzer. You create or select an analyzer that declares which capabilities you want, and the service runs a vision model over the image, returning the requested information in a consistent JSON schema. Prebuilt image analyzers are provided out of the box, and custom image analyzers let you pick exactly which capabilities to enable.

Because the result is structured, it can feed straight into downstream systems. A product catalog can be built from captions and tags, an accessibility pipeline can convert captions to alt text, and an image search index can store both the tags and any OCR'd text for retrieval later.

Think of an image analyzer as the visual counterpart of a document analyzer: the same idea of a named, versioned, reusable configuration, but the input is a standalone image rather than a multi-page document, and the extraction targets are visual concepts rather than document fields.

Image Analyzers vs. Vision Chat Models

Both image analyzers and vision-capable chat models can look at a picture, but they are built for different jobs. The distinction matters when you choose a tool.

AspectImage analyzerVision chat model
Primary roleRepeatable, structured extraction at scaleConversational understanding and open-ended answers
OutputFixed JSON schemaFree-form text (or JSON if prompted)
ConsistencyHigh, same schema every callVaries with prompt and sampling
Best forBatches of images, pipelines, automationOne-off questions, reasoning about an image

When you need to answer "what is this?" once, call a vision model. When you need the same fields extracted from ten thousand images every night, build an image analyzer. The two work well together: an analyzer can preprocess and structure images, and a chat model can then reason over the structured results.

Use Cases for Image Analysis

  • Generating alt text and accessibility descriptions for published images.
  • Tagging product photos so e-commerce searches find the right items.
  • Reading text from signs, labels, and receipts photographed in the field.
  • Detecting and counting people for safety or analytics use cases.
  • Building image search indexes that combine visual tags with embedded text.

Where Image Analysis Fits in This Course

Later in the course you will connect analyzers to agents and to search indexing. Image analyzers feed both paths: an agent can call an image analyzer as a tool to understand a photo the user uploaded, and an index can store an image's tags and OCR text so it becomes findable by search. Understanding the analyzer's output shape now makes those integrations straightforward later.

Summary

Image analyzers extend Content Understanding beyond documents, producing structured captions, tags, people detections, and OCR from a single image. They follow the same analyzer model as documents, trade open-ended reasoning for consistent structured output, and are the right choice for high-volume visual pipelines.
