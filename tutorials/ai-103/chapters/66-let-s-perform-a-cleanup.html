Let's perform a cleanup

Every lab in this course leaves resources behind, and each one keeps accruing charges and cluttering your subscription. This chapter walks through a systematic cleanup: you remove the orders API stack, review the Foundry project, and confirm nothing expensive is still running before you move on.

What This Section Created

Over the last few labs you created these resources:

  • A resource group containing the function app and its storage account.
  • A Foundry project with model deployments used by the agent.
  • The CloudXeus agent with the OpenAPI tool attachment.

Delete the Orders API Stack

Everything for the function app lives in one resource group, so deleting the group removes it all in one step:

az group delete --name rg-cloudxeus-orders --yes --no-wait

The --yes flag skips the confirmation prompt, and --no-wait returns immediately while Azure deletes in the background.

Deleting a resource group is permanent. There is no recycle bin for a function app or its storage. If you still want the orders API for later chapters, publish it fresh from your local project instead of keeping the cloud resources alive.

Delete the Storage Account Separately (If Needed)

In this lab the storage account was created inside the resource group, so the group delete handles it. If you ever create a storage account in a shared group, remove it explicitly:

az storage account delete --name stcloudxeusorders001 `
  --resource-group rg-cloudxeus-orders --yes

Clean Up the Foundry Project

Exercise — Tidy the Agent and Its Deployments

  1. In the Foundry portal, open the agent used in this section and delete it. This also removes the OpenAPI tool connection and the key stored in it.
  2. Review your model deployments and delete the ones you no longer need. Keep a chat-capable deployment if the next section reuses it.
  3. Confirm you are not leaving any unused or duplicate resources in the project.

Deleting an agent severs the stored function key with it, which is good practice. If you delete the agent before the function app, remove the key manually from the function app's key list so the secret does not linger.

Verify Nothing Expensive Is Left

Two quick checks confirm the cleanup worked:

  • List the resource groups and confirm the orders group is gone:
az group list -o table
  • Look at cost analysis in the portal for the last few days and confirm the daily spend has dropped to your baseline.

What to Keep

Not everything must go. Keep resources that the rest of the course reuses:

  • Your Foundry project and at least one chat model deployment.
  • Your local cloudxeus-orders-api folder and the OpenAPI file, which you may republish later.
  • Your Azure account and CLI login.

Summary

The section's cloud footprint is gone: the function app stack is deleted through its resource group, the agent and its tool connection are removed, and the remaining Foundry resources are trimmed to what the course still needs.
