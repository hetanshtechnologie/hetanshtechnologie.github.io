Lab - Controlling Model Behaviour

In this lab you will take the theory from the previous chapter and apply it to a real deployment. You will run four short experiments that change the system prompt, the temperature, the token limit, and the output format, and observe how each lever changes what the model returns.

What You Need

  • The working chat.py script from the first API lab.
  • Your endpoint and key set as environment variables.
  • A deployed chat model, such as gpt-4o-mini.

Experiment 1 - The system prompt changes the role

Create roleplay.py with the following code. Run it twice, once with each system prompt by editing the file between runs:

from openai import AzureOpenAI
import os

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

prompt = "You are a pirate. Answer every question in pirate style."

response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    messages=[
        {"role": "system", "content": prompt},
        {"role": "user", "content": "How do I cook pasta?"},
    ],
)
print(response.choices[0].message.content)

Now change prompt to "You are a professional nutritionist. Answer briefly with exact measurements." and run again. Notice how the same question produces completely different answers.

Experiment 2 - Temperature controls variability

Create temperature.py. This script asks the model to invent a tagline ten times and shows the difference between a low and a high temperature:

from openai import AzureOpenAI
import os

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

def taglines(temp):
    print(f"--- temperature = {temp} ---")
    for _ in range(5):
        response = client.chat.completions.create(
            model="YOUR_DEPLOYMENT_NAME",
            temperature=temp,
            messages=[
                {"role": "user", "content": "Invent a short tagline for a coffee shop."}
            ],
        )
        print(response.choices[0].message.content)

taglines(0.0)
taglines(1.0)

At temperature = 0.0 the five answers are nearly identical. At 1.0 they vary noticeably. This is the same model — only the sampling changed.

Experiment 3 - max_tokens caps the answer

Create tokenlimit.py and set max_tokens to a very small number:

response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    max_tokens=15,
    messages=[
        {"role": "user", "content": "Explain quantum computing in detail."}
    ],
)
print(response.choices[0].message.content)
print("Stopped because:", response.choices[0].finish_reason)

You will see a truncated answer, and finish_reason will be length instead of stop. This is how you detect that the model hit the cap.

Experiment 4 - Forced JSON output

Create json_output.py. This request forces the model to reply in JSON and then parses the result:

from openai import AzureOpenAI
import os, json

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    response_format={"type": "json_object"},
    messages=[
        {"role": "system", "content": "Return a JSON object with keys: city and population."},
        {"role": "user", "content": "Tell me about Cairo."},
    ],
)

data = json.loads(response.choices[0].message.content)
print("City:", data["city"])
print("Population:", data["population"])

Summary

You have now seen the four core behaviour controls in action: the system prompt, temperature, max_tokens, and structured output. Each one changes the model's response in a predictable way, and together they let you shape one deployment into many different assistants.
