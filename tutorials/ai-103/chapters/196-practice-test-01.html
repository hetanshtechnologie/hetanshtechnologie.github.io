Practice Test 01

This practice test checks your understanding of the course so far: generative AI fundamentals, Microsoft Foundry and model deployment, agents and tools, retrieval and knowledge bases, document parsing services, content safety, and workflows. Read each question, choose the best answer, and check yourself against the answer key. Treat it like the real exam: answer before you look.

The Test

  1. What is the defining trait of a generative model compared with a discriminative model?
    • A) It classifies inputs into predefined categories.
    • B) It learns the distribution of training data and samples from it to create new content. (correct)
    • C) It only returns probabilities for existing labels.
    • D) It requires labeled training data for every output.
  2. In an LLM, what is a token?
    • A) A single English word.
    • B) A chunk of text that can be a whole word or part of a word, used as the unit of prediction. (correct)
    • C) The API key used for authentication.
    • D) The number of API calls in a subscription.
  3. What does the temperature parameter control in a chat model?
    • A) The maximum length of the response.
    • B) How deterministic versus creative the sampling is. (correct)
    • C) The number of tokens in the prompt.
    • D) The number of retries on failure.
  4. Which component holds the raw, unmodified documents in an agentic retrieval architecture?
    • A) The knowledge source. (correct)
    • B) The embedding model.
    • C) The vector index.
    • D) The system prompt.
  5. What does the indexing pipeline do to each source document?
    • A) It rewrites the document in the model's own words.
    • B) It extracts text, splits it into chunks, embeds each chunk, and stores them in an index. (correct)
    • C) It deletes the original file after processing.
    • D) It translates the document into every supported language.
  6. Why is chunking quality important for retrieval?
    • A) Smaller chunks always return better results than larger ones.
    • B) Chunk size trades precision against surrounding context and directly affects retrieval quality. (correct)
    • C) Chunking only affects storage cost, not results.
    • D) Chunks must match the question word for word.
  7. A scanned PDF contains no text layer. What must happen before its content can be indexed?
    • A) OCR must recover the text from the page images. (correct)
    • B) The file must be converted to Word format.
    • C) The scan resolution must be reduced.
    • D) Nothing; scanned PDFs index exactly like digital ones.
  8. When a table spans multiple pages, what is the key step the parser must handle correctly?
    • A) Delete the header row from every page after the first.
    • B) Reconstruct the table by matching column structure and merging fragments in page order. (correct)
    • C) Treat each page as a separate unrelated table.
    • D) Convert the table to an image so it is never parsed.
  9. In a custom Content Understanding analyzer, what do the field descriptions do?
    • A) They label the output for display only.
    • B) They tell the extraction model what to look for, and precise descriptions improve reliability. (correct)
    • C) They control the OCR language.
    • D) They determine the file formats accepted.
  10. Which Document Intelligence model would you use to extract vendor, invoice number, and total from an invoice with no custom work?
    • A) prebuilt-invoice (correct)
    • B) prebuilt-read
    • C) A custom classification model
    • D) prebuilt-idDocument
  11. What is the difference between a custom extraction model and a custom classification model in Document Intelligence?
    • A) Extraction models return text; classification models return images.
    • B) Extraction models pull named fields from documents; classification models assign documents to categories. (correct)
    • C) There is no difference.
    • D) Classification models require an LLM; extraction models do not.
  12. What is a model version in the context of a document service, and why should you track it?
    • A) It is a marketing label with no effect on behavior.
    • B) It is a snapshot of model behavior that can change field names and confidence, so integrations must be pinned and re-tested. (correct)
    • C) It is the version of the SDK you installed.
    • D) It only affects billing, never results.
  13. Why wrap invoice extraction behind a remote tool API instead of letting the agent call the service directly?
    • A) It lets you control authentication, validation, logging, and the ability to swap parsers. (correct)
    • B) It makes the agent faster.
    • C) It removes the need for a system prompt.
    • D) It prevents the agent from ever making a tool call.
  14. What is the role of an OpenAPI specification when registering a remote tool?
    • A) It encrypts the connection between the agent and the tool.
    • B) It describes the endpoint, its operation, parameters, and responses so the agent knows when and how to call it. (correct)
    • C) It trains the extraction model.
    • D) It stores the API key for the tool.
  15. An invoice has no due date. What should a well-prompted invoice agent do?
    • A) Infer a typical due date from similar invoices.
    • B) Say explicitly that the invoice does not list a due date. (correct)
    • C) Report the issue date as the due date.
    • D) Refuse to answer any question about the invoice.
  16. What is indirect prompt injection?
    • A) The user repeatedly sending the same prompt.
    • B) Malicious instructions hidden inside documents, retrieved content, or tool output. (correct)
    • C) A prompt that is too long.
    • D) A content filter blocking safe output.
  17. In Content Safety text analysis, what drives your moderation decision?
    • A) The category of the content alone.
    • B) The severity level combined with your own blocking policy. (correct)
    • C) The length of the text.
    • D) The language of the text.
  18. What is the main reason to use a workflow instead of a free-running agent?
    • A) Workflows make the multi-step process predictable and auditable. (correct)
    • B) Workflows require no model calls.
    • C) Workflows are always cheaper than agents.
    • D) Workflows cannot use tools.
  19. Why should each step of a workflow have a defined input and output contract?
    • A) So steps compose without guesswork and can be swapped or tested independently. (correct)
    • B) So the workflow cannot be changed later.
    • C) To reduce the number of steps.
    • D) To hide the steps from auditors.
  20. When a workflow step fails after exhausting retries, what is the correct outcome?
    • A) Let the exception crash the whole flow.
    • B) End in an explicit state such as "needs manual review" with a clear error payload. (correct)
    • C) Return a plausible best-guess value so the flow continues.
    • D) Silently skip the step and proceed.
