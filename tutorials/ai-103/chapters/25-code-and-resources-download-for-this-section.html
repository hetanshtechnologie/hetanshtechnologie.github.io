Code and resources download for this section

Every lab in this section is built from a handful of short scripts. Rather than retyping the same client setup each time, you can download the finished example files for this section and use them as a starting point. This chapter explains what the download contains and how to set up your project folder so every script just works.

What Is in the Download

The resources for this section are a single ZIP file containing these Python files, one per lab:

Downloading the Resources

  1. Download the ZIP file for this section from the course download page.
  2. Extract it into a folder named ai103 on your machine.
  3. Open that folder in VS Code with File > Open Folder.

Set Up the Project Folder

After extraction, your folder should look like this:

ai103/
  chat.py
  roleplay.py
  temperature.py
  tokenlimit.py
  json_output.py
  vision.py
  web_search_tool.py
  code_interpreter.py
  requirements.txt
  .env.example
  sample_image.png

Install the required packages once, in this folder's terminal:

pip install -r requirements.txt

Credentials Without Hard-Coding

Every script reads AZURE_OPENAI_ENDPOINT and AZURE_OPENAI_KEY from environment variables. The simplest way to keep them out of your code is to set them in the terminal before you run a script:

$env:AZURE_OPENAI_ENDPOINT = "https://YOUR-RESOURCE.openai.azure.com/"
$env:AZURE_OPENAI_KEY = "YOUR_KEY"

Alternatively, copy .env.example to a file named .env, fill in the values, and let the python-dotenv package load them automatically at the top of each script.

The .env file contains your key, so it must never be committed to a repository. Add .env to your .gitignore file the moment you create it.

Replace the Placeholders

Before running any example, search the file for YOUR_DEPLOYMENT_NAME and replace it with the exact name of your deployment in Foundry. The endpoint and key come from your environment variables, so no other placeholder needs editing.

If you do not want to download the files, you can type the examples by hand — the code in the lab chapters is identical to what you will find in the ZIP. Typing them yourself is often the best way to learn.

Summary

The section download gathers all of the lab scripts, a requirements file, a credentials template, and a sample image into one folder. After installing the dependencies, setting your environment variables, and replacing the deployment-name placeholder, every example in this section runs as written.
