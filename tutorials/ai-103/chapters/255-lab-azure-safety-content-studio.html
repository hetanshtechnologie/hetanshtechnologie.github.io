Lab - Azure Safety Content Studio

Content Safety Studio is the browser-based workspace that sits on top of Azure AI Content Safety. It gives you a visual way to test moderation without writing code, try different threshold settings, manage blocklists, and inspect how the service scores individual pieces of content. This lab walks you through signing in, testing text moderation, and exploring the results.

What Content Safety Studio Gives You

The studio bundles the main Content Safety features into one interface:

  • Moderate text content to see severity scores for each category.
  • Moderate images to check for unsafe visual content.
  • Prompt Shield to detect prompt injection attempts.
  • Blocklist management to create and edit custom term lists.
  • Sample data you can paste in, plus JSON results you can copy for reference.

The studio does not replace the API; it is a diagnostic and configuration tool that helps you understand behavior before you wire moderation into an application.

Opening the Studio

Step 1 — Navigate to the studio

  1. Open Content Safety Studio in your browser and sign in with the account that owns your Azure subscription.
  2. If prompted, select the subscription, resource group, and the cs-ai103-demo resource you created in the previous lab.
  3. You land on a home page with tiles for the different moderation features.

Step 2 — Moderate a text sample

  1. Select the Moderate text content tile.
  2. Paste a sample sentence into the text box. Try something clearly mild first, such as "I really enjoyed the training course."
  3. Select Run test.
  4. Examine the results. The studio shows severity scores for the harmful content categories and highlights which parts of the text triggered them.

Step 3 — Push the sample harder

  1. Replace the text with a clearly hostile sentence that includes profanity or a threat.
  2. Run the test again and compare the severity scores with the first sample.
  3. Note how the score moves from low (safe) toward the high end (severe) as the content becomes more aggressive.

Content Safety reports severity on a scale where 0 means safe and the highest value means severe. Your application decides what to do at each level — allow, warn, or block. The studio is the fastest way to calibrate that threshold because you can see the exact numbers for realistic samples.

Testing an Image

Image moderation works the same way. Under the image moderation tile you can upload an image file and run a test. The studio reports severity results for the visual categories, letting you confirm how strict your configuration is before you deploy.

Keep a small library of test images — one clearly safe, one borderline, one clearly unsafe — so you can quickly re-verify behavior after changing thresholds or regions.

Inspecting the JSON Output

Every test you run in the studio produces a JSON response identical in shape to what the API returns. Click the results view to see it. The key fields to recognize:

{
  "categoriesAnalysis": [
    {
      "category": "Hate",
      "severity": 0
    },
    {
      "category": "Violence",
      "severity": 2
    },
    {
      "category": "SelfHarm",
      "severity": 0
    }
  ]
}

Each entry names a category and its severity score. A severity of 0 means the service found nothing in that category; a higher number means the content was flagged. Your policy maps these numbers to actions.

Summary

Content Safety Studio turns the moderation service into a visual, interactive tool. You tested text samples, compared severity scores, and looked at the JSON that your application code will consume. In the next lab you will use the studio's Prompt Shield feature to detect prompt injection attempts.
