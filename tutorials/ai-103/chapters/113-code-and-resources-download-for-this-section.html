Code and resources download for this section

This section of the course moves beyond plain text and works with images and safety. You will teach a chat model to look at a picture you send it, generate brand new images from a text description, modify existing pictures with words, and then harden your applications against harmful content — hidden instructions buried in documents, and text or images that violate content policies. To keep all of the labs consistent, this chapter explains the sample code and supporting files you should download before you begin, and how the folders and credentials are organized.

What This Section Covers

Each chapter in this section builds on the one before it. The flow looks like this:

  • Vision input (chapter 114): send a photo to a chat model and ask questions about what it shows.
  • Image generation (chapters 115 and 116): create a brand new image from a text prompt using Python.
  • Image editing (chapters 117, 118, and 119): modify an existing image, either by describing the change or by supplying a mask that tells the model which region to regenerate.
  • Prompt Shields (chapters 120 and 121): detect hidden instructions embedded in documents and other untrusted text.
  • Content safety (chapters 122 through 125): moderate both text and image content so your applications can reject harmful input.

Downloading the Sample Resources

All of the Python scripts used in the labs are included in the companion download for the course. Find the download link on the course resources page that came with your registration, then save the archive to your machine and extract it into a folder such as C:\ai103\section-images-and-safety. Keep this folder separate from the earlier sections so files with the same names do not overwrite each other.

The archive contains ready-to-run versions of every script you will type in the following labs. The guidance in each lab will ask you to build the files yourself step by step, and you can use the downloaded copies to compare your work when something behaves unexpectedly.

The Folder Layout

Once extracted, the folder is organized so that every lab knows where to find its images and scripts:

PathPurpose
scripts/Python files for each lab, named to match the chapter, for example vision_chat.py
images/Sample images used as input, including a building photo, a room, and a plain background
images/masks/Black and white mask images used for mask-based editing
output/The folder where generated and edited images are saved so you never mix them up with the originals

The Sample Images

You will not need to source your own pictures for these labs. The download provides small, license-clear images that are well suited to the exercises:

  • sample_building.jpg — a city scene used in the vision input lab.
  • sample_room.jpg — an interior used for prompt-driven editing.
  • sample_background.png — a simple scene with an empty region used for mask-based editing.
  • mask_region.png — a white region on a black background that marks the area to be regenerated.
  • sample_photo.jpg — a general photo used in the image moderation lab.

Getting Ready Before You Begin

Confirm the following pieces are already in place, because every lab in this section relies on them:

  • Python 3.9 or newer and VS Code, installed as you did in the earlier chapters.
  • A chat model deployment in Microsoft Foundry that supports vision input, such as gpt-4o or gpt-4o-mini.
  • An image generation model deployment in Foundry, such as dall-e-3 or gpt-image-1.
  • An Azure AI Content Safety resource for the moderation labs. You will create this resource in a dedicated lab later in the section.
  • Your endpoint URLs and API keys for the Foundry project, stored as environment variables rather than pasted into the scripts.

Every lab in this section uses API keys. Never paste a key directly into a script file that you might share or commit, never put it in a screenshot, and never type it into a chat window. Store it in an environment variable and read it in code, exactly as shown in the labs.
