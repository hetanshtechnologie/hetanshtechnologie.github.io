Section Quiz

This quiz covers the speech and voice arc: Speech to Text, Text to Speech, the Speech MCP server, the Voice Live API, and speech translation. There are seven questions. The correct answer is marked on each question, and a full answer key follows at the end of the page.

Quiz

Question 1. Which two delivery modes can you use to send audio to Speech to Text?

  • A. Push and pull
  • B. Batch transcription and realtime recognition (correct)
  • C. Streaming and snapshot
  • D. File upload and blob sync

Question 2. What does the Recognizing event (or the recognizing callback) deliver during a realtime recognition session?

  • A. A permanently finalized transcript
  • B. Only the final confidence score
  • C. Partial, intermediate results that update while the user is still speaking (correct)
  • D. The full transcript after the session stops

Question 3. Which markup format lets you control pitch, speaking rate, pauses, and expressive style in a text-to-speech request?

  • A. HTML
  • B. Markdown
  • C. JSON
  • D. SSML (correct)

Question 4. When speech is exposed through the Azure Speech MCP server, how does an agent use it?

  • A. It compiles custom speech models at runtime
  • B. It discovers and calls speech capabilities as MCP tools (correct)
  • C. It re-routes all traffic through a wake word service
  • D. It must use the REST API directly for every call

Question 5. What is the defining behavior that makes the Voice Live API feel like a realtime conversation?

  • A. It batches all recognition until the call ends
  • B. It translates every phrase into at least three languages
  • C. It maintains a single audio channel where synthesis can be interrupted by incoming speech (correct)
  • D. It always uses a custom neural voice

Question 6. Which scenario best fits the dedicated Speech Translation service rather than an LLM pipeline?

  • A. Translating a marketing brochure with strict brand terminology
  • B. Live multilingual captions that must track the speaker in real time (correct)
  • C. Rewriting a transcript into a formal executive summary
  • D. Post-editing old meeting notes with an improved model

Question 7. What is the main advantage of the LLM-based approach to speech translation compared with the speech-native service?

  • A. Lower latency to the first translated word
  • B. No intermediate text is ever produced
  • C. Full prompt-level control over style, domain, and terminology (correct)
  • D. It does not need a Speech resource at all

Answer Key

QuestionAnswerExplanation
1BBatch transcription handles pre-recorded files asynchronously; realtime recognition streams audio and returns partial results live.
2CThe recognizing/partial event fires with provisional text while speech is still arriving; the recognized event delivers the finalized phrase.
3DSSML tags such as <prosody>, <break>, and <mstts:express-as> control delivery and style.
4BThe MCP server exposes speech operations as tools; the agent selects and calls them during a conversation.
5CA single audio channel that supports interruption and turn-taking is what makes the session feel live.
6BLive captions need low latency and streaming partial translations, where the speech-native service excels.
7CAn LLM accepts prompts that control tone, domain vocabulary, and business context; the speech service is less customizable.

Summary

If you answered most questions correctly, you have a solid grasp of the speech and voice arc.
