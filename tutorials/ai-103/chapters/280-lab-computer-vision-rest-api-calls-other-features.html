Lab - Computer Vision - REST API Calls - Other features

The caption lab showed you the full REST pattern. This lab extends the same pattern to the remaining features you have used in Python: tags, object detection, brand detection, and OCR. Each feature is just a different value in the features query parameter, with the response containing a matching result block. By the end of the lab you will be able to request any combination of features with a single HTTP call and read the results directly.

Review the Endpoint

All four features share the same endpoint, headers, and body. Only features changes:

POST /computervision/imageanalysis:analyze?api-version=2024-02-01&features=FEATURES
Headers: Content-Type, Ocp-Apim-Subscription-Key
Body: image bytes or a JSON object with a "url" field

Tags

curl -X POST \
  "https://YOUR_ENDPOINT/computervision/imageanalysis:analyze?api-version=2024-02-01&features=tags" \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -d '{"url": "https://upload.wikimedia.org/wikipedia/commons/1/1e/Cat_and_dog.jpg"}'
{
  "tagsResult": {
    "values": [
      {"name": "pet", "confidence": 0.99},
      {"name": "dog", "confidence": 0.98},
      {"name": "cat", "confidence": 0.95},
      {"name": "sofa", "confidence": 0.72}
    ]
  }
}

Object Detection

curl -X POST \
  "https://YOUR_ENDPOINT/computervision/imageanalysis:analyze?api-version=2024-02-01&features=objects" \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -d '{"url": "https://upload.wikimedia.org/wikipedia/commons/1/1e/Cat_and_dog.jpg"}'
{
  "objectsResult": {
    "values": [
      {"name": "dog", "confidence": 0.94, "boundingBox": [30, 60, 180, 220]},
      {"name": "cat", "confidence": 0.91, "boundingBox": [300, 90, 160, 200]}
    ]
  }
}

Brand Detection

curl -X POST \
  "https://YOUR_ENDPOINT/computervision/imageanalysis:analyze?api-version=2024-02-01&features=brands" \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -d '{"url": "https://YOUR_SITE/branded_product.jpg"}'
{
  "brandsResult": {
    "values": [
      {"name": "Contoso", "confidence": 0.9, "boundingBox": [120, 40, 150, 60]}
    ]
  }
}

OCR

curl -X POST \
  "https://YOUR_ENDPOINT/computervision/imageanalysis:analyze?api-version=2024-02-01&features=read" \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -d '{"url": "https://YOUR_SITE/notice.jpg"}'
{
  "readResult": {
    "blocks": [
      {
        "lines": [
          {"text": "PLEASE WAIT", "words": [{"text": "PLEASE"}, {"text": "WAIT"}]}
        ]
      }
    ]
  }
}

Combining All Features in One Call

Separate features with commas to run them all at once:

curl -X POST \
  "https://YOUR_ENDPOINT/computervision/imageanalysis:analyze?api-version=2024-02-01&features=caption,tags,objects,brands,read" \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -d '{"url": "https://upload.wikimedia.org/wikipedia/commons/1/1e/Cat_and_dog.jpg"}'

The response now contains one block per feature. Notice how the JSON grows: caption text, a list of tags, object bounding boxes, brands, and OCR lines all in a single payload.

Exercise 1: Exercise each feature over REST

  1. Send the tags request and confirm the response contains tagsResult. Read the confidence scores.
  2. Send the objects request and confirm each object has a boundingBox. Compare the boxes with what the objects look like in the image.
  3. Send the brands request against an image you believe contains a well-known logo. If no brands appear, try a different, clearly branded image.
  4. Send the read request against a photo of text and verify the extracted lines match the image.
  5. Send the combined request and count how many result blocks appear in the response.

Running all features on every image is rarely the right choice in production. Each feature costs processing time and money, so request the minimum set your application consumes. The combined call above is a debugging convenience, not a production pattern.
