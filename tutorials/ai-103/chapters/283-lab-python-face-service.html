Lab - Python - Face service

In this chapter you will move from hand-written REST calls to the official Python SDK. You will write a small application that loads a photo, detects every face, draws a rectangle around each one, and prints the attributes the service recovered. This is the same pipeline you built with raw HTTP in the previous chapter, but expressed in idiomatic Python that is far easier to maintain.

What You Need Before Starting

  • A Face resource (or multi-service Cognitive Services account) from the previous lab, with its endpoint and key.
  • Python 3.9 or newer and VS Code.
  • A local photo with at least one clear face.

Install the Python Package

The current Face SDK for Python lives in the azure-ai-vision package. This package also covers other computer-vision capabilities, but the classes you need here are the ones used for face analysis. Install it with:

pip install azure-ai-vision

Set Up the Project

Step 1 - Create the folder and script

Create a folder named ai103-lab283 and inside it a file called face_detect.py.

Step 2 - Provide your connection details

Set the endpoint and key as environment variables so they never end up hard-coded in source:

$env:AZURE_FACE_ENDPOINT = "https://YOUR-RESOURCE.cognitiveservices.azure.com/"
$env:AZURE_FACE_KEY = "YOUR_KEY"

Detect Faces and Read Attributes

The SDK wraps the detection request in a small set of options objects. The vision service options carry the endpoint and credential, the source points at the image, and the analysis options tell the service which attributes to return.

from azure.ai.vision import VisionServiceOptions, VisionSource, FaceAnalysisOptions, FaceAnalysisFeature, VisualFeatures

import os

endpoint = os.environ["AZURE_FACE_ENDPOINT"]
key = os.environ["AZURE_FACE_KEY"]

service_options = VisionServiceOptions(endpoint=endpoint, key=key)

analysis_options = FaceAnalysisOptions(
    features=[
        FaceAnalysisFeature.HEAD_POSE,
        FaceAnalysisFeature.FACE_ATTRIBUTES,
    ],
    gender="female",
    glasses="reading",
    age="35",
    emotion="happiness",
)

with open("photo.jpg", "rb") as stream:
    image_bytes = stream.read()

source = VisionSource(bytes=image_bytes)

Note that attribute hints like gender and age above are example values — the SDK's exact parameter names vary by preview version. The stable, documented approach is to pass the feature flags you care about and read the returned fields afterwards. The safest pattern that works across versions is to request detection plus the attributes you need, then iterate over the results:

from azure.ai.vision import VisionServiceOptions, VisionSource, FaceAnalysisOptions, FaceAnalysisFeature
from azure.ai.vision.enums import VisualFeatures
import os

service_options = VisionServiceOptions(
    endpoint=os.environ["AZURE_FACE_ENDPOINT"],
    key=os.environ["AZURE_FACE_KEY"],
)

analysis_options = FaceAnalysisOptions(
    features=[FaceAnalysisFeature.DETECT, FaceAnalysisFeature.FACE_ATTRIBUTES]
)

with open("photo.jpg", "rb") as stream:
    source = VisionSource(bytes=stream.read())

result = VisionSource.analyze(service_options, source, analysis_options)

if result.reason == "SUCCEEDED":
    for face in result.faces:
        box = face.bounding_box
        print(f"Face at x={box[0]} y={box[1]} w={box[2]} h={box[3]}")
else:
    print("Analysis failed:", result.reason)

The azure-ai-vision package is released as a preview and its API surface shifts between versions. If a member name no longer matches your installed version, run dir(module) in a REPL or check the package's own stub files to discover the current names. The concepts — service options, source, analysis options, and a results object with a face list — stay the same.

Drawing Boxes Around the Faces

A list of coordinates is easier to judge when you can see it. The Pillow library lets you open the photo and draw the rectangles the service returned, then save the annotated copy:

pip install pillow

from PIL import Image, ImageDraw

image = Image.open("photo.jpg")
draw = ImageDraw.Draw(image)

for face in result.faces:
    x, y, w, h = face.bounding_box
    draw.rectangle([x, y, x + w, y + h], outline=(0, 255, 0), width=4)

image.save("photo_annotated.jpg")
print("Saved photo_annotated.jpg with", len(result.faces), "faces highlighted")

Bounding boxes are returned in raw pixel coordinates, so they line up exactly with the source image at its original resolution. If you display the image scaled down, multiply the coordinates by the same scale factor before drawing.

Verifying Two Photos Show the Same Person

Detection alone is not identity. To compare two photos you need to detect both, then call verify with the two face IDs. The Verify response includes an isIdentical flag and a confidence score:

import requests
import os

endpoint = os.environ["AZURE_FACE_ENDPOINT"].rstrip("/")
key = os.environ["AZURE_FACE_KEY"]
headers = {"Ocp-Apim-Subscription-Key": key, "Content-Type": "application/json"}

def detect_face(url):
    r = requests.post(
        f"{endpoint}/face/v1.0/detect",
        headers=headers,
        json={"url": url},
        params={"returnFaceId": "true"},
    )
    r.raise_for_status()
    return r.json()[0]["faceId"]

face_a = detect_face("https://example.com/person-a.jpg")
face_b = detect_face("https://example.com/person-b.jpg")

r = requests.post(
    f"{endpoint}/face/v1.0/verify",
    headers=headers,
    json={"faceId1": face_a, "faceId2": face_b},
)
r.raise_for_status()
print(r.json())

Depending on the service tier you created, verify may require a limited-access approval. If you receive a 403 or an access notice, remove the verify step — detection and analysis alone are enough to complete this lab.

Troubleshooting Common Errors

ErrorLikely causeFix
401 Access deniedThe key is wrong, or it belongs to a different account.Re-run az cognitiveservices account keys list and copy the current key.
404 or Resource not foundThe endpoint is mistyped, or the Face sub-path is missing.Check the endpoint ends in .cognitiveservices.azure.com/ and the URL includes /face/v1.0/....
InvalidImageSizeThe image exceeds the accepted size for binary uploads.Resize or re-encode the image below 6 MB.
AttributeError on the SDKYour installed azure-ai-vision version uses different names.Inspect the package and adapt the member names to your version.

Summary

You have now built a real Python application around the Face service: it loads an image, detects every face, draws the bounding boxes onto a copy of the photo, and prints the results. You also saw how to verify two faces against each other through the REST endpoint and how to recognise and fix the most common setup errors. This detection-and-annotate workflow is the same foundation you will use for the Custom Vision labs, where you will start training models that answer questions the prebuilt service cannot.
