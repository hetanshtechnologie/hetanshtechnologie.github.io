Introduction to Computer Vision

So far this course has focused on models that read and write text. In this section you change mediums: the input becomes an image, and the task is to help a machine understand what the image contains. Computer vision is the branch of AI that does exactly that — it lets applications describe, classify, locate, and read what is inside pictures and video. This chapter introduces the field, the individual tasks you will perform in the labs, and the Azure AI Vision service that powers them.

What Computer Vision Means

Computer vision is the field of artificial intelligence concerned with making machines interpret visual data. Where a language model converts a prompt into words, a vision model converts pixels into meaning. The pixels alone carry no information to a program — a photo is just a grid of color values — so the entire problem is extracting the meaning buried in that grid.

The capabilities have matured a great deal. Early systems could only tell whether an image contained a particular object. Modern services can write a natural-language caption of a scene, draw boxes around every object they find, read printed and handwritten text, recognize logos, and identify where people are standing. These building blocks combine into real applications: accessibility tools that describe photos aloud, retail systems that count products on shelves, and document pipelines that extract text from scanned paperwork.

The Core Vision Tasks

Every vision application is built from a small set of tasks. Each task answers a different question about the image:

  • Image classification and tagging — "What is in this picture?" The service assigns one or more descriptive tags to the whole image, such as mountain, lake, or person.
  • Image captioning and description — "What is happening in this picture?" The service writes one or more natural-language sentences describing the scene.
  • Object detection — "Where are the objects?" The service draws bounding boxes around each detected object and labels it.
  • Optical character recognition (OCR) — "What text is in this image?" The service extracts the words and their locations from printed or handwritten content.
  • Brand detection — "Which companies appear in this image?" The service recognizes thousands of well-known logos and reports their position.
  • Face and people detection — "Where are the faces and people?" The service locates faces or people and reports their position and attributes.
  • Image analysis and moderation — assessing properties such as adult content or the dominant colors in an image.

Purpose-Built Services vs. Multimodal Models

You have already sent images to multimodal chat models, which can describe an image in natural language. That approach is flexible and powerful, but purpose-built vision services have real advantages for many production tasks:

  • Deterministic structure: Object detection returns bounding-box coordinates you can parse reliably; a chat model returns free-form text.
  • Cost and speed: A focused analysis call is usually cheaper and faster than a full multimodal generation call.
  • Specialized accuracy: OCR tuned for receipt and document text, or brand detection trained on thousands of logos, beats general-purpose models at those narrow jobs.
  • Simple integration: A REST endpoint with a key is easier to embed in a pipeline than a conversational model.

Use a multimodal model when you need open-ended understanding and flexible reasoning about an image. Use a purpose-built vision service when the output must be structured, fast, and cheap, or when the task is narrow and well-defined.

Azure AI Vision

Azure AI Vision is the family of cloud services that provides these vision capabilities through simple API calls. You create a Computer Vision resource in your Azure subscription — the subject of the next lab — and that resource gives you an endpoint URL and keys. Your application sends the image to the endpoint with one or more requested features and receives structured JSON back.

The main surface you will use in this section is Image Analysis, which bundles tagging, captioning, object detection, brand detection, people detection, and OCR behind a single call. You pick which features you need per request, which keeps costs down and responses fast.

Authentication works exactly like the other Azure AI services you have used in this course: send the resource key in an Ocp-Apim-Subscription-Key header and point your call at the resource endpoint. Keep the key out of your code by storing it in an environment variable.

Building a Vision Pipeline

Real applications rarely make a single vision call. A typical pipeline stages several tasks:

  1. Ingest — load the image from a local file, a URL, or a blob storage container.
  2. Analyze — request the features your workflow needs: tags, caption, objects, brands.
  3. Extract — run OCR to pull any embedded text into a structured form.
  4. Act — feed the results into a search index, a database, or a downstream AI model.

In the labs that follow you will build each stage with a Computer Vision resource, first through the Azure portal, then with Python and with raw REST calls.

Responsible Use of Vision

Vision services analyze people's faces, documents, and personal moments. That power needs guardrails:

  • Do not use face or people detection to profile, track, or make decisions about individuals without clear justification and consent.
  • OCR on personal documents (invoices, medical forms, ID cards) may expose sensitive data; protect the extracted text accordingly.
  • Published captions should be accurate; a wrong caption in an accessibility feature can mislead the very users it is meant to help.

Azure AI Face and Vision services have usage restrictions that Azure enforces. Review the service's terms and responsible AI guidance before building applications that analyze individuals, and apply for approval where the service requires it.

Summary

Computer vision lets applications extract meaning from images through a set of well-defined tasks: tagging, captioning, object detection, OCR, brand detection, and more. Azure AI Vision packages these tasks behind a single resource and API, and Image Analysis lets you request exactly the features you need per call. In the next chapter you will create your first Computer Vision resource.
