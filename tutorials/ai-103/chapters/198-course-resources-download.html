Course resources download

All of the code, prompts, and small data files used across this course are bundled into a single download. Instead of retyping every lab script, you can grab the bundle, extract it into a project folder, and run the examples with just a little configuration. This chapter explains what the download contains, how to set it up, and how to handle credentials safely.

What Is in the Download

The course resources download is a ZIP file containing everything you need to follow the hands-on chapters:

ItemWhat it is used for
labs/Finished Python scripts, one per lab, matching the code shown in each chapter
prompts/A collection of reusable system prompts and few-shot examples
data/Small sample documents, invoices, and images used by the content understanding and RAG labs
requirements.txtThe Python packages used by the examples, such as openai, requests, and python-dotenv
.env.exampleA template for storing your endpoint and key without hard-coding them

Downloading and Extracting

  1. Go to the course download page and download the resources ZIP file.
  2. Extract it into a folder named ai103-resources on your machine.
  3. Open that folder in VS Code with File > Open Folder.
  4. Open a terminal inside VS Code (menu: Terminal > New Terminal).

After extraction, the top-level layout looks like this:

ai103-resources/
  labs/
    chat.py
    vision.py
    agent.py
    ...
  prompts/
    system-prompts.txt
  data/
    sample-invoice.pdf
    sample-image.png
  requirements.txt
  .env.example

Install the Dependencies

Run this once in the project terminal to install everything the scripts need:

pip install -r requirements.txt

If you are on Windows and pip is not recognized, try python -m pip install -r requirements.txt instead.

Store Your Credentials Safely

Every script reads values such as AZURE_AI_FOUNDRY_ENDPOINT and AZURE_AI_FOUNDRY_KEY from environment variables. Copy the template and fill in your values:

Copy-Item .env.example .env

Then edit .env and replace the placeholders:

AZURE_AI_FOUNDRY_ENDPOINT=https://YOUR_RESOURCE.services.ai.azure.com/
AZURE_AI_FOUNDRY_KEY=YOUR_KEY

The python-dotenv package, already in requirements.txt, loads these automatically at the top of each script.

The .env file contains real credentials, so it must never be committed to source control or shared. Add .env to a .gitignore file immediately, and treat it like a password.

Replace the Placeholders

Before running any lab, search the script for YOUR_DEPLOYMENT_NAME and replace it with the exact deployment name you created in Foundry. Endpoints and keys come from your environment, so those are the only values that need editing.

You do not have to use the download at all — the code in every lab chapter is printed in full, so typing it yourself works just as well and often teaches more. The bundle exists for convenience, especially when you want to run a finished example quickly.

Summary

The course resources download collects the lab scripts, prompts, sample data, dependency list, and a credentials template into one bundle. After extracting it, installing the requirements, setting up .env, and replacing the deployment-name placeholder, every example in the course is ready to run.
