Section Quiz

This quiz checks your understanding of the whole section: building an API with Azure Functions, describing it with OpenAPI, attaching it to an agent, securing it, and managing its cost. Read each question carefully, pick the best answer, and check yourself against the answer key at the end.

The Quiz

  1. Which Azure Functions trigger turns a function into a REST endpoint an agent can call?
    • A) Timer
    • B) HTTP (correct)
    • C) Blob
    • D) Queue
  2. What is the purpose of the OpenAPI specification in this section?
    • A) To document training data for the model.
    • B) To describe an HTTP API so agents can call it as tools. (correct)
    • C) To configure the Azure storage account.
    • D) To replace the function code.
  3. In the Python v2 programming model, how do you mark a route as requiring a function key?
    • A) Set auth_level=func.AuthLevel.FUNCTION on the route decorator. (correct)
    • B) Add a password field to the function's JSON.
    • C) Rename the function file.
    • D) Change the storage account tier.
  4. Where does the platform place the function key when the agent calls the orders API?
    • A) In the message content the user sees.
    • B) In the x-functions-key header configured on the connection. (correct)
    • C) In the OpenAPI document body.
    • D) In the response JSON.
  5. Which response should the API return when a customer asks about an order id that does not exist?
    • A) 200 with an empty list
    • B) 404 with a JSON error message (correct)
    • C) 500 with no body
    • D) 301 redirect
  6. Which part of an OpenAPI document determines the base URL the agent calls?
    • A) servers (correct)
    • B) paths
    • C) components
    • D) info
  7. In a tool-backed agent conversation, which factor usually dominates the bill?
    • A) Storage account charges
    • B) Model token usage (correct)
    • C) Function execution time
    • D) Network data transfers
  8. What is the fastest way to remove all of the orders API resources created in this section?
    • A) Delete the local project folder.
    • B) Delete the resource group containing the function app and storage. (correct)
    • C) Stop the local func start process.
    • D) Remove the agent from the portal.

Answer Key

QuestionAnswerWhy
1BThe HTTP trigger exposes a function as an endpoint.
2BThe OpenAPI spec turns a REST API into callable agent tools.
