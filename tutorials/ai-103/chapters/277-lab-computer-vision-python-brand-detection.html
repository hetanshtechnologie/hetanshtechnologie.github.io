Lab - Computer Vision - Python - Brand Detection

Brand detection is object detection specialized for a narrow category: logos and trademarks. The service recognizes thousands of well-known brands and reports each one it finds, along with its position. This is the feature behind marketing analytics — knowing which brands appear in your content or your customers' photos. In this lab you will run brand detection from Python and print every brand the service recognizes with its location.

What You Need

  • Your Computer Vision endpoint and key.
  • Python 3 with the requests package installed.
  • A test image containing at least one recognizable brand logo, such as a product photo or a storefront picture.

Write the Brand Detection Code

import os
import requests

ENDPOINT = os.environ["COMPUTER_VISION_ENDPOINT"]
KEY = os.environ["COMPUTER_VISION_KEY"]

ANALYZE_URL = ENDPOINT.rstrip("/") + "/computervision/imageanalysis:analyze"
params = {
    "api-version": "2024-02-01",
    "features": "brands",
}

with open("test.jpg", "rb") as f:
    image_data = f.read()

headers = {
    "Content-Type": "application/octet-stream",
    "Ocp-Apim-Subscription-Key": KEY,
}

response = requests.post(ANALYZE_URL, params=params, headers=headers, data=image_data)
response.raise_for_status()

brands = response.json()["brandsResult"]["values"]
if not brands:
    print("No brands detected.")
else:
    for brand in brands:
        name = brand["name"]
        confidence = brand["confidence"]
        box = brand["boundingBox"]
        print(f"{name:<15} conf={confidence:.2f}  box={box}")

Run and Observe

Exercise 1: Detect brands in a local image

  1. Save the script as vision_brands.py.
  2. Set the environment variables and run python vision_brands.py.
  3. Read the output. Each detected brand prints with a confidence score and a bounding box.
  4. Test an image with a clear, unobstructed logo first, then a scene where the logo is small or angled. Note how confidence changes.
  5. Try an image with no logos at all. The service should print "No brands detected."

Brand detection only recognizes brands in its built-in catalog. An obscure or new logo will go undetected. If you need to recognize a specific, custom logo, object detection with a custom-trained model is the better route.

What the Response Looks Like

{
  "metadata": {"width": 640, "height": 480},
  "brandsResult": {
    "values": [
      {"name": "Coca-Cola", "confidence": 0.93, "boundingBox": [80, 120, 200, 80]},
      {"name": "Pepsi", "confidence": 0.71, "boundingBox": [430, 300, 160, 70]}
    ]
  }
}

The structure mirrors object detection: each entry has a name, a confidence, and a boundingBox of x, y, width, height.

Combining Features in One Call

Brand detection often makes more sense alongside other features. A single request can return tags, objects, and brands together, so you can answer "what is this image, what is in it, and which brands appear?" in one round trip:

params = {
    "api-version": "2024-02-01",
    "features": "tags,objects,brands",
}

result = response.json()
brands = result["brandsResult"]["values"]
print("Brands:", [b["name"] for b in brands])

for obj in result["objectsResult"]["values"]:
    print(f"Object: {obj['name']}")

Practical Uses and Caveats

  • Marketing teams use brand detection to measure product placement and sponsorship visibility.
  • Content platforms can detect competing brands appearing in user uploads.
  • Confidence below about 0.5 is usually unreliable; apply a threshold before acting on the result.
  • Occult, distorted, or heavily stylized logos are frequently missed.

Detecting a brand in an image is not permission to use its logo. Trademark law governs how logos may be displayed and reused. Use brand detection for analysis and reporting, not for reproducing or repurposing brands in your own materials.
