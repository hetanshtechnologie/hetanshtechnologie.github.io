Using OpenAPI Tools Review

This review tests your understanding of the OpenAPI tools section: how Azure Functions hosts an API, what the OpenAPI specification describes, how Foundry turns a spec into agent tools, and how authentication protects the whole flow. Try each question from memory before checking the answer key.

Questions

Question 1

In the Python v2 programming model, what declares that a function is reachable over HTTP and sets its route and methods?

A. A separate function.json file
B. The @app.route decorator on the handler
C. The app.trigger("http") function
D. An entry in host.json

Correct answer: B.

Question 2

What does the operationId field in an OpenAPI document become when the spec is attached to a Foundry agent?

A. The URL of the endpoint
B. The HTTP method
C. The tool name the model sees
D. The authentication header name

Correct answer: C.

Question 3

A support agent should answer politely when a customer asks about an order that does not exist. Which API design detail makes that possible?

A. A 200 response with an empty body
B. A 404 status code with a JSON error message the model can read
C. Returning the whole order list
D. Logging the request silently

Correct answer: B.

Question 4

Which OpenAPI document section lists the base URL the operations are resolved against?

A. paths
B. info
C. components
D. servers

Correct answer: D.

Question 5

After changing a route's auth level to FUNCTION, what does a request without a key receive?

A. 200 OK with the data
B. 401 Unauthorized
C. 404 Not Found
D. 409 Conflict

Correct answer: B.

Question 6

Where should the function key value live so the model never sees it?

A. In the OpenAPI document's servers block
B. In the agent connection's API key header configuration
C. In the operation summary text
D. In a chat prompt to the model

Correct answer: B.

Question 7

Which authentication method avoids storing any shared secret by letting the platform request a token as its own Azure identity?

A. API key in a header
B. Basic auth
C. Managed identity
D. API key in the query string

Correct answer: C.

If you missed more than two questions, re-read the OpenAPI and authentication chapters before moving on. The next chapters close out the section with cost management and cleanup, so make sure the core concepts are solid first.

Summary

This review checked the full journey of an OpenAPI tool: building an API on Azure Functions, describing it with a specification, attaching it to an agent, and securing it with a function key. With the mechanics confirmed, the next chapters look at what this section costs and how to clean it up.
