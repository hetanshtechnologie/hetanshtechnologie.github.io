Setup Checklist

Before running any of the scripts, confirm your environment is ready:

  • An Azure AI Speech resource exists, and you have its key and region.
  • Python 3.9 or later is installed, and a virtual environment is active.
  • The Speech SDK is installed: pip install azure-cognitiveservices-speech
  • Environment variables YOUR_SPEECH_KEY and YOUR_SPEECH_REGION are set.
  • An audio file named sample.wav is present in the working folder.

Store the key and region in environment variables exactly as the labs show, never in the script files. If you commit code to source control, add a .gitignore entry or use a local .env file that is never committed.

Quick Start Commands

Once the environment is ready, the four scripts run in the same order the labs introduced them:

$env:YOUR_SPEECH_KEY = "PASTE_YOUR_KEY_HERE"
$env:YOUR_SPEECH_REGION = "eastus"

python transcribe_file.py          # transcribe sample.wav
python realtime_dictation.py       # listen from the microphone
python synthesize_speech.py        # create welcome.mp3
python translate_speech.py         # stream live translation

Resources You Should Have Created

  • A Speech services resource (the single most important prerequisite for this whole section).
  • A working Python virtual environment with the Speech SDK.
  • If you followed the MCP lab: an MCP client configured with the Azure Speech MCP server.

Speech billing is based on usage: per-minute of recognized audio, per-character of synthesized audio, and per-second for open streaming sessions. After you finish the labs, stop any running recognizers and consider deleting the resource if you created it only for this course — or at least review its spending before the next section.
