OpenAI API Platform - Sign-up

ChatGPT is the consumer product, but this course is about building applications. For that you need the OpenAI API platform — the developer side of OpenAI where you create API keys, manage credits, and call the models programmatically. This chapter walks you through creating the account and obtaining your first API key.

Consumer Product Versus Developer Platform

It is easy to confuse the two sides of OpenAI's offering, so keep this distinction clear:

AspectChatGPTOpenAI API platform
Who it is forEnd users chatting in a web or mobile interfaceDevelopers calling models from code
InterfaceChat windowDeveloper dashboard plus REST APIs and SDKs
BillingFree tier or consumer subscriptionPay-as-you-go for API usage, with prepaid credits for new accounts
Product you getAssistant conversationsAPI keys, models, usage metrics, and code samples

Both can share the same email address, but they are separate accounts with separate billing. The chapters that follow use the API platform.

Requirements Before You Start

  • A working email address you can verify.
  • A phone number for account verification.
  • A payment method. New accounts typically receive prepaid credits, but OpenAI still asks for a card for verification and for usage beyond those credits.

Sign-up details, free-credit amounts, and regional availability change over time and vary by country. If your region is not supported, you will be told during sign-up. The general flow described here — verify your identity, create a key, store it securely — has been stable for years.

Step-by-Step: Create the Account

Exercise 1: Sign up for the OpenAI API platform

  1. Open a browser and go to the OpenAI platform sign-in page.
  2. Click Sign up and create an account with your email, or sign in with Google or Microsoft. If you already have a ChatGPT account, you can use the same identity.
  3. Verify your email address by clicking the confirmation link that OpenAI sends you.
  4. Complete any required identity verification steps (often a phone number).
  5. When prompted, add a payment method. Confirm that the account has prepaid credit available before you start making API calls.
  6. Open the API keys page from the platform dashboard.
  7. Click Create new secret key, give it a name such as ai103-course, and click Create secret key.
  8. Copy the key and store it somewhere safe — you cannot view the full key again later.

About API Keys

An API key is a long string that identifies your account on every request. Your code sends it in an HTTP header, and OpenAI uses it to authenticate you, to track usage, and to bill the correct account. Treat it exactly like a password:

  • Never paste it into a public chat, a forum, or a shared code repository.
  • Never hard-code it in source code that others can read.
  • Use environment variables or a .env file (which you should add to .gitignore).
  • If a key leaks, revoke it immediately from the API keys page and create a new one.

Anyone who has your API key can spend your credit. OpenAI and Azure both monitor for leaked keys and may block them, but you should never rely on that — protect the key from the start, and rotate it as soon as you suspect exposure.

Credits and Billing

API usage is metered: you pay for tokens sent and received, with prices depending on the model. New accounts usually start with prepaid credit, which is perfect for the small requests in this course. Before each lab, check the platform's billing or usage page to confirm how much credit remains — the requests in this section cost fractions of a cent each, so a small amount of credit goes a long way.

Create a dedicated key per project and name it clearly, like ai103-course. If one project's key ever leaks, you can revoke just that key without breaking your other projects.

Summary

The OpenAI API platform is the developer side of OpenAI, separate from the ChatGPT consumer product. You created your account, verified your identity, added a payment method, and generated a named API key, then learned how to protect it. With a key in hand, the next chapter explores the playground — the fastest way to experiment with models before writing any code.
