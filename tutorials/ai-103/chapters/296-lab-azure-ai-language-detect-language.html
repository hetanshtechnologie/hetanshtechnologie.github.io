Lab - Azure AI Language - Detect Language

Language detection answers a deceptively simple question: which language is this text written in? It matters more than you might think. A document that arrives in German, Spanish, or Japanese needs a different translation, summarization, or routing pipeline than an English one. In this lab you will try the Azure AI Language language detection feature in your browser using Language Studio — no code required. The next chapter creates the resource formally; here you will see the feature working and learn to read its output.

What You Need

  • An Azure account you can sign in to.
  • Access to Language Studio at https://language.cognitive.azure.com/.
  • A few sample sentences in different languages. You can write your own or use the ones in this lab.

Open Language Studio and Connect a Resource

Language Studio needs a Language resource to run its models. If you have never used the service before, the portal will prompt you to select an existing resource or create a new one as part of the flow. You can accept that offer here — the formal portal and CLI creation steps come in the next chapter.

  1. Open a browser and go to https://language.cognitive.azure.com/.
  2. Sign in with the Microsoft account tied to your Azure subscription.
  3. On the home page, find the resource selector (usually near the top-right). Choose your subscription and your Language resource, or select Create new resource and follow the dialog.
  4. Wait for the resource to be linked, then continue to the feature gallery.

Language Studio groups features by category. Look for Classify text and Extract information tiles — language detection lives under the classification area of the gallery.

Detect the Language of a Text

Exercise 1: Detect a language in Language Studio

  1. From the Language Studio home page, select the Detect language tile under Classify text.
  2. In the Upload text tab, paste this English sentence into the text box: Customer service resolved my issue within minutes.
  3. Confirm the resource selector is pointed at your Language resource.
  4. Select Run. The page now shows the detected language, its ISO code, and a confidence score.
  5. Replace the text with Meine Bestellung ist noch nicht angekommen. and run again. Note the language code changes to de.
  6. Try ¿Dónde está la oficina de reclamaciones? and ご注文ありがとうございます。. Record the codes: es for Spanish and ja for Japanese.

Reading the Result

Language Studio displays the outcome, and underneath it shows the JSON the service returned. For a single document the response contains one result with three useful fields:

FieldExampleMeaning
iso6391NamedeThe two-letter language code used across systems
nameGermanHuman-readable language name
confidenceScore1.0How sure the model is, from 0 to 1

Your application will usually store the ISO code and the confidence, and drop the display name.

Detect Languages for a Batch

Exercise 2: One request, several documents

  1. Back in the Detect language page, switch to the Upload text area and paste all five sentences below, one per line:
The quarterly report is attached for your review.
Der neue Sensor wird nächste Woche installiert.
La factura fue enviada por correo electrónico.
Le remboursement est approuvé.
商品は明日発送されます。
  1. Run the analysis. Language Studio returns one result per line, each with its own code and confidence.
  2. Compare the confidence scores across the five documents. Longer, clearly structured sentences should score near 1.0.

Short texts are the hardest case for any language detector. A single shared word like menu or hôtel can be ambiguous, and the confidence score drops accordingly. When you route on language, set a threshold (for example, 0.8) and send anything below it to a human or a fallback queue instead of guessing.

Why Confidence Scores Matter

The detection model returns a probability-like score. A score near 1.0 means the evidence is strong; a score near 0.5 means the model is genuinely torn between languages. Applications rarely act on the score alone — they combine it with a business rule. A support portal, for example, might auto-assign tickets in confident languages and flag ambiguous ones for manual triage.

Do not treat the language name as a country. German (de) is spoken in several countries, and es covers Spain and Latin America. The service detects the language, not the locale. If you need regional variations, handle locale detection separately.

Summary

You used Language Studio to detect the language of single texts and batches, and you learned to read the three fields that matter: the ISO code, the language name, and the confidence score. The next chapter formalizes the setup by creating the Azure AI Language resource you will use for the rest of this section.
