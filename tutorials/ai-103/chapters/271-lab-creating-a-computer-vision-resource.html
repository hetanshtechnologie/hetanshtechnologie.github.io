Lab - Creating a computer vision resource

In this lab you will provision a Computer Vision resource in your Azure subscription — the endpoint and key that every image analysis call in this section will use. A Computer Vision resource is a single Azure service, separate from the AI Services resource you may have created for language or Foundry workloads. By the end of the lab you will have a working resource, know where to find its endpoint and keys, and be able to verify it responds to requests.

Prerequisites

  • An active Azure subscription. If you have completed earlier sections of this course you already have one.
  • Permission to create resources in that subscription.
  • The Azure CLI installed, if you want to try the command-line route.

What the Resource Provides

The Computer Vision resource gives you two things your code will depend on:

  • An endpoint — the base URL your requests are sent to, with a form such as https://YOURNAME.cognitiveservices.azure.com/.
  • Access keys — secret values that authenticate your requests. You can have two keys so you can rotate one without downtime.

Keep the endpoint and key together somewhere you can find them later; nearly every remaining lab in this section starts by pasting them into a script or a configuration file.

Step-by-Step: Create the Resource in the Portal

Exercise 1: Create a Computer Vision resource through the Azure portal

  1. Open a browser and go to the Azure portal at https://portal.azure.com. Sign in with your Azure account.
  2. Use the search bar at the top and type Computer Vision. Select Computer vision from the results.
  3. Click Create. You will land on the "Create Computer vision" blade.
  4. Choose your subscription, then select or create a resource group. A dedicated group such as rg-ai103-vision keeps this section's resources together.
  5. Give the resource a globally unique name, for example cv-ai103-<yourname>. Only letters, numbers, and hyphens are allowed.
  6. Select a region. Pick one that is geographically close to you for lower latency.
  7. Choose a pricing tier. The free tier F0 is sufficient for the labs in this course. Note that the free tier has monthly call limits; if you expect to exceed them, use the standard tier.
  8. Review your settings and click Review + create, then Create. The deployment takes less than a minute.
  9. When the deployment completes, click Go to resource.
  10. In the resource menu, open Keys and Endpoint. Copy the endpoint URL and one of the two keys — you will use them throughout this section.

On the free tier, image analysis calls are limited to a small number of transactions per minute and per month. If a lab starts returning HTTP 429 (too many requests) responses, wait a moment and retry, or temporarily switch the resource to a paid tier.

Create the Resource with Azure CLI

The Azure CLI achieves the same result and is repeatable across environments. First sign in, then create the resource group and the Computer Vision resource:

az login

az group create --name rg-ai103-vision --location eastus

az cognitiveservices account create --resource-group rg-ai103-vision \
  --name cv-ai103-demo \
  --kind ComputerVision \
  --sku F0 \
  --location eastus

Note the --kind ComputerVision value: it creates the single-service vision resource rather than the multi-service AI Services account. After the resource exists, fetch its endpoint and keys:

# Show the endpoint
az cognitiveservices account show --resource-group rg-ai103-vision \
  --name cv-ai103-demo --query "properties.endpoint"

# Show both access keys
az cognitiveservices account keys list --resource-group rg-ai103-vision \
  --name cv-ai103-demo --query "[key1, key2]"

Verify the Resource Responds

Confirm the resource works before you start the labs. The quickest check is a minimal request against the endpoint. This call asks for a caption on a public sample image:

curl -X POST \
  "https://YOUR_ENDPOINT/computervision/imageanalysis:analyze?api-version=2024-02-01&features=caption" \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -d '{"url": "https://upload.wikimedia.org/wikipedia/commons/1/1e/Cat_and_dog.jpg"}'

If you see a JSON response containing a captionResult field, the resource is working. If you get an authentication error, double-check that the key is copied exactly and that there are no extra spaces. If you get a 404, confirm the endpoint value is complete — it must include the scheme and host, for example https://cv-ai103-demo.cognitiveservices.azure.com/.

Clean Up When You Are Done

Once you finish this entire section you can remove the resource by deleting its resource group. Everything created inside it goes with it:

az group delete --name rg-ai103-vision --yes --no-wait

Deleting a resource group is permanent and cannot be undone. Wait until you have finished every vision lab in this course before removing it, because all of them depend on this resource.

Summary

In this lab you created a Computer Vision resource through the Azure portal and the Azure CLI, retrieved its endpoint and keys, and verified it responds to a caption request. This resource is the backbone of the image analysis labs that follow, which will move from the portal to Python and finally to raw REST calls.
