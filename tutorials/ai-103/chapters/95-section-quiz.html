Section Quiz

This quiz checks your understanding of the section: continuous evaluation, response completeness, diagnostics and tracing, guardrails and content filters, prompt shields, and the model router. Read each question, pick the best answer, and check yourself against the answer key at the end.

The Quiz

  1. What does a continuous evaluation flow in Foundry do?
    • A) It retrains the agent's model on new user data.
    • B) It periodically scores recent conversations with evaluators and records the trends. (correct)
    • C) It monitors deployment latency only.
    • D) It blocks harmful content.
  2. Which evaluator measures whether an answer covers everything the user asked for?
    • A) Groundedness
    • B) Relevance
    • C) Completeness (correct)
    • D) Fluency
  3. When a model stops because it hit the output token limit, what does finish_reason report?
    • A) stop
    • B) length (correct)
    • C) filter
    • D) error
  4. What is a diagnostic setting?
    • A) A prompt that tells the model how to behave.
    • B) A rule that streams a resource's logs and metrics to durable destinations. (correct)
    • C) A deployment configuration for model routing.
    • D) A content filter threshold.
  5. In tracing, what is a span?
    • A) A single log line in chronological order.
    • B) One operation inside a trace, with timing, identity, and attributes. (correct)
    • C) A harm category.
    • D) A model deployment.
  6. Which harm categories do content filters screen against?
    • A) Hate, sexual, violence, and self-harm (correct)
    • B) Spam, phishing, and malware
    • C) Copyright, trademark, and patent
    • D) Only profanity
  7. What is indirect prompt injection?
    • A) The user directly ordering the model to ignore its system prompt.
    • B) Malicious instructions hidden inside retrieved documents or tool output. (correct)
    • C) A model producing copyrighted text.
    • D) A content filter blocking safe content.
  8. Which statement about the model router is correct?
    • A) It spreads identical traffic across identical servers.
    • B) It sends each request to the most appropriate model based on routing rules. (correct)
    • C) It retrains models on routing decisions.
    • D) It replaces content filters.

Answer Key

QuestionAnswerWhy
1BContinuous evaluation re-scores recent data on a schedule and tracks trends.
2CCompleteness specifically measures coverage of the request.
3Blength signals truncation at the token limit.
4BA diagnostic setting routes telemetry to workspaces, storage, or event hubs.
5BA span is one operation within a trace, nested under a parent.
6AThe four main categories are hate, sexual, violence, and self-harm.
7BIndirect injection arrives through content the agent retrieves.
8BRouting chooses the best model per request rather than balancing identical work.

Summary

This quiz covered the observability and safety layer of the course: continuous evaluation scores agent quality over time, response completeness identifies coverage gaps, diagnostics and tracing make platform and agent behaviour inspectable, and guardrails — content filters and prompt shields — enforce safety boundaries. Finally, the model router allocates requests to the right model. If you scored eight of eight, you are ready for the LangChain section. Otherwise, re-read the chapters you missed before moving on.
