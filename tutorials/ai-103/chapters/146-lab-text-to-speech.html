Lab - Text-to-Speech

In this lab you will give your application a voice. You will use the Azure Speech SDK to synthesize a sentence into an audio file, then extend the script to control delivery with SSML, choosing a specific neural voice, a speaking rate, and a pause for dramatic effect. By the end you will have a reusable function that turns any string into speech audio.

Exercise: Synthesizing speech from Python

Step 1 — Confirm your setup

This lab uses the same Speech resource and virtual environment as the previous labs. Verify the SDK is installed:

pip show azure-cognitiveservices-speech

If the package is missing, install it again as you did in the speech-to-text lab.

Step 2 — Write a basic synthesis script

Create synthesize_speech.py. The script reads the key and region from environment variables, renders the text with a named neural voice, and saves the result to an MP3 file.

import os

import azure.cognitiveservices.speech as speechsdk

SPEECH_KEY = os.environ.get("YOUR_SPEECH_KEY", "")
SPEECH_REGION = os.environ.get("YOUR_SPEECH_REGION", "")
VOICE_NAME = os.environ.get("VOICE_NAME", "en-US-JennyNeural")

speech_config = speechsdk.SpeechConfig(
    subscription=SPEECH_KEY,
    region=SPEECH_REGION,
)
speech_config.speech_synthesis_voice_name = VOICE_NAME

speech_config.set_speech_synthesis_output_format(
    speechsdk.SpeechSynthesisOutputFormat.Audio24Khz160KBitRateMonoMp3
)

synthesizer = speechsdk.SpeechSynthesizer(speech_config=speech_config)
text = (
    "Welcome to the speech and voice section of AI-103. "
    "This audio was synthesized entirely by code."
)

result = synthesizer.speak_text_async(text).get()

if result.reason == speechsdk.ResultReason.SynthesizingAudioCompleted:
    stream = speechsdk.AudioDataStream(result)
    stream.save_to_file("welcome.mp3")
    print("Saved to welcome.mp3")
elif result.reason == speechsdk.ResultReason.Canceled:
    cancellation = speechsdk.CancellationDetails(result)
    print(f"Canceled: {cancellation.reason} — {cancellation.error_details}")

Step 3 — Run it and listen

python synthesize_speech.py

Open welcome.mp3 in any player. You should hear a natural female neural voice reading your sentence.

Step 4 — Take control with SSML

Now create synthesize_ssml.py. Instead of plain text, it sends an SSML document that selects a voice, slows the pace, and inserts a pause. Note that angle brackets inside the XML must be escaped inside the HTML source of this page.

import os

import azure.cognitiveservices.speech as speechsdk

SPEECH_KEY = os.environ.get("YOUR_SPEECH_KEY", "")
SPEECH_REGION = os.environ.get("YOUR_SPEECH_REGION", "")

speech_config = speechsdk.SpeechConfig(
    subscription=SPEECH_KEY,
    region=SPEECH_REGION,
)
synthesizer = speechsdk.SpeechSynthesizer(speech_config=speech_config)

ssml = """<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis"
         xmlns:mstts="https://www.w3.org/2001/mstts" xml:lang="en-US">
  <voice name="en-US-AriaNeural">
    <mstts:express-as style="cheerful">
      <prosody rate="0.9">
        Great work!<break time="600ms"/>
        Your pipeline now has a voice.
      </prosody>
    </mstts:express-as>
  </voice>
</speak>"""

result = synthesizer.speak_ssml_async(ssml).get()

if result.reason == speechsdk.ResultReason.SynthesizingAudioCompleted:
    speechsdk.AudioDataStream(result).save_to_file("ssml_demo.mp3")
    print("Saved to ssml_demo.mp3")
else:
    cancellation = speechsdk.CancellationDetails(result)
    print(f"Canceled: {cancellation.reason} — {cancellation.error_details}")

Step 5 — Compare the two outputs

python synthesize_ssml.py

Play ssml_demo.mp3 next to welcome.mp3. The second clip uses a different voice, speaks slightly slower, carries a cheerful tone, and pauses deliberately after the first phrase — all controlled by markup rather than by editing the audio file.

Reading the Result

Note how the SDK returns a SpeechSynthesisResult whose reason tells you whether audio was produced. The AudioDataStream object is what lets you save the bytes to a file. For short clips, you can also access result.audio_data directly as a byte array and stream it to a speaker or a network connection.

You do not need to generate audio synchronously. The SDK supports an event model — Synthesizing, SynthesisStarted, SynthesisCompleted — that lets you start playing the beginning of a long narration before the end has been generated.

Choosing the Right Voice

The voice name is simply a string such as en-US-JennyNeural or en-GB-SoniaNeural. You can list all available voices by calling the voices list endpoint and filtering by locale and gender. When you pick a voice, keep your audience in mind: the same sentence sounds different in a news anchor voice versus a conversational one, and matching the voice to the product's personality matters as much as the words themselves.

Custom neural voices are a governed resource. Training a voice on someone's recordings requires consent, and Microsoft enforces usage policies on custom voice deployment. If you plan to build a custom voice, review the responsible AI guidance for speech before uploading any recordings.

Summary

You synthesized audio from plain text with the Speech SDK, saved the output to an MP3 file, and then took control of voice, rate, tone, and pauses using an SSML document. TTS is now a drop-in building block for your applications.
