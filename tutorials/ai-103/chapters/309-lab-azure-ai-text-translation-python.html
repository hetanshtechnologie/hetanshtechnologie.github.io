Lab - Azure AI Text Translation - Python

In this lab you will use the Azure AI Text Translation service from Python. Instead of hand-building HTTP requests, you will work with the azure-ai-translation-text SDK, which wraps the translation REST endpoint in a clean client object. By the end of the lab you will have a small reusable function that translates any sentence into one or more target languages with only a few lines of code.

Exercise: Translating text with the Python SDK

Step 1 — Check your prerequisites

You need a Translator resource (or a multi-service Azure AI Services resource) with its endpoint, key, and region handy. If you have not created one yet, review the previous chapter. You also need Python 3.8 or newer.

  • Endpoint — something like https://YOUR-NAME.cognitiveservices.azure.com/
  • Subscription key — shown under Keys and Endpoint in the Azure portal
  • Region — the region you selected when you created the resource

Step 2 — Install the SDK

Create a virtual environment if you do not already have one, then install the translation client library.

pip install azure-ai-translation-text

Step 3 — Write the translation script

Create a file named translate_demo.py with the following content:

from azure.ai.translation.text import TextTranslationClient, TranslatorCredential
from azure.ai.translation.text.models import InputTextItem

ENDPOINT = "YOUR_TRANSLATOR_ENDPOINT"
KEY = "YOUR_TRANSLATOR_KEY"
REGION = "YOUR_TRANSLATOR_REGION"

credential = TranslatorCredential(KEY, REGION)
client = TextTranslationClient(endpoint=ENDPOINT, credential=credential)


def translate(sentence, target_language):
    response = client.translate(
        body=[InputTextItem(text=sentence)],
        to_language=[target_language],
    )
    if response and response[0].translations:
        return response[0].translations[0].text
    return ""


if __name__ == "__main__":
    source = "Good morning, the weather is lovely today."
    print("Source:", source)
    for lang in ("es", "de", "fr", "hi"):
        print(f"{lang}: {translate(source, lang)}")

Replace the three placeholder values at the top with the details from your resource, then save the file.

Step 4 — Run the script

python translate_demo.py

You should see the same sentence rendered in Spanish, German, French, and Hindi. Each call to client.translate() sends one request, and the service returns the translations as strongly typed objects.

Translating Several Sentences at Once

You do not have to call the service once per sentence. The API accepts a list of documents in a single request, and it can return every target language in the same response. This cuts down on round trips and on cost if your resource is billed per character.

sentences = [
    "Hello, how are you today?",
    "The quarterly report is ready.",
    "Please deploy the new service to production.",
]
targets = ["es", "fr", "ja"]

for sentence in sentences:
    response = client.translate(
        body=[InputTextItem(text=sentence)],
        to_language=targets,
    )
    print(sentence)
    for translation in response[0].translations:
        print(f"  {translation.to}: {translation.text}")

How the Request Is Structured

Behind the scenes the SDK sends a POST to /translator/text/v3.0/translate with a JSON body that lists the input texts and a query string that lists the target languages. The SDK builds those details for you, which means your code stays stable even if the URL or version changes. Notice that the language codes are ISO 639-1 values such as es, fr, and ja.

Keep the endpoint, key, and region out of your source code in a real project. Read them from environment variables or from a secrets store, and never commit them to a repository.

Summary

You installed the translation SDK, built a reusable translate function, and translated several sentences into multiple languages in a single request. The service also exposes batch, dictionary lookup, and transliteration operations, but the translate call you built here is the workhorse you will reach for first. In the next chapter you will perform the same translation using the raw REST API to see exactly what the SDK is doing under the hood.
