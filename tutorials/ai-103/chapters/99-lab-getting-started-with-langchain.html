Lab - Getting started with LangChain

In this lab you will get LangChain installed and running against a model deployed in Microsoft Foundry. By the end you will have a repeatable Python environment, a working connection to your deployed chat model, and a first chain that turns a user request into a formatted response. This environment is the foundation for every LangChain lab that follows, so take the time to verify each step before moving on.

Prerequisites

Before you start, confirm you have the following:

  • Python 3.10 or newer installed on your machine. Check with python --version on Windows or python3 --version on macOS and Linux.
  • pip available for installing packages.
  • A model deployment in Microsoft Foundry, with its endpoint URL, deployment name, and API key at hand. If you deleted your deployment earlier, redeploy a chat model before continuing.
  • A comfortable code editor — Visual Studio Code is a good choice for the rest of this course.

Keep your API key out of your code. Never paste a real key directly into a Python file that might be shared or committed to a repository. Use environment variables instead, as shown in this lab.

Step 1: Create an Isolated Environment

An isolated virtual environment keeps the packages you install for LangChain separate from the rest of your system. This avoids version conflicts between projects and makes your setup reproducible. Create a project folder and a virtual environment inside it:

mkdir langchain-lab
cd langchain-lab
python -m venv .venv

Activate the environment so that pip and python refer to it:

  • Windows (PowerShell): .venv\Scripts\Activate.ps1
  • macOS / Linux: source .venv/bin/activate

When the environment is active you will see its name in your prompt. Now install the packages you need:

pip install "langchain" "langchain-openai" "python-dotenv"

The langchain-openai package provides integrations for both OpenAI and Azure OpenAI-compatible endpoints. It is the package that brings the AzureChatOpenAI class into your project.

Step 2: Store Your Connection Details

Create a file named .env in the project folder and store your deployment details in it. The python-dotenv package will load these values into your environment when your code runs:

AZURE_OPENAI_ENDPOINT=https://YOUR_ENDPOINT
AZURE_OPENAI_API_KEY=YOUR_KEY
AZURE_OPENAI_DEPLOYMENT_NAME=ai103-chat-deploy
AZURE_OPENAI_API_VERSION=2024-06-01

Replace YOUR_ENDPOINT and YOUR_KEY with the values from your Foundry deployment, and make sure AZURE_OPENAI_DEPLOYMENT_NAME exactly matches the deployment name you chose when you deployed the model.

If you share your code, never share the .env file. Add .env to a .gitignore file if you initialize a repository in this folder.

Step 3: Make Your First Model Call

Exercise 1: Call your Foundry deployment through LangChain

Create a file named first_call.py with the following content:

import os

from dotenv import load_dotenv
from langchain_openai import AzureChatOpenAI

load_dotenv()

model = AzureChatOpenAI(
    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("AZURE_OPENAI_API_KEY"),
    api_version=os.getenv("AZURE_OPENAI_API_VERSION"),
    deployment_name=os.getenv("AZURE_OPENAI_DEPLOYMENT_NAME"),
    temperature=0.7,
)

response = model.invoke("Explain what a token is in one sentence.")
print(response.content)

Run the script from the activated environment:

python first_call.py
  1. If everything is configured correctly, the script prints a single-sentence answer about tokens.
  2. Run it again. The exact wording may differ because sampling introduces randomness.
  3. Temporarily set temperature=0 and run it a few times. With greedy decoding the output becomes far more consistent.

The invoke method is the core entry point in LangChain. It accepts input, runs the full pipeline, and returns the result. Every LangChain object you build — models, prompts, chains, and agents — supports invoke, which is what makes it so easy to combine them.

Step 4: Build a Prompt-and-Response Chain

A single model call is rarely enough for a real application. You usually want a system instruction, a templated user prompt, and a clean string output. LangChain composes these pieces with the pipe operator. Create a file named greeter.py:

import os

from dotenv import load_dotenv
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_openai import AzureChatOpenAI

load_dotenv()

model = AzureChatOpenAI(
    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("AZURE_OPENAI_API_KEY"),
    api_version=os.getenv("AZURE_OPENAI_API_VERSION"),
    deployment_name=os.getenv("AZURE_OPENAI_DEPLOYMENT_NAME"),
    temperature=0.5,
)

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a friendly course assistant for AI-103."),
    ("human", "Greet the learner named {name} and tell them what today's topic is: {topic}."),
])

chain = prompt | model | StrOutputParser()

result = chain.invoke({"name": "Sam", "topic": "LangChain"})
print(result)

Run the script:

python greeter.py

This time the flow has three stages: the ChatPromptTemplate fills the placeholders from the input dictionary, the model generates an answer, and the StrOutputParser extracts just the text. The chain is nothing more than those three pieces connected with |.

Try changing the prompt to ask for the answer as JSON, then swap StrOutputParser for LangChain's JSON output parser. You will get a parsed Python dictionary back instead of text — a pattern you will use repeatedly in later chapters.

Step 5: Inspect What Happens Under the Hood

LangChain objects expose rich metadata through attributes. A small change to the model call lets you see token usage and the raw response:

response = model.invoke("List three Azure AI services.")
print(response.content)
print("Token usage:", response.usage_metadata)

The usage_metadata dictionary shows prompt tokens, completion tokens, and total tokens for the request. Watching this number is a good habit because it maps directly to cost when your application scales.

Summary

You installed LangChain into an isolated Python environment, stored your Foundry deployment details in a .env file, made your first model call through AzureChatOpenAI, and composed your first prompt-and-response chain with the pipe operator. You also saw how to read token usage from the response. In the next chapter you will learn what an agent is and how LangChain builds one from models and tools.
