Lab - Creating an Azure AI Foundry resource

This lab creates the Azure resources that everything else in the course depends on: a resource group, an Azure AI Foundry hub with its supporting services, and a project inside the hub. You will do the primary steps in the Azure portal, and I will show the Azure CLI equivalents for each step in case you prefer working from Cloud Shell.

What You Will Need

  • Your Azure free account from the earlier chapters.
  • Access to the Azure portal at portal.azure.com, signed in with that account.
  • A preferred region that supports Azure AI Foundry — check the region selector during creation if you are unsure.

Names matter. Azure resource names are globally or regionally unique depending on the type, and some characters are disallowed. Use short, lowercase names without spaces or underscores — for example ai103-hub rather than "AI 103 hub". If the portal complains a name is taken, append a few random characters and retry.

Step 1: Create a Resource Group

Exercise 1: Create the course resource group

  1. Open the Azure portal and use the global search bar to open Resource groups.
  2. Click Create.
  3. Choose your subscription. For the resource group name enter rg-ai103.
  4. Select a region near you (for example East US or West Europe — any supported region works).
  5. Click Review + create, then Create. The resource group appears in your list within seconds.
# Same step from Azure CLI
az group create --name rg-ai103 --location eastus

Pick the region now and use it consistently for every resource in this course. A single region keeps model availability predictable and makes cleanup a one-step delete of the whole resource group.

Step 2: Create the Azure AI Hub

Exercise 2: Create the Foundry hub

  1. Use the portal search bar and search for Azure AI Foundry (the service entry, not the portal link).
  2. Open the service page and click Create.
  3. Fill in the basics:
    • Subscription: your free account subscription.
    • Resource group: rg-ai103.
    • Region: the region you chose in Step 1.
    • Name: ai103-hub.
    • Tier: choose the basic/free tier where available.
  4. Under the AI services and storage settings, let the wizard create the supporting resources automatically — it provisions an AI model service, a storage account, and a key vault for you. If it asks for names, use simple values such as ai103-model-svc, ai103store, and ai103vault.
  5. Click Review + create, verify the summary, then Create.
  6. Wait for the deployment to finish — this can take a few minutes because the supporting services are created together.

The hub's storage and key vault are created in the same resource group automatically. Do not delete them individually; they are wired into the hub and are deleted as part of it.

Step 3: Create a Project

Exercise 3: Create the project inside the hub

  1. On the hub's overview page in the portal, click the button to open it in Azure AI Foundry (labeled something like "Launch Foundry" or "Go to portal").
  2. In the Foundry portal you will be offered the choice to create a new project.
  3. Enter a project name such as ai103-project.
  4. Leave the other settings at their defaults — the project uses your hub's connected resources automatically.
  5. Click Create and wait for the project to appear in the project list.
# Azure CLI creates the resource; the project itself is created
# from the Foundry portal, or programmatically via the Azure SDK.
# The CLI equivalent for the hub resource looks like this:
az resource create \
  --resource-group rg-ai103 \
  --resource-type Microsoft.MachineLearningServices/workspaces \
  --name ai103-hub \
  --location eastus \
  --properties "{\"kind\":\"Hub\"}"

If the Foundry portal does not offer project creation immediately, return to the Azure portal, open your hub's resource page, and use the dedicated launch button there. It carries your hub into the Foundry portal pre-selected, and project creation is the next screen.

Step 4: Verify Everything Exists

Back in the Azure portal, open Resource groups and click rg-ai103. You should see the hub, the model service, the storage account, and the key vault listed together. Opening the hub's page shows its region, tier, and the connected resources. This single group is now the entire foundation of the course — everything you deploy later will be a model inside its model service, visible in this group.

Step 5: Record Your Connection Details

Before moving on, collect the values the next chapters will use. On the hub's page, look for Properties and Keys and Endpoint:

  1. Note the hub's endpoint URL (for example https://ai103-hub.cognitiveservices.azure.com).
  2. Open the model service resource (the AI service created with the hub) and copy one of its keys from the Keys and Endpoint blade.
  3. Write these down in a local, private note file along with your resource names and region.

That key is a secret. Store it in a local file you keep out of version control, or in an environment variable. The next labs will reuse it, so losing it means going back to the portal to copy it again — not a disaster, but avoidable.

Summary

You created a resource group, an Azure AI hub with its supporting services, and a project inside the hub, and you recorded your endpoint and key. Your course infrastructure now exists and is ready to host model deployments. If anything in your resource group looks wrong, remember the fast reset: delete rg-ai103 and recreate it. Next you will launch the Foundry portal and explore its interface.
