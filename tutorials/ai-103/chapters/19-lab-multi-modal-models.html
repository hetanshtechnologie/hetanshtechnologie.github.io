Lab - Multi-modal models

In this lab you will work with a multi-modal model: one that can accept images alongside text and answer questions about what it sees. You will send a local image to your deployment as base64 data, ask for a description, and then ask follow-up questions about details in the image.

What You Need

  • A vision-capable model deployed in Foundry, for example gpt-4o-mini or gpt-4o. Models that accept image input are usually described as vision or multimodal in the catalogue.
  • The endpoint and key environment variables from the earlier labs.
  • An image file on your machine, for example a photo you took or a screenshot. PNG and JPEG both work.

Not every chat model accepts images. If the request fails with a 400 error, check that the model you deployed is advertised as supporting image input.

How Images Travel to the Model

Images are not uploaded as separate files in the chat API. Instead they are embedded in the message as a data URI: a base64-encoded copy of the image bytes prefixed with a MIME type such as data:image/png;base64,.... The user message then becomes a list of parts — one for text and one for the image — instead of a plain string.

Prepare a Small Image

Large photos increase latency and cost because the model processes many image tokens. It helps to resize or crop to something like 1024 pixels on the longest side before sending. Most photo apps and even simple code can do this; for this lab a normal photo is fine, but keep it under a few megabytes.

Step 1 - Create the vision script

Create a folder ai103-lab19 and add a file vision.py:

from openai import AzureOpenAI
import base64
import os

client = AzureOpenAI(
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_KEY"],
    api_version="2025-01-01-preview",
)

with open("YOUR_IMAGE.png", "rb") as f:
    image_bytes = f.read()

data_uri = "data:image/png;base64," + base64.b64encode(image_bytes).decode("utf-8")

response = client.chat.completions.create(
    model="YOUR_DEPLOYMENT_NAME",
    messages=[
        {"role": "system", "content": "You describe images accurately and in a few sentences."},
        {"role": "user", "content": [
            {"type": "text", "text": "Describe what you see in this image."},
            {"type": "image_url", "image_url": {"url": data_uri}},
        ]},
    ],
)
print(response.choices[0].message.content)

Step 2 - Run it

python vision.py

The model should describe the contents of the image. If the file is a JPEG, change the extension in open(...) and the MIME type to image/jpeg.

Asking Targeted Questions

You can combine the image with precise questions to turn the model into an extraction engine. Try asking about specific details:

{"role": "user", "content": [
    {"type": "text", "text": "Count the number of people in the image. Then describe what the person in the centre is wearing."},
    {"type": "image_url", "image_url": {"url": data_uri}},
]}

Reading Text from Images

Vision models can also read text embedded in images, which makes them useful for screenshots, signs, and receipts. Replace the question text with:

{"type": "text", "text": "Transcribe all of the text you can see in this image, keeping the layout and order."}

One Message, Many Images

The content list can contain several image parts. This lets you ask a model to compare two screenshots or photos side by side:

{"role": "user", "content": [
    {"type": "text", "text": "Compare these two charts. Which one shows higher growth?"},
    {"type": "image_url", "image_url": {"url": chart_one_uri}},
    {"type": "image_url", "image_url": {"url": chart_two_uri}},
]}

Build the second data URI with the same base64 approach used for the first image.

Troubleshooting

ProblemLikely causeFix
400 error on requestThe deployment does not support image input.Deploy a vision-capable model.
Very slow responseThe image is extremely large.Resize to about 1024 px on the long edge.
Wrong MIME type errorThe data:image/... prefix does not match the file.Use image/jpeg for .jpg files.
Garbled text in the answerLow resolution or a very small font.Crop or zoom before sending.

Summary

You have sent an image to a vision-capable model and asked questions about it. You learned that images travel as base64 data URIs inside the message, that the model can describe, count, transcribe, and compare image content, and that the same chat pattern extends to multiple images per request. This multimodal capability will return later when you build document-analysis agents.
