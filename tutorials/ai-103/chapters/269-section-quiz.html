Section Quiz

This quiz checks your understanding of the whole section: the general concept of tools, the built-in image generation tool, and the built-in web search tool. Try to answer each question from memory before checking the answer key at the bottom.

Questions

Question 1

What is the fundamental role of a tool in a model-driven application?

A. To replace the model entirely
B. To let the model request information or actions that lie outside its own capabilities
C. To store conversation history
D. To speed up model training

Correct answer: B.

Question 2

Which piece of a tool declaration does the model read to decide whether the tool is appropriate for the current question?

A. The input_size
B. The search_context_size
C. The description
D. The output format

Correct answer: C.

Question 3

You attach an image generation tool but ask a purely textual question. What should you expect?

A. An image of your question is generated automatically
B. The call fails with an error
C. The model answers with text and never uses the tool
D. A blank image is returned

Correct answer: C.

Question 4

Which tool setting controls the resolution of a generated image?

A. search_context_size
B. input_size
C. user_location
D. output_format

Correct answer: B.

Question 5

What is the main reason a model cannot answer time-sensitive questions without a search tool?

A. It lacks a browser
B. Its training data ends at a fixed point in time
C. It is forbidden from using the internet
D. It can only answer mathematical questions

Correct answer: B.

Question 6

In a response that used the web search tool, what helps your application show the user where each claim came from?

A. The input_size value
B. The annotations or citations attached to the text answer
C. The model's temperature
D. The request ID header

Correct answer: B.

Question 7

You want search results biased toward a specific city for a local weather question. Which option do you set?

A. output_format
B. input_size
C. user_location
D. max_tokens

Correct answer: C.

Question 8

A claim in a search-grounded answer is backed by a citation. What does that citation prove?

A. The claim is true
B. The web page exists and is authoritative
C. The claim came from the cited page, not that the page is correct
D. The model verified the claim independently

Correct answer: C.

Summary

This quiz covered the section's two threads: how the concept of tools lets models request capabilities beyond their own, and how the image generation and web search tools implement that idea for creating pictures and retrieving current facts. If you missed any questions, re-read the relevant chapters before moving on. In the next chapter you will be introduced to computer vision and the Azure AI services that analyze images.
