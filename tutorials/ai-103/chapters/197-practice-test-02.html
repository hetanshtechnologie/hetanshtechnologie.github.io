Practice Test 02

This is the second full practice test for the course. It is designed to feel like the real exam: set aside sixty minutes, work through the questions in one sitting, and do not look up the answer key until you are finished. Each question has exactly one best answer. A few of the questions are deliberately more scenario-based than the section quizzes, so read every option carefully before you choose.

Instructions

  • Allow yourself 60 minutes to complete all ten questions.
  • Work closed book — no notes, no browser, no sample code.
  • Answer every question, even if you have to guess; there is no penalty for a wrong guess.
  • When you finish, compare your answers with the key at the end and review the chapters behind any you missed.

The Test

  1. A team wants to expose a model in Microsoft Foundry so that their application can call it. What is the correct first action?
    • A) Upload training data so the model learns the company's documents.
    • B) Create a deployment, which provisions the model behind an endpoint with a name and configuration. (correct)
    • C) Register a new user in Entra ID.
    • D) Enable continuous evaluation on the model catalog.
  2. In a chat completions call, which message role should carry the assistant's permanent rules and identity for the whole conversation?
    • A) user
    • B) assistant
    • C) system (correct)
    • D) tool
  3. In a Retrieval Augmented Generation (RAG) pipeline, what is the retrieval step responsible for?
    • A) Training the model on the retrieved documents.
    • B) Finding the most relevant snippets from a data source and placing them in the model's context. (correct)
    • C) Summarizing the entire data source into a single paragraph.
    • D) Translating the user's question into multiple languages.
  4. What is the main purpose of content filters and guardrails in a production agent?
    • A) To retrain the model automatically.
    • B) To block harmful categories of content in inputs and outputs, such as hate, violence, and self-harm. (correct)
    • C) To reduce the model's response latency.
    • D) To choose which model serves each request.
  5. In the Microsoft Foundry Agent Service, what is a "tool"?
    • A) A file of source code the agent can edit.
    • B) An external capability the agent can invoke, such as web search, a function, or an API. (correct)
    • C) A UI widget used to design prompts.
    • D) A deployment configuration setting.
  6. What does a workflow in Microsoft Foundry allow you to do that a single agent cannot?
    • A) Replace the underlying model with a smaller one.
    • B) Chain multiple agents and steps together with conditions and structured data passing between them. (correct)
    • C) Automatically fine-tune the model on new conversations.
    • D) Guarantee identical answers for every user.
  7. What is the role of an evaluator in continuous evaluation?
    • A) It blocks harmful prompts before they reach the model.
    • B) It periodically scores recent conversations on dimensions such as groundedness, relevance, and completeness, and records the trends. (correct)
    • C) It allocates requests across model deployments.
    • D) It stores conversation history for retraining.
  8. Which statement best describes the difference between a plain LangChain chain and a LangGraph graph?
    • A) LangChain is Python-only; LangGraph is JavaScript-only.
    • B) A LangGraph graph adds explicit state and control flow, letting you branch, loop, and route between nodes. (correct)
    • C) LangGraph removes the need for a model.
    • D) There is no difference; the names are interchangeable.
  9. What is the Model Context Protocol (MCP)?
    • A) A content safety filter that screens every model response.
    • B) An open standard that defines how AI applications connect to external tools and data sources. (correct)
    • C) A pricing model for API usage.
    • D) A file format for storing model weights.
  10. A support agent must answer questions using the company's product manuals. Which pattern should the solution use so the agent can ground its answers in that content?
    • A) A knowledge source and knowledge base used for agentic retrieval. (correct)
    • B) A single large system prompt containing every manual.
    • C) Random sampling with a high temperature.
    • D) A model router with no data connection.

Answer Key

2CThe system message carries the assistant's persistent identity and rules.
3BRetrieval pulls relevant passages from a data source and injects them into the prompt context.

6BWorkflows orchestrate multiple agents and steps with conditions and data flow.
7BEvaluators score agent output on quality dimensions and track results over time.

Scoring below eight out of ten? Focus your review on the chapters behind the questions you missed. Common trouble spots are the distinction between deployment and training, the role of the system message, and the difference between retrieval, evaluation, and guardrails — three concepts that are easy to confuse.

Summary

This practice test sampled the course's core architecture: deployments, prompting, retrieval, guardrails, agent tools, workflows, evaluation, orchestration frameworks, MCP, and knowledge bases for agentic retrieval. It exercises the same mental model you will need for the certification exam and for building real systems.
