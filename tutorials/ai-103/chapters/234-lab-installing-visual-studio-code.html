Lab - Installing Visual Studio Code

Visual Studio Code (VS Code) is the editor you will use for every code lab in this course. It is free, lightweight, and has first-class Python support. In this lab you will install VS Code, add the Python extension, and create a workspace folder where all your scripts will live.

What You Will Need

  • A working Python installation from the previous lab.
  • About 300 MB of free disk space for the editor and extensions.
  • An internet connection to download VS Code and its extensions.

Step 1: Download and Install VS Code

Exercise 1: Install Visual Studio Code

  1. Open the Visual Studio Code download page (code.visualstudio.com) in your browser.
  2. Download the installer for your platform — the Windows User Installer, the macOS Universal build, or the Linux .deb/.rpm package.
  3. Run the installer. On Windows, leave the default options and tick Add "Open with Code" action and Add to PATH if shown.
  4. Launch VS Code once the installation finishes.
# Ubuntu / Debian Linux alternative
sudo apt update
sudo apt install code

Do not confuse Visual Studio Code with the much larger Visual Studio IDE. For this course the lightweight Code editor is the right tool — install the one from code.visualstudio.com.

Step 2: Install the Python Extension

VS Code is a bare editor until you add extensions. The Python extension provides syntax highlighting, running scripts with a click, IntelliSense, and debugging:

  1. Open VS Code and click the Extensions icon in the left activity bar (the block puzzle icon).
  2. Search for Python in the marketplace.
  3. Select the extension published by Microsoft and click Install.
  4. Wait for the installation to complete; the extension button changes to a gear icon when ready.

After installing the Python extension, open the command palette (Ctrl+Shift+P on Windows/Linux, Cmd+Shift+P on macOS) and run Python: Select Interpreter. Choose the Python version you installed in the previous lab so VS Code and your terminal use the same interpreter.

Step 3: Create a Workspace Folder

All your course scripts need a home. Create one folder and open it in VS Code:

  1. On your hard drive, create a folder named ai103-lab — for example C:\ai103-lab on Windows or ~/ai103-lab on macOS/Linux.
  2. In VS Code, choose File > Open Folder and select ai103-lab.
  3. When VS Code asks about trusting the folder, choose Yes, I trust the authors.

Exercise 2: Confirm the workspace is ready

  1. Create a new file in the folder by clicking the new-file icon in the Explorer sidebar.
  2. Name it first.py and type print("VS Code is ready").
  3. Click the play button in the top-right corner (or press Ctrl+F5).
  4. You should see the output VS Code is ready in the terminal panel at the bottom.

The integrated terminal at the bottom of VS Code is the same terminal you will use to run commands in later labs. Any environment variable you set in your operating system is visible there after you reload the window, so keep your terminal skills sharp.

Recommended Settings

Two small settings make Python work smoother in VS Code:

  • Default formatting: in Settings search for Format on Save and enable it — VS Code keeps your code tidy automatically.
  • Linting: the Python extension enables linting by default, which flags problems like undefined variables before you run the script.

If the play button shows an error about a missing interpreter, run Python: Select Interpreter again and pick the Python you installed. This single setting resolves most "it works in terminal but not in VS Code" problems.

Summary

You installed Visual Studio Code, added the official Python extension, created a dedicated workspace folder, ran a first script from inside the editor, and configured interpreter selection and formatting. Your development environment is now complete — the next lab runs a real program with inputs and outputs.
