Code and resources download for this section

This section is the text-analysis heart of the course. You will prompt a chat model to find entities and topics, produce structured JSON, judge sentiment, and translate text — then switch to the dedicated Azure AI Language service for PII redaction, language detection, and named entity recognition, and finally drive the same service through an MCP server. Every lab is built from a handful of short scripts, so this chapter explains what the section's download contains and how to lay out your project folder so each example just runs.

What Is in the Download

The resources for this section are a single ZIP file containing one Python file per lab, plus a requirements file and a credentials template:

Downloading the Resources

  1. Download the ZIP file for this section from the course download page.
  2. Extract it into a folder named ai103-language on your machine.
  3. Open that folder in VS Code with File > Open Folder.

Set Up the Project Folder

After extraction, your folder should look like this:

ai103-language/
  naive_prompt.py
  json_output.py
  sentiment.py
  translate_chat.py
  lang_pii.py
  lang_detect.py
  lang_ner.py
  mcp_list_tools.py
  mcp_use_server.py
  translator.py
  requirements.txt

Install the required packages once, in this folder's terminal:

pip install -r requirements.txt

Credentials Without Hard-Coding

The chat-model scripts read AZURE_OPENAI_ENDPOINT and AZURE_OPENAI_KEY from environment variables, while the Azure Language scripts read AZURE_LANGUAGE_ENDPOINT and AZURE_LANGUAGE_KEY, and the translator script reads AZURE_TRANSLATOR_REGION alongside a key. The simplest way to keep these out of your code is to set them in the terminal before running a script:

$env:AZURE_OPENAI_ENDPOINT = "https://YOUR-RESOURCE.openai.azure.com/"
$env:AZURE_OPENAI_KEY = "YOUR_KEY"
$env:AZURE_LANGUAGE_ENDPOINT = "https://YOUR-LANGUAGE.cognitiveservices.azure.com/"
$env:AZURE_LANGUAGE_KEY = "YOUR_KEY"
$env:AZURE_TRANSLATOR_KEY = "YOUR_KEY"
$env:AZURE_TRANSLATOR_REGION = "YOUR_REGION"

Alternatively, copy .env.example to a file named .env, fill in the values, and let the python-dotenv package load them automatically at the top of each script.

The .env file contains your keys, so it must never be committed to a repository. Add .env to your .gitignore file the moment you create it.

Replace the Placeholders

Before running any example, search the file for YOUR_DEPLOYMENT_NAME and replace it with the exact name of your chat model deployment in Foundry. The MCP scripts also contain YOUR_SERVER_FQDN and YOUR_GENERATED_KEY, which must match the endpoint and access key of the Azure Language MCP server you deploy in the MCP chapter.

If you prefer to type the examples by hand, the code in the lab chapters is identical to what you will find in the ZIP. Typing them yourself is a better way to build familiarity with the Azure SDKs, but the download saves time when you want to redo a lab quickly.

Summary

The section download gathers the prompting scripts, the Azure Language scripts, the MCP client scripts, the translator script, a requirements file, and a credentials template into one folder. After installing the dependencies, setting the environment variables, and replacing the deployment-name and server placeholders, every example in this section runs as written.
