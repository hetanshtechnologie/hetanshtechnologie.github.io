Lab - Azure Speech - Text to Speech - Python

In this lab you move from the Speech Studio portal to real code. You will use the Azure Speech SDK from Python to synthesize text into an audio file, select a specific neural voice, and then read the result object to confirm the synthesis completed. The pattern you build here — configure the service, attach an audio target, and call the synthesizer — is the same one you will reuse for every speech operation in this course.

Exercise: Synthesizing speech with the Python SDK

Step 1 — Install the SDK

Open a terminal in your project folder and install the Speech SDK:

pip install azure-cognitiveservices-speech

Step 2 — Write the synthesis script

Create a file named tts_demo.py. The script reads the key and region from environment variables, selects a voice, and saves the synthesized audio to a WAV file on disk.

import os

import azure.cognitiveservices.speech as speechsdk

SPEECH_KEY = os.environ.get("SPEECH_KEY", "YOUR_SPEECH_KEY")
SPEECH_REGION = os.environ.get("SPEECH_REGION", "YOUR_SPEECH_REGION")
VOICE_NAME = os.environ.get("VOICE_NAME", "en-US-JennyNeural")

speech_config = speechsdk.SpeechConfig(
    subscription=SPEECH_KEY,
    region=SPEECH_REGION,
)
speech_config.speech_synthesis_voice_name = VOICE_NAME

audio_config = speechsdk.audio.AudioOutputConfig(filename="welcome.wav")
synthesizer = speechsdk.SpeechSynthesizer(
    speech_config=speech_config,
    audio_config=audio_config,
)

text = "Welcome to the speech section of AI-103. This audio was generated by Python."
result = synthesizer.speak_text_async(text).get()

if result.reason == speechsdk.ResultReason.SynthesizingAudioCompleted:
    print(f"Synthesized {len(result.audio_data)} bytes to welcome.wav")
elif result.reason == speechsdk.ResultReason.Canceled:
    cancellation = speechsdk.CancellationDetails(result)
    print(f"Canceled: {cancellation.reason}; {cancellation.error_details}")

Step 3 — Set your credentials and run

Set the two environment variables to match your Speech resource, then run the script. On Windows PowerShell you can set them inline before running:

$env:SPEECH_KEY = "YOUR_SPEECH_KEY"
$env:SPEECH_REGION = "eastus"
python tts_demo.py

Open welcome.wav in any media player and you should hear the sentence spoken by the voice you selected.

Step 4 — Switch voices and compare

Change VOICE_NAME to a different voice, such as en-GB-SoniaNeural or en-US-GuyNeural, and rerun the script. Save each output under a different filename and listen to the difference in accent, tone, and pacing.

Understanding the Result Object

The call to speak_text_async().get() blocks until synthesis finishes and returns a SpeechSynthesisResult. Its reason field tells you how the call ended: SynthesizingAudioCompleted means audio was produced, while Canceled means something went wrong. In the canceled case, CancellationDetails exposes the reason and a human-readable error message, which almost always points to a bad key, a wrong region, or a voice name the service does not recognize.

Controlling the Audio Output

The AudioOutputConfig decides where the synthesized audio goes. Passing a filename writes the clip to disk, as you did here. You can instead point the output at the default speaker by omitting the audio config entirely, or capture the bytes in memory and stream them to a web client. For format control, speech_config accepts an output format such as MP3 or 24 kHz mono; by default you get a standard WAV file.

For long narrations, do not block on a single .get() call. The synthesizer exposes events such as SynthesisStarted and Synthesizing, which let you stream the beginning of a clip to a player while the rest is still being generated.

Summary

You installed the Speech SDK, synthesized a sentence into a WAV file with a chosen neural voice, and learned to interpret the result object. Text-to-speech is now a drop-in building block you can combine with any generated text. In the next chapter you will take finer control of the delivery using Speech Synthesis Markup Language.
