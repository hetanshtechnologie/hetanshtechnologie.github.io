26. Appendix

Best Practices

  • Use separate warehouses for dev, test, production
  • Set AUTO_SUSPEND aggressively (5-10 min)
  • Use transient tables for staging data
  • Leverage zero-copy cloning for dev/test environments
  • Cluster large tables on frequently filtered columns
  • Use materialized views for dashboards
  • Set up resource monitors on all warehouses
