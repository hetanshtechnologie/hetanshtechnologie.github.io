38. Appendix

Best Practices

  • Use APIRouter to organize endpoints by domain
  • Separate models (schemas), services, and routes
  • Use dependency injection for DB sessions, auth, and config
  • Always validate input with Pydantic models
  • Use response_model to control output
  • Set up CORS explicitly for production
  • Use environment variables for configuration
  • Add logging and request ID middleware
